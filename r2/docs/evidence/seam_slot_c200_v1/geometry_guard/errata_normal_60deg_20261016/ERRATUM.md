# 60°法向条件勘误：推导系数错误，实际判定与统计不变

2026-10-16，依据用户附带反馈核查。错误由本地报告作者承担；不是附件推导错误。

原主报告第4节、normal/REPORT.md和normal_audit.py内的报告文本模板把60°条件写成了 `r < -sqrt(3)*abs(h)`。这是错误的系数；其实际对应30°条件。

对非退化三角形，已有恒等式为 `cos(theta) = -r/sqrt(r*r+h*h)`。要求 `theta < 60°`，先有r<0，再由`4r²>r²+h²`得到：

**正确条件：`r < -abs(h)/sqrt(3)`。**

解析反例r=-1、h=1给出theta=45°，通过正确60°条件，不通过原错误文字条件。垂直侧壁r=0、h≠0仍为90°，因此“该约束会误罚正常侧壁”的结论不变。
