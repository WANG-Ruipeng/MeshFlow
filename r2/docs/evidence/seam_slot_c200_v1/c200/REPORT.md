# SEAM_SLOT_C200：四条 TRAIN 条件、200 步端到端配对结果

完成日期：2026-10-16。状态：**两臂训练、32 RAW、32 单次官方 D0 POST、64 份评分及实际图审全部完成。**

## 结论

**共享原边表示已经出现真实的 seam→bulk 接续信号，不能把本轮归为“全部只是小翻片”；但当前完整配置还不能替代 FULL4_C200，也不直接放行 47 父长训练。**

候选 16/16 份有合法 C/F 接口；13/16 份从合法 seam 种子、不经过 C，能够沿合法 free 共边到达 bulk，其中 11/16 的 bulk 可达面积超过 30%。这说明固定底边的接口面与其余生成面可以共同形成较大的连通区域。它不证明完整封边、无交、整个网格可定向或新父泛化。

代价不能忽略：占用头只找回 36/62 条来源占用边；POST FF 增加 1.722 个百分点、I 增加 2.631 个百分点，新增 C/F 非流形边；共同口径的方向一致可达面积反而从 51.876% 降到 50.658%。因此本轮判为 **表示可行性的局部正信号，完整方法尚未晋级**。

实际图审中，唯一新增的明确座面采用是 `73/n1`，但它恰好没有 seam→bulk 共边。**不能把这个采用改善同时记成主体接续成功。**

## 4. 真正的 seam→bulk 结果与逐父差异

候选内部图从与 C 有合法边的保留 seam 面出发，只沿合法 free/free 共边扩展，**禁止经过 C，也不把 seam 面积计入 bulk 分子或分母**。点接触不算边。普通 FULL 没有 seam 角色，此列为 NA。

16 份候选共保留 141/144 张 seam，删除 3 张并保留原清理原因，没有复活。合法 seam→bulk 边共 54 条，总长 50.963；累计可达 bulk 面积 299.589，总保留 bulk 面积 656.134（模型单位平方）。逐输出比例宏均值 49.248%、中位数 53.341%，不把累计面积比替换为宏均值。

|---|---:|---|---:|
| 73 | 22 | 16.814% / **0%** / 63.649% / 28.937% | 1/4 |
| 3f | 2 | 93.983% / **0%** / 98.638% / 99.761% | 3/4 |
| 85 | 8 | **0%** / 45.543% / 40.510% / 46.175% | 3/4 |

这些正数说明存在实际共享边路径，而不是第三点恰好靠近 bulk。30% 只是预登记展示标记，不认证完整边界或形状质量，也不能反推一定是某一层 self-attention 起了作用。

值得保留的局部正例：`73/n2` 的共同整体可达面积从 0.019% 提高到 64.380%，其中 seam→bulk 为 63.649%；`85/n3` 从没有合法 C/F 边变为 7 条，seam→bulk 达 46.175%。但同父其他噪声并不均匀受益。

两个关键反例：

- `73/n1`：22 条合法 C/F 边、22 张合法 seam 全部保留，但 seam→bulk 边为 0、bulk 可达面积为 0。图上 C 用途改善，仍不能称为主体接续成功。此例占用布局完全正确，已经排除了“只有占用漏判”这一单一解释。
- `3f/n1`：从 C 出发的整体可达面积为 95.153%，但新 seam 的 free-only bulk 可达仍为 0。若允许经过 C，会错误地把旧连接记成新 seam 的贡献。图审也记录了额外斜片/内层外观。

只读缓存进一步定位到同一张 seam：RAW slot16（edge_id2），其固定端点引用 C 顶点；第三点经过 D0，再被 GEO 吸到另一个 C 顶点，最终三点共面并向内跨盖来源 C 面66/67/68。三个缓存精确交叠面积合计1.86047，等于这张 seam 的面积。I 的871/2048命中是带容差查询覆盖，不能直接替换为精确面积比，也不能把邻近查询命中当成第四个精确相交对。RAW 已有重复覆盖风险（I=24.365%），POST 将其变成更大的共面覆盖；既不是只有后处理造成，也不能只怪连续生成。证据见 `audits/3f_n2_cached_overlap_tail.json`。

## 6. 工程、预算和复核

训练使用严格 deterministic、math SDPA、BF16前向、FP32参数及积分、关闭TF32。实际资源检查后，CPU OT两worker；训练显存余量不允许第二worker，故两臂串行；采样首worker实测后允许两个独立进程部分重叠；D0逐臂执行。没有停止用户图形学进程。

训练墙钟 FULL358.400秒、SEAM385.100秒，合计约12分23秒，另有准备、导出、采样、评分和审阅。训练 reserved 峰值3124/3140MiB；这不是进程显存峰，WDDM进程显存为NA。整卡峰值13536/13221MiB含其他应用，不能全部归因于本实验。实际调用账本：
