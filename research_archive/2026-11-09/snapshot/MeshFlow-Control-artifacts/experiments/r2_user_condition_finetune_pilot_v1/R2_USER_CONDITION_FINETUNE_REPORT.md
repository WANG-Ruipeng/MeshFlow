# R2 用户式条件续训 pilot：实际结果

实验：R2_USER_CONDITION_FINETUNE_PILOT_V1  
完成日期：2026-10-10（Asia/Shanghai）  
状态：固定训练、生成、评分与全量 AI_PROXY 图像审阅已完成。停止于注册预算，不晋级默认模型。

**这次真实执行完成，但还不足以用 USER 替换原 R2。** 117 条用户式条件带来了有限的座面采用信号：两条新座面条件各有一份噪声更清楚地使用 C，另一份噪声未同步改善。相对同预算普通续训，靠背没有清楚的用途收益；新面板近重复覆盖与瘦长三角面增加，旧任务也有局部回退。

这不是实现接线失败，也不能解释成“新数据无效”或“全部问题来自脏数据”。本轮支持的结论更窄：**当前 R2 上，完全替换为这117条小K条件续训1000步，尚未得到可采纳的整体改进。** 原主实验 R2 step6000 继续作为研究参照；两份续训终点保留作证据。

## 1. 实际训练了什么

| 模型 | 唯一起点 | 训练条件 | 新增更新 | 累计更新 |

| R2_FROZEN | 主实验完整R2 step6000 | 无 | 0 | 6000 |

| R2_CONT_USER | 同一份R2及完整AdamW/RNG | 同25父，活动117条条件 | 1000 | 7000 |

没有使用确认实验R2、START权重或仅含参数的推理导出作为训练起点。初始生成器、优化器、逐参数时钟和RNG身份均核验；两臂末端194个AdamW状态的步数均为7000，完整终点与纯生成器导出参数一致。

架构保持 Native/T1 + role + Geo，全参数微调；free-only FM，HYBRID λ=0.25，先对原Gaussian做free-only OT，再混入独立epsilon，不重新匹配。batch8 / microbatch1，每批8个不同父，4原宽+4共同宽度增强（0.9—1.1）。FM仍按整batch的 `9 × sum(N−K)` 标量归一。

AdamW：lr=1e-5，betas=(0.9,0.95)，weight_decay=0，gradient_clip=1，无新scheduler；继承原动量。BF16前向、FP32参数与积分，TF32关闭、SDPA math、确定性算法严格启用。沿用原纯FM训练器的模式和算术；未新增B、READOUT、教师或几何loss。没有用在线FM大小择优终点，因为两臂面对的free任务不同。

500步仅存恢复点，未生成或评价500步图。唯一评价终点是local1000/global7000。

两臂各8000次曝光，每父恰320次；117条新C和395条旧C全部被使用，HOLD/DEV训练曝光0。USER实际座面/靠背曝光4135/3865；small/medium/full为1440/3351/3209；K=1有1510次。完整分布见[逐父曝光](audit/parent_exposures.csv)、[逐条件曝光](audit/condition_exposures.csv)、[曝光分组](audit/exposure_breakdowns.csv)。

这轮没有清洗完整答案：14个已知缺陷父继续保留，原M合计310对确认问题及3对UNKNOWN。117条活动条件中64条Y有确认问题；3ede的两条座面C/Y仍有局部共面重叠，7f82仍有未决面对。风险不从生成分数扣除，不把UNKNOWN当无交。详见[数据配对审计](audit/DATA_PAIRING_AUDIT.md)。

## 4. 冻结的评价口径

三模型每个28输出：6新条件×2固定Gaussian，以及8旧条件×2原Gaussian。冻结R2旧16份RAW仅复用几何，84份都按本轮同一配置重新CPU评分。新Gaussian和C查询在首次新生成前冻结；不按结果重抽。

尺度固定为 `L = sqrt(3) × 2 / 0.3762 = 9.2081382646`，不从生成bbox或来源GT回算。每个C使用2048个固定面积查询；先平均同条件两噪声，再父等权。新/旧面板分别汇总，座面/靠背另列。

- CF、FF分别统计C–free、free–free的确认穿透及正面积共面重叠，受影响面比例分母为N−K；不是面对数比例，不是whole-mesh Ri。
- I即ConflictCov_C：全部C查询上的穿越影响带，与C内部查询上的近并行free覆盖的并集，分母为全部C查询权重。cross/dup半径均0.005L；0.01L边界排除带仅用于dup，cross不受此排除；近平行角度15°。近重复项也可能标记合法薄壳/厚度，**不能直接当语义失败或确认非法重复**。并集不等于两项直接相加。
- 三角形形状报告free最小角<5°比例、真实q>10比例、q均值及角度分布。`q = sum(l_i²) / (4 sqrt(3) A)`；与面积近零退化分开。近退化面积阈值A/L²≤1e-12。
- D_free为同条件两噪声free表面的对称平方距离、L²归一，每个free2048面积点；每条件只有一个噪声对。距离更大不代表变化更合理。
- 精确坐标共享边/连通分量只作RAW诊断，不把三角汤分量直接叫明显碎片。S无登记接口、E无外露任务、唯一GT重建均为NA；没有补造指标或运行特征教师。

84评分PASS、生成CF/FF未决面对与I不确定覆盖均为0，面积退化/零面积/精确重复面计数为0。**PASS指计算与输入合同有效，不是优质网格。** 原来源M的UNKNOWN仍保留。全部84的精确坐标CF共享边为0，也不据此强加本轮未要求的水密合同。

## 7. 决策与一个优先后续假说

**不晋级 R2_CONT_USER；维持主R2作baseline。** 保留117条条件池及本轮全部证据，因为它展示了局部适配信号，但不把“C精确保留”“CF略降”或两张较好的图片当作控制能力已经提高。

如果继续，优先检验一个候选：**在相同R2配方下做新旧条件混合回放，控制完全替换旧C分布带来的代价。** 当前证据直接显示，新池K更小、free监督量更多，旧任务又出现小角与CF回退。相比立即加步数或加loss，先检验这项已实际改变的数据分布更容易解释。

可证伪假说：完全替换C20/C40是部分回归的原因；保留旧条件曝光后，仍可维持局部新座面采用信号，并减少旧任务CF/小角代价。如果C用途仍只改善单噪声、靠背仍无收益，或新面板近重复/整体折层不缓解，就不能认为混合解决了问题。这里不指定未经测量的比例或追加预算，也不据本轮断言训练目标缺陷就是根因。

**本报告只提出假说；没有自动启动混合组、增加更新、清洗新数据、改变loss、扫描求解器或切换默认模型。**
