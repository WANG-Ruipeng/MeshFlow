# 单快照 Flow Matching 实验：完成报告

已按附件执行零训练接线核查、提取域干预、单快照 direct FM 训练、字段组合诊断，以及预先规定条件触发的一次更细步长复测。自由生成在本轮仍未通过。当前更直接的缺口是位置、法向及跨字段联合误差；结果没有支持继续增加 Euler 步数，也没有支持把 Q 传输设为下一步必须加入的生成模块。

这只是一个固定对象、一个模型种子、一个训练预算的诊断。它没有否定 FM，也没有证明网络容量不足或某一种新架构必然有效。

固定目标是薄 U 的 frame 6、已审核有效的解析 q_only 状态（256 个元素，目标提取网格508面）。用宽128 DeepSets、原优化器及原 chart 训练 direct FM 3,000 步，实际24,000次目标曝光；训练耗时125.878秒，最后100步 loss均值0.359118。训练完成后冻结权重，32个预先固定噪声进行64步Euler自由采样。

保留上一轮24目标数据的 chart mean/scale，没有为单对象重新归一化；采样噪声与旧实验逐字节相同，但不与本轮训练噪声或独立路径探针精确重合。独立审核覆盖全部24,000训练噪声，并重放4批训练配对。这个任务刻意允许记住唯一目标，不讨论泛化与多样性。

**“有效”指闭合有向二维流形、所有顶点链接为单环、Betti=[1,0,1]、无精确自交/退化/重复面、图容量有限且非负；没有额外表面RMS或面数阈值。** 所有实际面数与表面误差单独保留，因此不能把表中有效直接叫作完整形状重建成功。两个域分别报告，不做逐样本取最优。

替换的独立字段是实际提取位置 v、未单位化的 raw n、中心化4×4因子 F。世界坐标 Q 始终在选定位置重新解码；没有直接搬运旧世界Q，没有重新求最优顶点、裁剪点、单位化法向或重拟合Q。原始拟合元数据 p 与实际提取点 v 不相同，报告中的“位置”明确指后者。

这张表支持的定位：

- 预测 Q 因子在真位置、真法向环境中有30/32可提取，但仍有2份夹点式非流形，不能说 Q 已完全学好。其固定域表面RMS中位数为0.071705%目标包围盒对角线；参考是选定508面目标网格。
- 单独保留预测位置只有1/32有效；单独保留预测法向只有4/32有效。位置与法向当前都有直接可见的缺口。
- 两个单字段在真值环境中可容忍，并不保证组合可容忍：固定样本23、25、30的 OPO 和 OOP 各自有效，OPP均失效；样本20的 POO 和 OOP有效，POP失效。八组合为同一噪声、同一匹配，排除了换样本造成的表面比较。
- 真位置单独替换仍然0/32，不能把问题简化成“只修位置就行”。替换真Q的 PPO在包围盒域只救回2份，也未提供“Q是唯一瓶颈”的证据。

自由64步的固定域32份均成功执行提取，但0份通过联合有效合同；30份有非单环顶点链接、21份有非流形边、22份不连通（这些计数相互重叠）。没有精确自交或退化。全部32份生成点均在真实固定角点域内。输出面数290–396，中位数327；表面RMS中位数3.142897%目标包围盒对角线。这说明仅仅“程序能提取”和“没有自交”远远不足。

独立条件路径探针使用32份未用于更新的噪声、六个固定时刻。t=0.9的输入已含90%目标：端点诊断在固定域23/32有效、包围盒域24/32有效。它们属于目标辅助诊断，不能当成生成结果，也不能单凭近端成功证明积分器出错。

零速度基线只计算了语义误差，没有测量其网格有效率；不能把近端探针的全部通过率归功于网络。后验终点位置匹配与条件路径初始耦合不同，以上是描述性比较，不是严格的相同状态速度误差分解。保留初始耦合时自由终点的法向均角中位数也有41.158度，位置RMS7.964%bbox。路径早期t=0的端点预测仍有8.938%位置RMS与40.67度法向均角。现有证据并非“训练路径全部学好、唯独积分不行”；早期学习与离轨状态上的误差仍需要区分。

训练前已规定：某一域t=0.9探针至少24/32有效、同域自由64步至多8/32有效，才追加一次同权重同噪声的256步Euler。包围盒域满足触发条件，因此实际执行了这一复测：

- 固定域：64步0/32，256步0/32，救回0份。
- 包围盒域：64步0/32，256步0/32，救回0份。
- 自由终点位置RMS中位数从6.21666%变为6.22620%；法向均角从48.777度变为48.923度。没有观察到有用改善。

这只排除了当前模型下“把64步增到256步就能修好”的简单解释，不是所有求解误差均可忽略的证明。没有继续扫步数或追加训练。

零训练检查也已完成：

1. 总速度训练目标、实际采样更新、因子空间传输链式法则、目标重复/重排编码共38项检查通过；两种chart/两种精度/两臂合计8次已知速度oracle回放全部通过。未发现阻碍这轮direct实验的接线错误。
2. 目标F采用对称主PSD平方根，不是Cholesky；目标重复编码和重排后还原逐字节一致。本轮没有观测到目标标签随机正交gauge，但生成F依然不受唯一性约束。
3. 对上一轮64个自由终点保留P/n/Q，仅将固定角点换成生成位置AABB加固定余量：direct仍0/32，transport仍0/32。24个旧oracle仍24/24有效，其中14个的规范三角面连接发生变化，证明提取域的确是一项实质干预。
4. 本轮单目标float64、float32 chart在两个域的4次oracle检查全部有效；八组合OOO的64次身份检查全部有效，规范目标连接一致。

必须更正上一轮角点越界口径：官方固定角点实际是 ±1。旧 input_sites_outside_corner_cube 用 abs(v)>0.5 统计的是半立方体越界，不能据它断言越出官方提取域。重新按 ±1 核算，旧direct有5/32份、总计6个点越界；旧transport有32/32份、总计123个点越界。旧原始文件不覆盖；此报告和新域诊断保留更正。薄U目标改变包围盒后规范三角面完全相同，旧PL表面采样RMS的小幅变化来自面序及抽样变化，不是几何收益。

本轮生成、probe、组合与oracle合计644次提取（不含独立的90次旧域干预）。独立复核6594/6594项通过；这是账本和执行一致性通过，不能覆盖自由生成0/32的结果。主实验原清单5264个文件约285.04 MiB，包括完整状态、网格、提取追踪和最终权重。所有输出在新目录；官方MeshFlow源码仍干净，官方长训保持暂停。

我的下一步建议是保留FM，但暂不恢复多对象，也不扩大当前同时生成P/n/F的训练矩阵。优先针对位置与法向做一个预先限定预算的学习能力/局部几何交互对照，并保持本轮噪声、字段账本和有效性审核。是否需要换局部邻域网络、改法向表示或改耦合，现在还没有独立证据；这轮结果只给出了更明确的检验顺序。Q传输继续保留在已经有证据的有效初态形变任务中。
