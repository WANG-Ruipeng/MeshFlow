# 参考曲面语义更正（2026-09-25 03:37）

此前部分夜间实验协议/进度/说明把 A 的离线 RMS 参考称为“原 GT / original GT triangles”，并把优化器描述为“不接触 GT”。这些表述不准确，需要以下更正。已封存文件、数值、模型和失败记录保持原样，本说明作为外侧勘误。

## 实际测量的是什么

A 固定真实对象主场实验中的 ref_vertices/ref_faces 是同一份 2050 节点径向场的 2050 顶点、4096 三角面完整曲面，逐值等于 RadialSupport.mesh(logr)，并非原始资产网格。16/16 对象均已只读逐数组核验通过。它测量的是：把这个主场离散为 512 面时，出口引入了多少表面误差。

- layout_student/prepare.py 原本就强制检查该等式，再把这些数组写入学习/评测数据。
- layout_value/optimizer.py 从同一 logr 重建同一完整参考曲面，用局部表面距离目标优化布局。因此不能说它没有参考曲面信息。它没有读原始资产；内部优化采样和离线两次 MC 采样彼此不同，但参考几何相同。
- 学习网络仍只收到既定的 256 点 proxy 特征和状态；上述更正没有改变模型输入。教师制作利用完整主场曲面，属于从局部优化结果进行摊销学习的设置。
- 两次独立 MC 是同一参考曲面的独立抽样，用于检查估计稳定性，不是两个独立参考对象或外部测试集。

## 哪些结论仍成立

同场 RMS、精确512面、拓扑/相交、共同双角门槛、训练和恢复测试的数值不变。有关“教师方向拟合改善并不保证同场几何/质量收益”“质量门槛改变局部优化轨迹”的结论仍按原限定成立。它们不能直接升级成对原始资产重建更好、端到端生成质量更好，或类别泛化的证据。

原 layout_value/representation/ 中另有主场到原始资产的独立指标，归一化依据原 lineage。其16对象 RMS 中位0.240873%、范围0.163943%–0.398798%（原资产包围盒对角线百分比）。本次只核验并读取旧指标，没有重新抽样；这些表示误差不能与出口误差简单相加。当前勘误也没有对各新学习出口重新测量原始资产误差。

生成主场三出口的 same-field RMS 本就明确使用生成主场参考；分布指标另与真实资产比较。这两种指标应继续分开解释。
