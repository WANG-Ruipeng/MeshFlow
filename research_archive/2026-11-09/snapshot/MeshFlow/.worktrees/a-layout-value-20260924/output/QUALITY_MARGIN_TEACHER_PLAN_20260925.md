# 四对象质量余量教师：待决定是否执行的固定预案

状态：仅设计，未建立正式 run、未运行优化或扰动、未修改原标签。等待 balanced 结果与 root 的执行决定。

目的：区分“主场上不存在足够好且有余量的端点”与“原教师过于贴边、微小方向误差容易失去资格”。本轮只能提供局部优化与邻域证据，不能证明全局不存在，也不能直接证明网络能够学会新教师。

## 固定比较

沿用 warm_start.py 的同四个 train UID：

- 7f1be3e7b6adeeae9bb399e812556da2：最大教师位移能量对象。
- 2379915c82c2b2d02530f02db7e9157e：先前单对象诊断对象。
- 8c919e992db7cb081e5b68ee10358ea3：较小教师位移对象。
- 736820a85063a4371e5b68ee10358ea3：原零位移教师对象。

每个对象恰好两起点：Fixed、已冻结的原 teacher_u。共 8 次原 optimize_layout 调用，无网络预测参与。两个起点不是相互公平的在线算法；teacher 起点是离线参考，只检验局部可达性。

唯一新质量要求：同主场实际 Fixed 的 min_triangle_angle_deg 与 triangle_min_angle_p05_deg 各加 0.1 度。原 1e-6 度数值容差保留；同时输出未经容差修正的实际余量，避免把恰好满足阈值描述成稳健证书。

原优化器源码不变：CPU 4 线程、interop 1、float64、64 步，安全时间上限 3600 秒；原 2048 内部 MC 与三点面求积、原 Adam/线搜索/切向投影/retract、最小内部 loss 的 accepted feasible 选择不变。种子沿 warm_start：1493501 + 原 sorted16 UID index，同 UID 两起点相同。原始起点、第 0/16/64 步、实际终止快照和 optimizer_final 分开保存；若未达快照或恢复失败明确留账，不插入 Fixed 回退、不重启、不换起点、不搜索 margin 或步数。

同时报告旧 Fixed 门槛与新 +0.1 度门槛、两种角度实际余量、精确有效性、两次 GT RMS、相对 Fixed 与原 teacher 的误差变化、优化耗时。不能用 GT RMS 选择两个起点、快照或新标签；可行但误差更大是质量—逼近代价，不应隐藏。

## 邻域敏感性

沿 teacher_sensitivity.py：每对象 16 个预定 trial，seed = 1393501 + 16 * 原 training_parent_index + trial；每顶点独立 Gaussian，投影至当前端点切平面、归一成单位分量 RMS，然后 normalize 回球面。相同 UID/trial 共用原始 Gaussian，所有端点复用它；不同端点的切平面不同，不能声称实际位移向量完全相同。

三个被扰动端点为原 teacher、Fixed 起点优化终点、teacher 起点优化终点。fraction 固定 [0, 0.0001, 0.001, 0.01, 0.1, 0.5, 1]，扰动绝对幅度统一使用该对象原 teacher 相对 Fixed 的位移分量 RMS，而不是各个新端点自己的位移。由此共 4 * 3 * 16 * 7 = 1344 个计划槽位；优化失败/无可用端点仍保留槽位，不能只统计成功端点。

新旧端点的主要稳定性比较均使用原 Fixed 双角度门槛；另外显示相对 +0.1 度门槛的角度余量。记录方向行列式、归一后的真实方向 MSE、两角度和角条件通过率。扰动阶段不做完整精确相交审核，所以只能称“角条件稳定性”，不能称完整有效率。

关键限制：736820... 的原 teacher 位移 RMS 为零，严格复用原定义时所有 fraction 都是零扰动。这一行必须标作“扰动退化，不能判断稳定性”，不能把 16/16 当稳健证据。若下一步确需比较这个零教师对象，应另行预声明一个所有端点共用、由 train12 正能量中位数决定的绝对 RMS 网格；本预案不擅自增加该实验。

独立切向 Gaussian 不是学习模型的误差分布：没有跨顶点结构、偏差和径向区域相关性。提高此通过率只支持更大的局部角条件余量，不能推断训练后资格通过率或生成质量提升。

## 成本与解释边界

现有 a_warmstart_cpu_smoke_20260925_02 合成 CPU4 烟测：4 步优化约 1.624 秒，一次端点精确审核约 0.139 秒，双 8192 MC 约 1.241 秒。直接外推 512 步约 208 秒，16 个端点审核加 MC 约 22 秒；只宜估计为几分钟起，真实对象恢复/线搜索/拒绝会增加耗时。1344 个径向查询和角度统计另计，不能拿合成烟测当正式运行速度。隔离计时窗口期间不运行。

若两起点均恢复失败：只说明固定预算/原恢复策略未找到更严格端点，不等于可行域为空。若找到更大余量且保留原教师大部分误差收益：支持再考虑有余量标签训练，但本轮不修改原标签。若更大余量以明显 RMS 退化为代价：显示该对象上的局部 Pareto 代价。若有余量但随机扰动仍脆弱：说明固定 0.1 度未解决当前邻域敏感性，仍不能据此调 margin 重跑。
