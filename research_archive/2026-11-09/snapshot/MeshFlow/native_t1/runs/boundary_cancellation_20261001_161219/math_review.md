# Localized Boundary Cancellation：独立数学审查

本记录仅含解析推导和最小夹具建议。未调用 loss、autograd、模型、GPU、OT、优化器或几何评分；没有修改主实现或生产公式。审查了 `E:/AGENTS.md`、仓库及 `experiments/mf_h1_local0` 的祖先规则，并检查本目录，未发现适用的 `AGENTS.md`。

## 1. 本次解释的公式和单位

对每张预测自由三角形，先按 `dot(cross(pred), n_GT) < 0` 决定是否反转其三个半边方向。这里 `n_GT` 必须是对应源面的、脱离随机角排列的可信一致朝向参考。固定 C 只贡献按同一全局朝向得到的有向外边界。

半边 a→b 的中点和切向量分别取

`m_e = (a+b)/2`，`tau_e = b-a`。

因此 tau 是**带长度的边向量**，不是单位切向。两个尺度分别为 `sigma_s = (0.05, 0.10)_s * L`，每个尺度

`B_s(z) = sum_e exp(-||z-m_e||²/(2*sigma_s²)) * tau_e`，

`loss = (1/2) * sum_s [ (1/R) * sum_r ||B_s(z_r)||² / L² ]`，`R=64`。

坐标、查询、sigma 和 L 同时缩放 c 时，B 缩放 c，loss 不变。若改用单位切向，B 不随 c 缩放，原 `/L²` 会使 loss 缩放为 `1/c²`，且不再按边长表示边流。这不是等价实现。若实现先把坐标除以 L，则使用归一化边向量、sigma=0.05/0.10，最后不能再次除以物理 L²。

中点 Gaussian 是边线积分的一点求积，不能据此声称对任意边细分不变：同一长边拆成两段后，两个新中点的核值通常不同。不过，**两侧使用相同完整边的共形三角剖分**仍逐边精确抵消，无需均匀网格。

## 2. 闭合和直角测试为何应通过

一条被一致定向的两张相邻面共享的边，其两个半边为 a→b 和 b→a。它们具有相同中点、相同 Gaussian 权重，且 tau 相反，所以贡献逐点相消：

`k(z,m)*(b-a) + k(z,m)*(a-b) = 0`。

这与面面积、边长、两面夹角及 sigma 无关。对共形、闭合、一致定向的三角网格，所有边逐对消去，因此 B 对所有 z 恒为零。直角立方体的折角不构成例外。

对于分成已知 C 和自由区的同一个闭合网格：自由区内部边互消，C 内部边无需纳入；剩余 C 边界和自由区边界应逐对反向抵消。若 C 有多个分量或不是拓扑圆盘，证明仍成立，只要求正确提取全部有向边界，不擅自补面或连接分量。

FP32 中只能要求预注册容差内近零，不能承诺任意求和顺序下逐位零。门槛 `<1e-6` 应明确作用于上述无量纲 loss，而不是混用 B 的 RMS、未归一化 loss 或最大分量。

## 3. 绕序和法向属于数据准备正确性

原始源 GT 若一致定向，而 chair 归档包含随机奇置换，不能直接把归档三角形的 cross 当成全局一致 `n_GT`。奇置换会翻转 cross，但不会改变三角片几何；若连 GT 参考法向也随奇置换翻转，逐面对齐后依然可能保留彼此冲突的面朝向，共享边将错误相加。

正确证据链应是：原始源面 ID及原始角序 → 一致朝向参考法向与 C 有向边界 → 按实际 face/corner 标签对应到当前样本。几何坐标和实际采样顺序保持不变；不能为了过门禁修改真实 C、复制三角形或投影预测顶点。参考法向和固定 C 不应接收梯度。

当 `dot(pred_normal,n_GT) != 0` 且参考 n_GT 固定时，预测角的奇置换翻转预测 normal，并同步翻转半边；符号对齐把最终有向半边集合恢复为相同集合，理论上具有 S3 不变性。浮点求和次序仍可能产生舍入差异。

**零内积是单独的边界情形。** 当预测法向与参考法向正交，或预测面退化时，`<0` 分支不能消除方向歧义：奇置换后两个零内积都不触发反转，最终半边可整体反向。与其它场相加时 loss 也可能改变。方向切换在零内积处不光滑，不能把非零内积下的 S3 证明推广到该处。应记录这类情况；不要临时加抖动、换法向或改阈值后声称仍是原公式。

## 4. 小裂缝：局部有下降方向，不是全局保证

先看一对原本抵消的边。保持同一向量 e 和反向 -e，把中点沿单位方向 d 对称分开：`m±delta*d/2`。其场为

`B_delta(z) = e * [ k(z,m+delta*d/2) - k(z,m-delta*d/2) ]`。

在 delta=0 附近，

`B_delta(z) = delta * e * k(z,m) * ((z-m)·d)/sigma² + O(delta³)`。

因此有限查询下的 loss 为 `A*delta² + O(delta⁴)`，其中 A≥0。若查询至少覆盖一个对应核导数非零的位置，则 A>0，小的非零裂缝给出正 loss，并有 `delta * dloss/ddelta > 0`，梯度下降沿这一参数方向促使裂缝闭合。对完整闭合夹具扰动某张自由面，也可用零点附近 `||J*delta||²` 作同样的局部分析；需要该扰动的 J 非零。

该结论不是任意裂缝、任意查询、任意远距离下的保证。例如所有查询都在上述两中点的垂直平分面上时，两核相等，这对分开的边仍完全抵消。查询远离边且 sigma 很小时，场也可能数值极小。有限查询的盲区和公式的局部性需保留，不能通过看输出后重新选查询把门禁变成必过测试。

最小梯度证据应同时报告 `L(0)`、`L(delta)`、`dloss/ddelta`，或 `grad_X L · (X_closed-X_gap) < 0`。它证明夹具选定闭合方向有利，不证明每个顶点梯度都指向其 GT，也不证明训练后自动水密。

## 5. 相反法向重叠是公式自身的精确反例

取任意非退化三角形 T。两张预测三角形完全重合，但其可信 GT 参考法向分别为 +n 和 -n；例如参考来自原本位于薄体两侧、彼此分开的目标面。按规定对齐后，第二张的每条半边恰好是第一张的反向半边。

于是对任意查询和任意 sigma，每条边都有相同中点和核值，故

`B_T(z) + B_reverse(T)(z) = 0`。

没有其它场时，两个尺度 loss 都为零，且 `grad loss = 2*B*grad B = 0`。两张三角形各自面积可以很大，此反例不需要退化、下溢、特殊随机种子或稀疏查询。把这种反向重叠对加到任意已有零场的表面上，整体仍为零；加到非零背景场上也不会改变 loss 值，但不据此断言所有独立顶点梯度为零。

若两张面的可信 GT 法向同向，方向对齐会使它们同向，此时场相加而不是相消；在能看到单张面非零场的查询上，重复面不会通过这一抵消方式得到零损失。**同向子例通过不能替代相反法向子例。** 相反法向子例不是数据绕序错误：其 GT 参考本身可以合法、一致且来自闭合薄体的两侧。

所以：恢复 raw 朝向能修复不正确的内部边抵消，但不能修复上述反例。两个 sigma 或增加 R 也无法消除逐点为零的场。该 loss 测量一个平滑有向边界场，不是表面嵌入、自交、重复覆盖、面间分离或流形性的充分判据。任意额外闭合有向分量本身也有零边界场。

## 6. 最小固定夹具建议及判读

1. **非均匀闭合网格**：不等边四面体，原始一致朝向，C 取其中一面、自由区为其余面。固定查询，检查两个尺度和总 loss。同步 face/S3 标签重排后复核。若失败，先查共享边、raw 朝向、标签映射和归一化，不先改公式。
2. **直角立方体**：12 个共形三角片、原始外向朝向；选一侧两三角片作 C，其余自由。C 内部对角线须消去，只留下其外边界。直角不应引入物理残差。
3. **小裂缝**：在前述闭合夹具上，沿预先固定的方向小幅移动一个自由面，使用预先固定的查询。报告正 loss 和该扰动参数的闭合方向梯度；同时保留查询对称或远离造成盲区的限定，不把局部证据外推。
4. **平行重叠，必须两子例**：相同非退化重叠几何，分别使用同向 GT 参考和相反 GT 参考。前者测试方向对齐，后者测试公式零空间。后者按原式应得到精确抵消意义下的近零 loss/梯度；若门禁要求“不应抵消”，必须如实标 FAIL，而不是删除该子例、改 sigma、换种子或补正则。

本审查不替代 root 执行的 CPU 四门禁，也不提前报告它们的实测结果。若门禁因第4反例失败，能得出的结论是原式不具备所要求的排除错误抵消保证；这不等于证明它在任何训练中都无效，更不构成跳过门禁启动训练的理由。
