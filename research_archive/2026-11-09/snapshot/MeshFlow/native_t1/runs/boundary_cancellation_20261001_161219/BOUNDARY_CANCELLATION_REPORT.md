# Localized Boundary Cancellation：CPU 门禁报告

**结论：`FAIL_PRE_GPU_GATE`。原式已经实现并完成 CPU 数值基准，但没有满足进入 GPU 的必要条件。没有执行梯度系数标定、模型前向、500 步训练或新完整生成。**

这不是模型级新上下文性能的阴性结论：`G_Boundary` 尚无训练终点，不能报告它相对 L0 的 RMS、Gamma 或 FF 变化。当前停止依据是用户要求的 CPU 门禁失败，尤其是第四项出现可解析证明的假抵消。

## 实现与固定解释

- `tau` 为带长度的有向边向量，已按用户明确回复实现。
- 每张 free 面的三个半边按预测法向与可信 GT 法向内积的符号定向，严格沿用 `<0` 才反向；没有改写法向、加抖动、加 epsilon 弹簧或投影。
- 固定 C 通过可信源索引提取有向边界；C、GT 参考法向、空间查询及 bbox 全部 detach。
- 每例 64 个查询，使用独立 CPU RNG seed20261001，在固定 GT 的轴对齐 bbox 内均匀抽取。未根据模型输出选择查询或更换种子。
- 两尺度固定为 `0.05 L`、`0.10 L`，对各尺度 `mean_z ||B_sigma(z)||²/L²` 取算术平均。tau 已含边长，没有再次单位化。
- 门禁用 CPU FP64；损失实现接受 FP32/FP64。没有使用 GT 作为生成器输入；GPU 模型接线尚未进入。

### 裂缝的梯度确实可能走错方向，但要限定测试含义

固定双三角片的原始裂缝宽度为 `0.01414213562`。共享端点梯度沿“扩大缝隙”方向的两个投影为 `-0.001569713`、`-0.007865526`，因此负梯度方向扩大缝隙。一次预先固定尺度的**坐标梯度探针**后：

- loss：`0.03183374143 → 0.03182627151`；
- 对应共享端点的 gap RMS：`0.01414213562 → 0.01415494619`；
- 整面平移方向的 autograd 导数为 `-0.015890880256`，有限差分为 `-0.015890880265`，绝对差 `9.22e-12`。

这是直接几何坐标的诊断位移，不是模型或 optimizer 更新。该双三角片仍有开放外边界，测到的是外边界与裂缝共同贡献的梯度，不能称为隔离裂缝项，也不能单凭它断言完整闭合物体训练一定恶化。它仍未满足本次指定的字面门禁。下面的反向重叠反例不依赖此限制，已足以阻止 GPU 阶段。

### 反向重叠是公式本身的零空间

让两张非退化预测三角形完全重合，而各自可信 GT 法向分别为 `+n` 和 `-n`。GT 本身可以是薄物体两侧原来分开的面，并非错误法向。对齐后，每对重合半边具有相同中点、相同 Gaussian 权重、相反的边向量：

`k(z,m) tau + k(z,m) (-tau) = 0`。

因此对**任意查询位置、任意 R 和 sigma**都有 `B_sigma(z)=0`，平方损失和坐标梯度也为零。实际 FP64 残差仅在舍入量级。不能通过增加查询数、修改 lambda 或调大/调小 sigma 修复这一反例。

同一固定测试中，将这两张面略微分开，loss 为 `0.0002169711`；沿分离距离的导数为 `+0.0302020211`，负梯度会减小分离距离。说明反向双层可以被吸向重合，而不是被排斥。

低边界流残差不等于无重叠、无自交或流形。当前证据也不证明该项在任何训练中都不可能有帮助；它证明的是**原式不能满足本轮要求的防假抵消门禁**。未据此添加任何新损失或补救项。

## 真实 chair 的朝向检查：另一个问题，已与公式问题分开

两个原始源网格各有 112 面、168 条共享边，均为反向双关联，边界和超二关联为 0。归档角排序使每个父对象的 56 张面发生奇置换：

| 父对象 | 归档中同向共享边 | 直接归档法向的 oracle loss | 恢复源 GT 朝向后的 oracle loss |
| --- | ---: | ---: | ---: |
| P0 | 108 / 168 | 0.08024498293 | 5.7590e-33 |
| P1 | 114 / 168 | 0.07443810355 | 3.0941e-33 |

源面 ID、canonical-to-raw face 映射与角排列能恢复原始朝向。CPU oracle 已使用该恢复链；坐标逐字节保持，原数据没有修改。只用归档当前 `cross` 当作 GT 参考，会把角排序问题错误带入 loss。

C 内部边的省略要求其一致定向的双关联正确抵消。实现记录同向双关联和超二关联；真实源审计及恢复后的合法 fixture 满足这两个计数为 0。`archive_naive` 专门展示违反该前提的无效输入，不能把它当作可训练目标。

恢复朝向能解决数据准备问题，**不能消除反向 GT 法向重叠的零空间**。源边方向一致也不能单独认证无自交、顶点流形性或全局朝外。
