四、在原attention内部实现，不另建ControlNet主干

先确认本地实际EquiDiT路径，不能机械套用公开仓库版本。

预期结构是：
角特征池化为面特征；
面级全局self-attention；
面消息广播给三个角；
原后续角级处理。

保留原Q/K/V、QK归一化、AdaLN、attention输出投影、
role/time处理、FFN及其顺序。

本轮固定只在4个均匀深度位置启用关系修正。
若主干有L个兼容块且L>=4，使用1-based层号：
ceil(L/4)、ceil(L/2)、ceil(3L/4)、L。
登记实际模块路径与层号。
不根据结果增加或移动注入层。
若本地结构与此不兼容，明确报告，不另写一套替代主干。

设：
i是接收面；
a是该面三个角之一；
j是源面；
h是attention head；
ell0[i,j,h]是原attention实际内容logit；
v[j,h]是原value；
R[i,a,j]仅对free角、known源面定义。

新增模块的语义：

ell[i,a,j,h]
  = ell0[i,j,h]
    + 1[i为free且j为known] * b_h(R[i,a,j])

w[i,a,:,h]
  = softmax over 全部有效源面j of ell[i,a,:,h]

message[i,a,h]
  = sum_j w[i,a,j,h]*v[j,h]
    + sum_{j为known} w[i,a,j,h]*u_h(R[i,a,j])

再经过原attention输出投影、原gate及残差路径。

要求：

1. 原全局known/free通信保留。
2. softmax分母仍包含全部有效源面，不另做只对known归一的cross-attention。
3. 新修正只作用free←known。
4. 三个free角可以因不同R获得不同消息。
5. known查询行不加新修正。
6. 不把几何消息直接当坐标更新，不做最近点吸附或投影。
7. 原始完整C角坐标和既有Geo路径在全部实验臂保留。
8. 不添加固定角编号、固定面编号或GT对应。
9. 不添加自由面法向、硬kNN、额外终点预测或时间开关。

每个启用层使用：
R维度11；
Linear(11,32) → SiLU → Linear(32,H+D)。

H是实际head数，D是该层value总维度。
前H维输出各head的logit修正；
后D维输出分head的pair-specific value修正。

最后一层weight和bias均初始化为0。
第一层正常初始化。
MOMENT_XY与SURFACE_XY对应新增张量逐位相同。
不要再叠加一个初始化为0的外层乘法gate。

零初始化在数学上恢复原attention：
b=0、u=0时，三个角得到原面级广播消息。
它不保证训练后质量不下降。

普通SDPA不直接支持query-dependent pair value，
不能把u[i,a,j]误塞成只依赖j的标准V。
必须实现上述数学定义并做前向、梯度对账。


五、统一11维几何关系

所有几何计算使用FP32；FP64只作小规模参考。
不在BF16中计算距离、logsumexp或协方差。

用现有固定Gaussian先验尺度定义单位：
若sigma_Z=1，直接使用当前模型坐标。
若实际先验是标量sigma_Z≠1，
仅在关系计算内部统一使用x'=x/sigma_Z、C'=C/sigma_Z。
该缩放是全局已知常数，不是每物体或每条件重归一化。
真实模型坐标和C保存字节不变。

以下公式中的x、y均指这个共同关系坐标。

固定：
s(t)^2 = (1-t)^2 + 0.1^2。

0.1是本轮冻结的关系带宽下限，不是新增采样噪声。
训练和推理使用同一关系定义。
不按alpha、GT宽度或物体尺寸调整带宽。

A. MOMENT_XY

已知三角形顶点y1,y2,y3：

c = (y1+y2+y3)/3

Sigma_uniform
  = sum_a [(ya-c)(ya-c)^T] / 12

mu = c
Sigma = Sigma_uniform
z = -||x-c||^2 / (2*s(t)^2)

B. SURFACE_XY

在同一个已知有限三角形内部使用固定正权重对称求积：
节点y_r，权重a_r>0，sum_r a_r=1。

logk_r = -||x-y_r||^2 / (2*s(t)^2)

p_r = softmax_r(log(a_r)+logk_r)

mu = sum_r p_r*y_r

Sigma = sum_r p_r*(y_r-mu)(y_r-mu)^T

z = logsumexp_r(log(a_r)+logk_r)

这里没有t*y。
这是每张三角面内部归一化的表面查询，
不是整个C的全局核回归，也不是把每个求积点当成新attention token。
known源token数仍为K，不变成K乘求积点数。
不额外加入log面积偏置或面积加权attention。

两臂统一输出：

R = [
  mu-x的3维；
  Sigma的6个独立分量：
    xx, yy, zz, xy, xz, yz；
  log1p(max(-z,0))；
  t
]

共11维。

MOMENT_XY的均匀协方差用解析公式。
SURFACE_XY使用同一格式的加权协方差。
两臂的区别仅是几何关系统计，不是新增网络容量。

求积固定为192点：
参考三角形等分为8^2个小三角形，
每个使用三个局部重心点：
(2/3,1/6,1/6)及其三个不同排列。
总计3*8^2=192点，等正权重1/192。
必须核验节点集合在六种corner排列下对称。

本轮把192点版本当数值参考级候选。
不声称这是高效部署版本。
不在结果出来后换成48点或768点重训挑选。
若192点无法通过准确度或成本门禁，停止正式三臂训练并报告阻塞。

退化三角形：
数值单元测试可使用归一化重心推前分布的有限延拓；
不要将零面积退化面称为合法面积表面。
正式数据继续遵循原几何合同，不为本轮悄悄更换数据。


六、避免不必要的显存与计算放大

每次模型forward，根据当前F_t和C计算一次R，
供4个注入层共享。
不能在4层重复计算三角积分。

同一次Euler50中，C的求积点、均匀质心等静态量可缓存。
F_t和t相关的权重、mu、Sigma、z每个采样步必须重算。
不同alpha的C不能误用同一缓存。

按query和known维度分块。
不构造完整[B,3F,K,192,3]大张量。

也不要构造完整[B,3F,K,D]的高维pair value。
因为最后一层是线性的，可以严格等价地重排：

phi_iaj = SiLU(A*R_iaj+a)，维度32；

b_iajh = B_h*phi_iaj+beta_h；

u_iajh = U_h*phi_iaj+gamma_h。

于是每head的额外消息可计算为：

U_h * sum_{j为known}(w_iajh*phi_iaj)
+ gamma_h * sum_{j为known}w_iajh。

这样避免展开D维pair value。
这是原MLP的精确代数重排，不是新的低秩近似。
必须在小样本上与字面实现核对前向和参数梯度。

各层phi依赖该层参数，不能跨层错误复用。
共享的是纯几何R。

任何attention重构都必须保留原mask语义、QK归一化与gate。
如为了统一后端而改变了H_CONT的数学等价载体实现，
必须在训练前核对原函数和梯度，并在三臂一致使用。
不把后端变更造成的差异写成几何机制收益。
