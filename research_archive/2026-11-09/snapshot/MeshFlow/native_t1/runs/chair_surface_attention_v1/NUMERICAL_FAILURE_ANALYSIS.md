# 数值门禁失败分析

本次复核未发现公式、192 节点构造或冻结 fixture 坐标单位与任务定义不一致。生产规则的数值门禁仍未通过，正式训练已阻断；本报告不改变原始数值或门禁状态。

复核只读取原 CSV、NPZ 和源码，另做表格汇总及输入三角形尺度测量，没有重新计算关系、求积、OT 或模型输出。本次文档修正仅修复编码；乱码原件保留在 `postrun_review/originals/NUMERICAL_FAILURE_ANALYSIS.initial.md`。

192 点来自 64 个等面积小三角形，每个小三角形使用重心坐标 `(2/3, 1/6, 1/6)` 的三个排列，权重均为 `1/192`。整数节点复核确认六种角点置换闭合，并满足一次、二次均匀三角形矩。实际门禁调用为 n8/FP32、n64/FP64 和 n128/FP64，点数分别为 192、12288、49152。

四个 fixture 的 C 和 free 终点均与原 model target 按原面索引、角点排列映射后逐位相同。保存的训练路径查询及探针也可由保存输入逐位复原。原 pre-OT 坐标乘 2 正好等于 model target；关系模块使用该最终模型坐标，sigma_Z=1，没有再次乘 2 或做父级 bbox 归一化。已知三角形最长边可达 5.3153，n8 小三角形最长边为 0.6644；t=1 时 s=0.1。

普通比较共 7504 对，任一分量达到或超过 0.01 的有 1459 对；均值、协方差、压缩质量分量分别失败 1446、5、310 对。极端远点另有 1072 对，按协议单列，不进入普通数值门禁。

参考精度仍有限制。这里的 192 对 12288 点差异是两种数值求积规则之间的差异，不能称为已认证的真实积分误差。96 个预注册参考子集对中，ordinary_40、t=1、query 0、known 41 的 n64 对 n128 均值差异为 0.0011148664959007117，超过参考阈值 0.001。其余三个 fixture 的子集通过，不能证明全部普通比较对或整个空间的参考均已收敛；参考未完全收敛也不能据此宣布 192 点通过门禁。

`numerical_failure_analysis.json` 保留 80 个 fixture/t/query 类汇总、逐分量失败位置、268 个 C 三角形的输入坐标及尺度，以及参考失败位置。失败比较对的“小三角形最长边/s”中位数为 1.692113037895886，通过比较对为 0.41046548234374186；这是描述性关联，尚不能作为因果结论。

唯一优先后续假说是：晚 t 的高斯核较窄，大三角形上的 n8 网格欠分辨，导致当前主要差异。下一项独立授权的离线检验应保持同一冻结 C、查询、t、sigma 和带宽，先建立误差受控的独立参考并认证参考误差小于 0.001，再检验保存的 192 点差异是否仍超过 0.01，并与小三角形最长边/s 的尺度关系一致。若认证参考支持 192 点而与 n64 不符，或独立审查发现公式、尺度错误，则该假说不成立。本轮只提出该检验，没有执行，也没有启动训练或修改数值设置。
