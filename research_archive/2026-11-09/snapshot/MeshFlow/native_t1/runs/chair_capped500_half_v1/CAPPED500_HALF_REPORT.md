# CAPPED500 半幅权重实验报告

任务：`CHAIR_CAPPED500_HALF_AMPLITUDE_PILOT_V1`。执行日期：2026-10-07。独立目录：`native_t1/runs/chair_capped500_half_v1`。

**结论：半幅确实保留了一点平均接合收益，也修复了部分历史 CAPPED500 的覆盖误差和坏例；但没有得到稳定、更优的综合折中。继续保留 START，不晋级 HALF。**

这个结果不支持“把改动缩小一半就能兼得”的简单解释：有些距离下降，反向距离却上升；有些长薄片消失，又出现新的座面叠置。它也不证明所有插值比例都无效，本次只测试预先固定的 0.5。

## 实际做了什么

将历史 CAPPED500 相对 START 的完整参数改动缩为一半：`theta_half = (theta_START + theta_historical_CAPPED500) / 2`。对应 FP32 参数在 CPU 用 FP64 求均值，只转回 FP32 一次。全部194个参数张量、130401155个参数都纳入，包括 Geo 与 role embedding；实际没有注册 buffer。没有插值 AdamW、RNG 或输入流，保存的是独立推理权重。

实际参数差范数从4.54962742147变为2.27481371007，比值0.499999999854；最大单元素舍入1.1920929e-7。独立 CPU 复算与保存后 strict load 的模型状态 hash 相同。

| 项目 | 实际执行 |
|---|---:|
| 新完整 Euler50 输出 | 32/32，全部成功 |
| 新模型前向 | 1600/1600，每个输出50次 |
| 训练更新、反向、optimizer更新 | 0、0、0 |
| 重抽噪声、额外 alpha、重试 | 0、0、0 |
| 原 START / 历史 CAPPED500 结果 | 64条逐例核验复用，未重新生成或评分 |
| 最终配对范围 | 3模型 × 8父 × 4固定噪声 = 96条 |
| 失败或未闭合模型调用 | 0 |

OLD为n0/n1，FRESH为上一轮已实际评过的n2/n3；本轮两组都是已经观察过的DEV材料，**FRESH这个历史名称不代表本轮新的独立确认**。没有读取新父确认集，也没有扩展实验矩阵。

推理沿用原50步Euler、BF16 forward、FP32参数与积分、严格确定性、TF32关闭、math SDPA，以及C每一步硬保持。模型输入和噪声均来自原冻结NPZ，未作几何后处理。

**OLD f596是新的重要接口风险。** I父均比START和历史CAPPED都增加22.1436pp；n0/n1相对START分别+9.2285/+35.0586pp。E比历史CAPPED下降34.1220pp，原保守界限为[−34.2271,−34.0431]pp；E相对START却仍增加37.2766pp，两个参照不能混淆。这已触发旧定义下的严重单父代价描述线，没有为本次新增晋级阈值。

## 实际网格审阅

图集包含完整96个输出，同父相机覆盖全部三模型和四噪声；四个视角加wire，另附原评分向量的S/I/E图。蓝色为未修改的C，橙色为自由面。逐例AI记录位于`visuals/reviews/`，最终覆盖核验位于`audit/visual_review_complete.json`；这是AI图像审阅，不是人类可用率或力学测试。原渲染manifest中的PENDING是渲染当时的状态，最终审阅账本另存，不回写冻结的渲染原件。

确有局部恢复：c1b8 OLD n1的长悬片与尖刺减轻；bdd2 OLD n1历史CAPPED的大块落地三角薄片在HALF消失；86ec FRESH n3的长悬垂片也消失；341b FRESH n3的历史CAPPED主体碎裂明显减轻。

这些恢复没有覆盖全部风险：534b FRESH n2仍然严重短腿、低背，未恢复与固定输入匹配的完整支撑；n3虽部分闭合历史CAPPED背部裂口，悬片与座面错位仍在。c1b8 FRESH n3出现更明显的座下三角薄片；866e FRESH n2的前伸尖片比历史CAPPED更突出。

f596 OLD n0尤其直观：橙色生成座面抬到蓝色输入座片上方，形成双层结构和大斜侧片。C确实原样存在，但它没有自然成为最后椅子的那一层座面。n1主体仍是完整、可辨认的扶手椅，I图却出现新的大片重复/冲突标记；不应把这个问题误述为主体整体崩溃。接合得分升高不能单独保证输入被正确融入。

## 决策与交付

半幅可保留为有局部恢复的诊断权重；现有证据不足以把它列为更可靠的正式选择。下一步若继续，优先检验“改善接合的更新能否同时保持主体，并避免把C附近做成重复座面/薄片”，而不是继续假定缩小整体幅度就会单调改善。检验假说应要求收益跨父、跨固定噪声保留，同时消除这里的接口和主体尾部；本实验并未定位具体训练机制，也未自动启动该后续工作。
