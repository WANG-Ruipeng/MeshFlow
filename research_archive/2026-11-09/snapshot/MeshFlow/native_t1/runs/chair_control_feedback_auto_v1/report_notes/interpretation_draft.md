# 报告解释草稿：等待 H3 终点，不是最终结论

这轮实际研究把反馈作用于训练：START 从固定 Gaussian 完成 Euler50，再用 S/I/E 三个独立困难队列选择训练父内的真实轨迹，额外监督真实晚期状态到训练 GT 的剩余位移。没有把 CPU 评分浮点数冒充可微损失，没有使用 DEV/CONFIRM 几何作训练目标，也没有把模型自己的终态当成正确标签。

三个层次必须分开：C 在输出中的精确保留是实现硬约束；free 与 C 的接合、冲突及外露是实际生成能力；全椅主体合理性又是独立限制。C 保留通过不等于后两层通过，较高 E 也不等于主体完整。

H1 的正面证据不能抹掉。原回放辅助 MSE 在固定槽位上显著下降，而且在原训练反馈池上的真实 Euler50 的 S/I/E 都有均值改善。相对 START，S 增加 21.1476 个百分点，I 降低 1.1902 个百分点，E 增加 3.4917 个百分点。相对同队列的教师额外监督，S 增加 7.9714 个百分点、I 降低 3.6072 个百分点、E 增加 2.8815 个百分点；但 S 只有 3/8 父有利、中位数为 0，不能称广泛一致。此面板本来参与反馈和梯度，只是训练内学习证据。

H1 在 DEV 的方向不同。1000 步相对教师 S 下降 4.6770 个百分点，I 降低 0.9613 个百分点（6/8 父有利），E 增加 8.8078 个百分点（5/8 父有利）。S 牺牲超过冻结容限，I 未达到 2 个百分点门槛。相对 START 的 Dsym、512 MSE 分别退化约 13.40%、17.06%；即使相对教师 MSE 改善约 16.8%，仍过不了双参照质量约束。部分父的 E 增益集中，不能以均值描述全部 8 父；最终以逐父贡献、留一父结果和两噪声完整表为证。

训练诊断支持有限的 H3 检验，不支持机制定论。H1 辅助梯度真实存在，41 次原反向的观测中辅助/主 FM 梯度范数比中位数约 2.823，夹角余弦均值约 -0.0137；23/41 负向，1000 步有 85.5% 触发 clip。教师对照辅助梯度比中位数约 0.0729、clip 1.8%。这提示辅助强度与目标冲突是可检验因素，但 stale 轨迹、仅 8 个反馈父和终态 GT 对应变化也可能造成训练内收益不迁移，不能只凭相关诊断宣称唯一原因。

H3 从同一 START 独立开始，冻结为 loss-value cap：lambda_eff=min(0.1, detached_primary_FM/max(detached_aux_MSE,1e-30))。它不是梯度范数上界，也不是新的接合几何目标。辅助目标、队列和主 FM 样本与 H1 相同；与 H1 比较仅系数规则不同。对教师 1000 步的完整已执行路径验证表明限幅在每一步都严格不活跃，因此该路径是本探索流的精确匹配教师对照；这不证明新的独立训练流也不触发限幅。最坏步保守相对余量仍超过 92.48%，并保留逐步反事实表与完整权重身份绑定。没有宣称额外训练了另一条教师路径。

真实回放的规模比“16 条生成轨迹”更窄：全部 16 条原始生成和分数保存，但困难队列实际选择 12 条，覆盖 8/8 父；4 个父两个噪声都参与，4 个父只选到一份噪声。t=0.6/0.8 只有 24 个独立的状态/目标组合，48 个队列位置包含重复。早晚各 96 次辅助损失比较覆盖所有位置，但不是 48 个独立训练状态。冻结池没有根据本轮中途 DEV 换目标。

对图像的解释遵循完整比较而非挑例。341 noise0 在 1000 步的 FM 和教师对照同样明显退化，所以该坏例不能全部归咎于轨迹回放；341 noise1 的 TR 相比教师和 START 仍有新的明显主体破坏。866 的圆孔靠背恢复也出现在两种对照，不能全部记为 H1 独有收益。c1b 的两噪声有不同局部代价，f596 有主体和外露改善同时伴随新薄片。视觉检查是 AI_VISUAL_REVIEW，human usability 始终 NOT_RUN。

本轮沿用原独立三指标，不构造总分。S/I 适用性与 E 的 PARTIAL、参考可见域不确定性保留原定义和保守区间。即使某个输出的当前 E 命中未决比例为 0，参考域仍可不确定，不能把所有 PARTIAL 改成 PASS。FF 的原受影响 free 比例很高不等于无效，报告原数值和增量，不改阈值、不替换裁判。

工程修复与科学失败分开记录。首次 START 完整 50 次调用后因为保存函数形参重名丢失一个输出，原噪声精确重试一次，原调用和重试全部计账。三个原探索分支完成后 CPU 图库缓存的 tuple/list 比较错误导致控制器非零退出；只修复 JSON 语义比较，未重新训练或采样。C、输出非有限或模型数值失败不属于可以静默重跑的工程问题。


H3 中限幅活跃时，weighted auxiliary 的数值约等于 detached 主 FM，这是公式造成的恒等关系；不能把其下降当成独立辅助拟合证据。由于系数作为 Python 标量 detach，梯度仍是 lambda_eff 乘未加权辅助误差的真实梯度；其可达性用原额外反向的叶子 hook 核验。H3 的学习变化应报告 unweighted auxiliary、同状态早晚比较及真实 rollout，不能用被人为限幅的曲线冒充控制改善。
