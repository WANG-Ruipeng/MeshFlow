# HOLDOUT_FINAL_EVIDENCE

三臂固定 5000 步的已观察留出回归均已实际完成，每臂 32/32 生成与评分有效，并严格复用各自源 1000 步的 32 个历史 raw。父对象等权后，三臂 remainder RMS 均略高于各自 1000 步，GT 的 1% L 覆盖略有提高，FF 非法相交受影响自由面比例均升高。结果呈现收益与代价，不能据执行 PASS 宣称留出质量整体改善。

该集合是原 Session C 已评价过、未参与本次条件微调的 8 个父对象，各父 2 条件×2 噪声。它应始终称为“已观察留出回归”，不能称为全新确认集。这里只比较预先固定的 1000 与 5000；没有用中间留出 checkpoint 选择终点，也没有增补样本、求解器扫描或历史重生成。

严格核验包括：源三臂 1000 checkpoint 的文件字节 SHA256 与原 handoff、原评价身份相同；8 个评分器源文件的 SHA256 与源登记相同；96 个历史 raw 与原 ledger/score 身份匹配；96 个新 raw 和 score 文件哈希与新 ledger 匹配；两端输入均指向原 Session C 实际数组。旧 raw 的 51 帧已知 C 逐位保持，并与新端点 C 相同；新评价账本亦有 51 次 C 保持证据。

原 holdout bank 的 z 在已知槽为零，因此实际初态是“z 的自由部分加写入的 C”，而非未经写入 C 的整个 z。已逐例核对原 states[0] 等于这个实际初态，新 raw 保存的 noise 逐位等于该冻结 z。身份 JSON 保留了最初 CPU 比对错误及修正定义，源数据没有错误或修改。根目录刚刷新的 `holdout_regression.csv` 的 96 行、38 个指标及其两端值/差值全部与原评分 JSON 对应一致。

本阶段新生成为 96，sampling forwards 为 4800；旧 96 只复用，不能再次计入新增生成。没有为本分析运行模型、OT 或评分器，也未修改冻结代码、科学输入、原评分、根报告。此处“评分有效”指可以使用原指标，不是工程几何质量通过。

本轮固定预算的已观察留出回归结论是：覆盖有小幅提升，CF 有改善，remainder RMS 没有总体改善，严格接合与 FF 相交仍明显不足。这里不添加临时质量门槛，不追认新的模型选择规则，也不据这些结果延长训练。
