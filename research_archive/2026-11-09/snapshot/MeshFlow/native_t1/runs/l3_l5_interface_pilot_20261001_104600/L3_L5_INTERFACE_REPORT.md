# L3_L5_INTERFACE_REPORT

这是五个固定终点、六个已见parent/patch单元、每单元4个新噪声的匹配探针；没有开发排名、选择后补位或历史分数拼接。只新增J35/JEdge5各500更新，不自动切换默认模型。

1. **原L3/L5组合是否比单项更实用？** 没有达到预设的组合成功信号。J35相对L5，剩余RMS由1.05710%降至0.96483% L（−8.73%），Gamma RMS由1.02523%降至0.92341% L，Gamma覆盖率从24.16%升至31.92%；但FF平均65.96→84.29对（+18.33，+27.80%，配对中位+26.5，仅6/24下降、5/6单元均值变多），CF也9.63→11.08对。相对L0，J35仍多11.75对FF。它是更贴近表面的另一种取舍，不能称比单项更实用的全面组合。固定系数交互I：RMS −0.05410个百分点L、Gamma RMS +0.00445个百分点L、p95 +0.25661个百分点L、FF +19.96对；不能从局部负交互宣称纯机制协同。

2. **L5减FF的方向在新噪声上是否保留？** 本批保留了L5减FF的方向：相对L0平均72.54→65.96对（−6.58，−9.08%），配对中位−11.5，17/24输出下降、4/6单元均值下降；P1原片反而+9.25对，P0 patch2 +0.25对。L5的Gamma覆盖率宏值下降1.41个百分点，窄角<5度比例21.83%→22.71%。因此这是有重复但不普遍、也不等于全面质量提升的信号。

3. **D_edge替换L3是否真正改善接口？** 以D_edge替换L3后，完整生成出现真实但不均匀的改善。JEdge5相对J35：剩余RMS 0.96483→0.87157% L（−9.67%，15/24改善）；Gamma RMS 0.92341→0.76019% L（−17.68%，13/24改善）；p95 2.22570→1.70377% L（−23.45%，15/24改善）；CF 11.08→9.42对、FF 84.29→67.58对。相对L5，剩余RMS −17.55%，六个单元均值都下降、18/24改善，Gamma RMS −25.85%。但是P0相对J35的平均剩余RMS 0.52760→0.59582% L、Gamma RMS 0.52442→0.53833% L均恶化；P1改善更明显。P1 patch2对Gamma宏净改善贡献约97.8%，不能解释为各单元均匀收益。没有D_edge-only臂，结论只适用于当前固定L5背景。

4. **改善有没有转化为覆盖/CF/FF/尾部的新代价？** 有明确代价。JEdge5相对J35的Gamma严格覆盖率31.92%→26.97%（−4.95个百分点），仅7/24改善；P0 patch2四个噪声的Gamma覆盖全部下降，均差−26.85个百分点，剩余RMS +0.40795个百分点L、固定目标1%覆盖−10.69个百分点。另一方面，CF宏值和六单元均值都低于J35，FF宏值也降低。相对L5，JEdge5仍多1.625对FF，P0三个patch的FF均值都增加。全120输出没有NaN/Inf、近退化、共面重叠或UNRESOLVED；但仍有大量非法FF相交，精确C-free共边/共顶点均为0，不能称水密或拓扑合法。最坏Gamma p95仍8.74% L（L0为8.70%），宏尾部改善未消除最难输出。C继承的0或2个link异常单列。

5. **哪个结果值得保留，哪些只是局部信号？** 值得保留JEdge5作为下一次固定配方验证的候选，同时保留L5的较低FF参照和L0基线；不自动切换默认模型。J35保留为“teacher和覆盖收益、相交代价”的机制对照。五终点teacher上J35的FM/L3/L5/D_edge均值最好，而JEdge5相对J35四项分别差+60.87%/+21.08%/+25.53%/+24.48%，其完整生成平均误差却更低，说明teacher排序不能代替自由采样。所有模型绑定均12/12双向为正，这不是新候选独有的增益。
