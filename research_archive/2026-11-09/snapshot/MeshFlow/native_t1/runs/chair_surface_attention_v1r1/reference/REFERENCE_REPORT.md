# 独立积分参考：固定八例复核

固定八例的独立参考全部达到预注册的两档精度自洽要求。三个原最坏普通比较对，以及原 n64/n128 不收敛对，使用独立参考后仍有 192 点误差超过 0.01；四个低 t 对照的全部分量差异均小于 0.000021。这支持“晚期窄核相对三角形子网格欠分辨”的后续假说。八例为既有失败分析后的固定诊断样本，不能据此估计全部任务的失败率。

本参考没有修改原模型、候选求积规则或原门槛。协议、输入与源码在执行前已冻结；实际执行 18 次合成积分、16 次真实积分和 24 次原规则 CPU 调用，无模型调用、OT、训练或采样，没有重试。

方法将三角形映射为 Duffy 方形：

`y = A + r(C-A) + (1-r)w(B-A),  r,w ∈ [0,1]`。

三角形面积归一后的积分测度为 `2(1-r) dr dw`。SciPy 1.15.3 的嵌套自适应 Gauss–Kronrod 21 点积分同时计算质量、一阶矩和二阶矩，独立于原均匀三角格。以查询到三角形最近点为中心计算矩，并提出最近点的高斯指数因子，避免远点下溢及原始坐标二阶矩的消减。几何断点只由冻结输入、带宽和预注册倍数决定，未依据结果修改。两档相对容差固定为 1e-8 和 1e-10，绝对容差为各自相对容差的 1e-6 倍。

原 n64 参考在原均值最坏例的均值差为 0.003285883，在原参考不收敛例为 0.001291298，均超过 0.001；对应 n128 差降至 0.000291035 和 0.000176431。八例中 n128 的各分量差均小于 0.001。这进一步限制了将旧 n64 差异称为真实积分误差的做法，同时保留了原 192 点门禁失败的主要结论。

两档独立参考的最大均值 L2 差为 2.220446049250313e-16，最大协方差差为 4.071429686791025e-17，压缩质量差为 0，均小于冻结要求 1e-5。紧容差下最大估计相对质量误差为 2.252026833727766e-10，传播后的最大分量误差估计约 6.86e-9；已单独记录小质量归一的放大。SciPy 误差估计、采样到的内层最大误差及两档一致性都不是严格数学误差界，不能称为严格认证。部分两档积分使用了相同的自适应划分，因此接近机器精度的一致性也不是独立证明。

合成测试覆盖角点六排列、刚体变换、可解小三角形均匀矩极限、窄核近边角、远点、细长面、共线与重合极限；18 次积分共 805749 个核点评价。真实 16 次积分共 666876 个核点评价，全部低于逐次 1000000 点和 120 秒预算。原规则单对重算与旧多 known 分块计算之间最大差异为 4.72e-7，属于已披露的 FP32 归约差异；旧 CSV 保持原样。
