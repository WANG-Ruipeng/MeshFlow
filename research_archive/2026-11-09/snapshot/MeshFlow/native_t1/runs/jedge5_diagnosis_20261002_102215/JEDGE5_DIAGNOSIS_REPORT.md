# JEdge5 工作条件诊断报告

已完成全部固定预算并停止。两臂 raw 训练精确重放；数值步长、上下文/噪声依赖和 EMA 的分指标变化均影响结论。当前未建立 JEdge5 跨这些条件的稳定优势，也没有证据把问题唯一归因于架构冲突、普遍梯度冲突或缺少 EMA。

本轮按 A→B→C→D 执行。两个已见父对象、十个已观察上下文，固定新生成噪声 10401/10402；patch0 是原微调条件，patch1–4 是已见对象上的其他上下文。两噪声不能支持显著性、尾部概率或新对象泛化声明。

严格确定性、TF32关闭、SDPA math、FP32参数与积分保持。BF16/50独立入口与原生产采样器的51状态逐位一致；FP32路径的嵌入、QKV、注意力、MLP和速度输出实际均为FP32。六条同模型后缀恢复整段轨迹逐位一致。历史BF16置换误差沿用 baseline-inheritance，本轮没有重测或把旧FAIL改为PASS。

## Q1：J−B 差距是否依赖步长或BF16？

依赖数值设置，但不是一致优势。50→100 的 J−B 均值差分之差为 BF16 −0.241792、FP32 −0.154935 个百分点；对应中位差分仅 −0.009033、−0.019595。P0 patch4 两 seed 贡献到总体均值的变化分别为 −0.233113、−0.190513，说明宏均值明显受这些案例影响，所有案例仍完整保留。10401 分组在四种配置上均值均为 J 较低，10402 则均为 J 较高。精度差分之差在50步为 −0.038408、100步为 +0.048449，没有统一有利方向。不能忽略采样近似，也不能由100步均值变好推断训练策略普遍更好。

## Q2：较细积分是否收敛？

尚未建立一致收敛。固定第一 seed 四 case 中，100→200 同槽自由坐标 RMS 变化小于50→100的仅 B 2/4、J 3/4。B 在 P0 patch0 的变化由 0.028600%L 增至 1.163191%L；J 在 P0 patch4 由 5.472378%L 降至 0.139849%L，但 P1 patch0 反而由 1.807545%L 增至 3.736844%L。两模型的几何 RMS 在100→200各有3/4改善；坐标增量缩小与几何误差改善并非同一件事。200步只是更细数值参考，不是精确 ODE 真值。

## Q3：前段状态还是后段速度场？

暂不能唯一定位为前段或后段。各切点只有4/12案例在两种来源状态上都表现为 J 后段 RMS 较差；两个来源结论相反的有6/7/6个。P0 patch4/10402 在 t=.2 时，BB/BJ/JB/JJ 的 RMS 为1.02086/1.01097/2.41411/4.52954，J 来源早段状态与后续场均相关；但同 patch 的10401恰相反，BB约5.35593、JJ约0.87197，换用 J 后段仍难修复 B 来源状态。早段来源影响和局部后段影响均有案例支持，方向依赖 seed/patch。J 续跑通常减少 FF，但 RMS 与 Gamma 方向不统一；这不足以证明不可避免的取舍或架构冲突。

## Q4：监督收益是否只在训练C？

不是只在训练 C 获益。活跃区间 FP32 下，P0 其他 patch 的 FM、Edge、L5 和加权联合项均24/24状态改善；但生产 BF16 更混合，尤其 P1 训练 patch0 的联合均值增加约5.29%。明确的 teacher/生成分离例是 P1 patch2：FP32 活跃 teacher 联合损失均值下降12.82%，6/6状态改善；FP32/100 自由生成两个噪声的 RMS 却分别增加0.40205/0.46823个百分点，Gamma p95 均值反而降低1.18380个百分点。不能笼统归因于条件没有学到，也不能把 teacher 改善当作生成必然改善。

## Q5：标量和两种梯度空间是否一致？

三者信息不同，本次不支持普遍梯度冲突。400个 velocity 记录中，FM 与未门控诊断 Edge、L5 及其联合梯度的余弦均为正；实际门控关闭时联合梯度为0，其余弦不定义。Edge 与 L5 仅在同一个 P0 patch2/noise1/t=.9 状态出现3个极小负值，最低−0.00323。8个单层探针均同向，其 velocity 与对应 BF16 teacher 逐位相同、三项损失差为0。FM–joint 余弦在 velocity 空间0.235–0.281、所选参数空间0.524–0.788；joint/FM 范数比分别5.52%–9.52%与1.75%–4.55%。全400状态按 t 的实际联合/FM 比值均值为0、0、42.60%、9.72%、1.45%（.1/.3/.5/.75/.9）；前两时点由原门控严格归零。单层仅2360064个参数，不能外推整个网络长期行为；局部同向也不保证另一模型的 FM 或生成更优。

## Q6：raw重放与匹配EMA对照

两臂均500次更新，raw500 state SHA 分别与原 B/J 逐位一致，训练流起点和500批 hash 均恢复，因此 raw/EMA 可作匹配平均对照。20 case 中 B 的 RMS 由1.42949降至1.37169（13/20改善，配对中位−0.03177个百分点），J 由1.54922降至1.35302（16/20，中位−0.04288）。但 J 均值收益的97.48%净变化来自 P0 patch4/10402 这一个案例，该例降低3.82528个百分点；同 patch/10401反而增加1.29022，最差 RMS 由5.03203增至5.52219。完整20 case 仍为主结果，没有删除案例。B 的 FF 均值71.5→86.6、CF6.95→10.2；J 的 FF74.1→86.2、CF7.3→9.6，J 的 Gamma p95 2.32971→2.64840。J−B RMS 均值差由+0.11973变−0.01867，但 EMA 下 J 仅9/20较低、配对中位差+0.01014，不能写稳健超过 B。固定四 case 中 J 的 EMA3000 RMS 反而高于 raw3000，且未恢复 G0/2750 阶段较低均值，不能把平均效果等同于直接回退早权重，也不能宣称消除了终点劣化。20状态 teacher FM 在 B/J 的 EMA 后均值降低10.97%/16.52%，但 J EMA 相对 B EMA 只4/20较低，均值优势主要来自 t=.1，其余时点的均值均更差。Teacher 和自由采样变化必须分开解释。

## Q7：支持什么，尚不能说明什么？

得到支持的限定结论：所测 BF16 生产对账、FP32 同状态续跑和精确训练重放合同成立；采样近似会改变 J−B 宏均值差，尚未建立一致数值收敛；来源状态、patch 与 seed 共同影响后续表现，无法统一归为单一前段或后段问题；teacher 收益可迁移到其他已观察上下文，但不保证完整生成改善；EMA 会改变结果，且伴随接口尾部和相交代价。尚无支持的是 loss 与架构必然冲突、FM 与几何项普遍反向、缺 EMA 是唯一根因、所有 RMS 退化都必须接受为不可避免取舍。单层与短程相关状态、两父对象和两噪声无法回答普遍机制或新对象泛化；本轮不升级默认模型、不选新超参数。

## 质量、资源与交付

300个正式终点评分（168 A、72交叉后缀、60 D）全部 NaN/Inf 计数为0，按原阈值检测的近退化、零面积、CF/FF unresolved 与共面非法对计数也为0。这不等于拓扑合法：FF 非法对范围29–164、CF 穿刺 pair 范围0–51；小于5度角的自由面比例范围11%–32%，q>10比例0–26%。150个复用输出的绑定四格中146个双方向均为正，4个不利方向完整保留于 binding 表，不能用平均绑定正值掩盖它们，更不能把这些相关 case 当独立成功概率。源 C 继承的精确 link/绕序/共边异常本轮没有追加拓扑认证，保持 NOT_RUN。

CF/FF沿用原独立浮点检测器及阈值，未执行的精确谓词、精确拓扑/水密认证明确NOT_RUN。已知C保持和112面数逐轨迹断言；没有Pair、Stage2、Guidance、焊接或几何修复。条件绑定四格复用输出评分，见 analysis/binding.csv；绑定成立不等于候选有新增质量收益。

GPU并发按首个正式任务实测递增，采样和训练分别估算，预留至少2GiB；详情见 registration/resource_snapshots.jsonl 与 dispatch.jsonl。WDDM下进程显存查询不可得，记录全卡占用增量估计和PyTorch allocated/reserved峰值，未把allocated当完整进程占用。并发时长不是隔离算力基准。网络前向CUDA事件、host时间、显式同步、轨迹保存、CPU OT、训练更新、EMA更新、checkpoint保存与离线几何审计在 timing.json 分账；嵌套计时不相加为总墙钟时间。

固定首seed同视角full/free图见 figures/A_*（全部十个上下文）及 figures/D_*（四个预登记曲线case）；完整边界统一范围，未删除不利案例。代码补丁code.diff、源快照、协议、必要测试和逐case表均在本目录。
