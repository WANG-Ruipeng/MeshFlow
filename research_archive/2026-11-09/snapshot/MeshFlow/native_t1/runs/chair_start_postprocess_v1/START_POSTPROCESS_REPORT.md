# START 保持 C 的后处理对照报告

本轮结论：固定的保持 C 几何整理确实减少了自由面之间的非法相交，但没有形成普遍的接合改善，也未观察到明显的整体结构修复。保留为离线对照，不自动接入 START 默认输出。学习式去噪没有可核验资产，尚未执行；本轮不能代表论文完整后处理的效果。

1. **相交收益跨父一致。** FF 非法相交受影响自由面比例从 91.8064% 降到 84.6360%，下降 7.1704 个百分点，8/8 父均下降。平均非法相交对数从 231.625 降到 195.75。23 个未删面输出仍平均下降 8.3423 个百分点，说明收益并非只是删掉若干面改变分母；这个按删面状态分组是事后描述，不是独立因果消融。
2. **接合改善集中。** S 从 13.1179% 到 13.5828%，平均 +0.4649 个百分点，3 父升、2 父降、3 父不变。86ec 父均 +7.6490 个百分点；去掉该父后其余七父均值为 -0.5614 个百分点。c1b8 父 -3.1542、f596 父 -1.5078 个百分点。不能仅用整体平均值宣称接合稳定改善。OLD +0.7158、历史 FRESH +0.2140 个百分点，均不是新独立测试。
3. **控制代价没有消失。** C 冲突 I 从 3.4271% 到 3.5553%，平均 +0.1282 个百分点。534b 父 I +1.2207 个百分点，即使它的 S 也略升。E 下界均值从 88.5424% 到 88.5124%，-0.0299 个百分点；每标签仍有 24 例 E 为 PARTIAL，原上下界全部保留。精确保留 C 不等于它不被其他面遮挡或穿过。
4. **主体误差几乎不变。** GT→free MSE 平均相对下降 0.0769%，free→GT 下降 0.0925%，双向平均下降 0.0835%；双向距离只有 3/8 父下降，5/8 上升。小幅平均变化不能作为明显形状修复证据。固定查询距离尾部和每父差异均保留在 CSV。
5. **连接仍很不完整。** 只有 2/32 个后处理输出与 C 具有至少一条实际共享边，全组共 5 条。以只合并完全相同坐标的 RAW 作基准，平均共享边连通分量为 150.625→138.0625，边界边 464→437.59375；非流形边 2→2.15625。32/32 都未满足每条边恰有两面的闭边条件，不声称水密或流形。不能把索引合并本身当成所有裂缝都被修好。
6. **修改量和身份均可追溯。** 32/32 C 坐标、面数、顺序、绕序和位模式不变。4046 个 free 角被移动，其中 55 个吸附到 C，其余 3991 个归到 free 代表点；最大位移 0.04196949 模型单位，小于固定半径 0.04197096，最大位移/L0 为 0.7180%。9/32 输出删除共 22 个 free 面（20 个合并后重顶点退化面、2 个重复 free 面），全部保留源面/角映射和删除原因。

全 32 页 RAW/GEO_C/GT 对照由 AI 实际查看，使用各父全部噪声共同相机、四实体视角与线框。总体轮廓前后接近，原有裂隙、碎片、尖薄片或缺失结构仍在；未见一致的大幅结构修复。逐例观察见 audit/visual_review_*.json。该观察不等于人类可用性研究，也不替代相交/水密检测。页脚的“no smoothing or geometry edits”限定于渲染阶段没有再修改传入网格；GEO_C 本身明确经过本轮几何处理。

**优先下一步：获取并核验论文学习式去噪器的真实实现、权重和输入尺度，再在这同一批 32 份 RAW 上补去噪阶段。** 检验假说是：合并前的坐标修正能让原本相关但未落入小半径的 free 顶点进入正确局部布局，在继续固定 C 的前提下，带来跨父的接合和网格连通改善，同时不以冲突、主体误差或大位移为代价。现有证据不足以直接扩大焊接半径，也不足以立刻训练新 refiner。

如果仍无法获得可核验的去噪器资产，该后续保持 BLOCKED；不要把本轮纯几何清理叫作已完成论文整链，也不要自动启动替代训练。本固定任务不执行该后续。

## 执行范围与证据边界

完成 RAW 与 GEO_C 的固定配对。GEO_C 是一次保持 C 的几何整理；未找到身份可核验的论文学习式去噪器代码/权重，DENOISE 和 DENOISE+GEO 均 NOT_RUN_ASSET_UNAVAILABLE。因此本轮不是论文完整后处理的复现，也不能从本轮推断学习式去噪无效。
OLD 为 n0/n1，FRESH 为历史 n2/n3；四份噪声都已被观察过，不是独立确认集。无模型晋级或默认采样路径变更。

## 固定处理规则

半径固定为 0.0419709560984 个模型坐标单位。采用参考尺度 x_ref=.95×.3762×x_model，参考半径 .015；源码有 x_model=2×x_unitbox/.3762。这个选择是论文启发的单一工程阈值，作者后处理具体运行尺度尚未完整追溯，不声称阈值等价复现；无输出 bbox 重归一、无阈值扫描。
C 的全部三角形、角顺序、绕序和 FP32 位模式保持；不同 C 锚不合并。free 角只在唯一 C 锚落入半径时吸附；多锚冲突拒绝。其他 free 角按确定顺序归到半径内不可移动的原始点代表，无传递链和均值漂移。仅删除 free 精确重顶点/共线/重复面，C 优先。没有补洞、平滑、裁剪、量化或法向绕序修复。
