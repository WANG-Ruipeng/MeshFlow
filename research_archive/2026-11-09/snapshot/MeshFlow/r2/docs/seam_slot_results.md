# SEAM_SLOT：已验证的接续收益与尚未解决的表面质量

整理日期：2026-10-17。这是对已完成实验的代码归档与证据整理，没有新增训练、采样、评分或图审。当前维护默认仍是 Chair HYBRID START；FULL_S6000 是充分训练的方法比较参照，SEAM 是 **R31 / BOUNDED_POSITIVE_SIGNAL** 候选。

**值得保留的是共享原边槽带来的真实主体接续，以及用户观察到的视觉改善。FF 和 I 没有随之整体改善，不能用接续收益掩盖这一代价。** 原端到端 C-only 版本在四条已见 TRAIN 条件上，将有合法 C/F 共边的输出从 13/16 提高到 16/16；13/16 存在不经过 C 的 seam→bulk 合法共边路径，其中 11/16 的 bulk 可达面积至少 30%。这比单纯靠近 C 或只长一圈孤立面片更有意义，但尚未证明新父泛化、完整封边或整体无交。

原报告和完整逐输出数据的只读副本见 [证据目录](evidence/seam_slot_c200_v1/README.md)，[全部 16 页配对图](evidence/seam_slot_c200_v1/c200/evaluation/gallery/README.md)来自原审阅包，无重新渲染或选例。数值均来自已保存结果，表中百分比是逐请求宏均值，边数是全组加总；没有只筛选有利样本。

## 表示与实验合同

- 与原生 FULL 对照相同，生成器仍继承 Native/T1＋role＋Geo，使用 free-only FM 和 OT 后 HYBRID0.25。
- 一个激活的 seam 槽对应一条 C 来源拓扑开放边：两个角点引用 C 原顶点并硬保持，第三点自由生成。Null 回到完整三角形 bulk 槽，总面数 N 固定。
- 833 参数的 C-only 占用头预测边是否激活。来源 ID 不作为数值特征；训练时使用来源占用布局，推理时使用预测布局。
- seam 的角时间为 `[1,1,t]`，bulk 为 `[t,t,t]`。固定角点不参与 FM 分母；实际自由标量数为 `9(N-K)-6S`。候选和对照的分母不同，不用总 FM 数值判胜负。
- 主实验两臂都从 FULL_S6000 的 live generator、匹配 AdamW/RNG 出发，各续训固定 200 步（global12000→12200）。四父为 73/3f/85/8c，K=20/14/12/16，N=231/168/166/183；每父每臂 400 实例曝光。
- 评价是四条 TRAIN C×四份预冻结噪声。Euler50 后单次官方 D0，恢复 C 与 seam 固定端点，GEO_C，再恢复来源 C 角序并固定 C 整理 free 方向。没有比较 best checkpoint。
- 当前原型只实现单边 owner、自由第三点；不支持多边共用一张 owner 面或第三点引用 C 的一般情况。不能把四条可表达条件当成任意用户 C 已受支持。

## 端到端 C-only 结果：与等预算 FULL4_C200 比较

来源：[原报告](evidence/seam_slot_c200_v1/c200/REPORT.md)、[64 行逐输出表](evidence/seam_slot_c200_v1/c200/evaluation/per_output.csv)、[配对终点表](evidence/seam_slot_c200_v1/c200/evaluation/endpoint_comparison.csv)。

| POST 指标 | FULL4_C200 | SEAM_SLOT_C200 / PREDICTED |
|---|---:|---:|
| 有合法 C/F 共边 | 13/16 | 16/16 |
| 合法 C/F 边数 | 131 | 175 |
| 合法 C/F 总长（模型单位） | 104.480 | 112.770 |
| C 出发的无向合法图可达 free 面积 | 51.876% | 56.029% |
| C 出发的方向一致合法图可达 free 面积 | 51.876% | 50.658% |
| CF 非法影响 free 面比例 ↓ | 3.751% | 1.704% |
| FF 非法影响 free 面比例 ↓ | 12.841% | 14.563% |
| I / ConflictCov_C ↓ | 0.671% | 3.302% |
| free 最小角 <5° 比例 ↓ | 22.496% | 18.100% |
| C/F 非流形边数 ↓ | 0 | 18 |

候选 seam→bulk 的独立口径：从与 C 有合法边的 seam 面起步，只沿合法 free/free 共边传播，**禁止借道 C，且分子和分母均不包含 seam 面积**。其比例宏均值为 49.248%，13/16 非零，11/16≥30%；普通 FULL 没有 seam 角色，此指标为 NA，而不是 0。30% 是描述门槛，不是完整成品合格线。

必须一起保留的案例：

- `73/n2`：共同整体可达面积 0.019%→64.380%，候选 seam→bulk 为 63.649%；`85/n3` 从没有合法 C/F 边变为 7 条，seam→bulk 为 46.175%。这是有价值的局部连接证据。
- `73/n1`：原头预测布局已与来源完全一致，22 条合法 C/F 边仍没有任何 seam→bulk 边。它是本轮唯一新增明确座面采用的请求，不能同时记成新增主体接续成功。
- `3f/n1`：C 出发整体可达为 95.153%，但 seam→bulk 为 0。两种图不可混用，否则会把经过 C 的旧连接错计为新 seam 的收益。
- `3f/n2`：POST I=42.529%，对应 FULL 为 0.098%。即便其 bulk 可达达 98.638%，仍有明显冲突代价；该坏尾不能从主表删除。

RAW 的 FF 为 84.360%→81.570%，但 POST 为 12.841%→14.563%；必须分阶段讨论。RAW 两种表示本就有不同的共享索引结构，不能直接用 RAW 共边数给学习能力排名。

## 冻结生成器的布局诊断：三种布局不是三个同级可部署模型

来源：[占用 rollout 报告](evidence/seam_slot_c200_v1/occupancy_rollout/REPORT.md)、[192 行逐阶段表](evidence/seam_slot_c200_v1/occupancy_rollout/analysis/per_output.csv)、[紧凑核心表](evidence/seam_slot_c200_v1/occupancy_rollout/analysis/key_results.csv)。

| 布局 | 如何获得 | 可支持的结论 |
|---|---|---|
| PREDICTED | C-only 头 `logit >= 0`；66 条边中激活 36 | 已执行端到端 C-only 方案 |
| ALL_ON（讨论中的 ALL_ACTIVE） | 缓存 logit 加 `ln(15.5)` 后判定；本面板恰好激活全部 66 条 | 无来源标签的冻结推理干预；不代表新 C 上已校准 |
| SOURCE_ORACLE | 训练来源布局的 62 条占用边 | 使用来源答案的诊断参照，不能作为 C-only 主结果 |

原头 TP/TN/FP/FN=36/4/0/26；解析去权重变为 62/0/4/0。它恢复正类召回，同时失去全部来源 Null 判断，不是同时修好两类。来源 Null 只是该来源完成没有接口，不表示开放生成的所有合理完成都禁止接续该边。

以下仍用原 GEO，同一冻结 SEAM 生成器、相同四 C 和噪声：

| POST 指标 | PREDICTED | ALL_ON | SOURCE_ORACLE（诊断） |
|---|---:|---:|---:|
| FF ↓ | 14.5629% | 14.1557% | 13.3980% |
| I ↓ | 3.3020% | 3.1433% | 3.1891% |
| 非法 FF 对数 ↓ | 343 | 345 | 316 |
| 合法 C/F 边数 | 175 | 231 | 210 |
| seam→bulk 非零请求 | 13/16 | 14/16 | 14/16 |
| seam→bulk 面积≥30% 请求 | 11/16 | 12/16 | 12/16 |
| seam→bulk 面积宏均值 | 49.2483% | 56.5023% | 56.8345% |
| C/F 非流形边数 ↓ | 18 | 27 | 32 |

新增非零 bulk 覆盖只有 `3f/n1`；`73/n1`、`85/n0` 仍为零。SOURCE 在 8c 四份噪声上 FF 都下降，但仍为 27.736% 的父均值。3f/n3 和 85 有退化，不能将来源布局视作稳定质量提升。

`3f/n2` 的 POST I 为 PREDICTED/ALL_ON/SOURCE=42.5293/44.3848/43.1152%。SOURCE 的最终精确非法 CF 面对为 0，I 仍很高，说明精确相交与近表面冲突覆盖不同。布局修正没有消除这一尾部。

该诊断新增 32 次 Euler50 和 32 次单次 D0，零训练；旧 PREDICTED 16 份复用。73 三布局相同、85 的 ALL_ON 与 SOURCE 相同，已逐数组核验。这些恒等结果不算独立新增收益。

## 容量保护与 FF 归因：单列候选，不悄悄并入主流程

来源：[几何保护报告](evidence/seam_slot_c200_v1/geometry_guard/REPORT.md)、[阶段账本](evidence/seam_slot_c200_v1/geometry_guard/attribution/stage_metrics.csv)、[容量逐例](evidence/seam_slot_c200_v1/geometry_guard/capacity/per_output.csv)。

原 PREDICTED POST 的 343 对非法 FF 中，338 对（98.54%）属于 bulk–bulk，4 对 seam–bulk，1 对 seam–seam。**残余 FF 主要位于 bulk 内部**；这不等于证明 SEAM 对 bulk 没有间接影响。PRE_GEO 的 1921 对中，1445 对在两面均保留时被原 GEO 消除、185 对涉及删面、291 对仍非法，同时新增 52 对。GEO 有巨大净收益，也有新增代价，不能简单归因为“后处理制造了所有自交”。

容量保护只改变同一 PRE_GEO 的合并决策，拒绝新合并使 C 边 incidence 超过 `max(2,当前 incidence)`。原 PREDICTED 的 C/F 非流形边 18→0、合法 CF 边 175→192，但 FF 14.563%→15.348%、方向一致整体可达 50.658%→48.581%，新终态未重现 13 条原合法 FF 边，并新增 11 对 seam–bulk 非法 FF。没有额外删掉原保留面，反而多保留 5 面。

ALL_ON/SOURCE 的容量版也有代价：FF 分别为 14.9245%/14.4506%，I 为 3.4332%/3.4180%，都高于各自原 GEO。容量约束不等于几何无冲突，当前不能作为免费的默认升级。

原报告的 60° 法向推导有正式勘误：正确不等式为 `r < -abs(h)/sqrt(3)`，不是乘 `sqrt(3)`。实际代码使用 `cos(theta) <= 0.5`，统计未受影响；该门禁仍误拒四 C 的 50/62 个合法来源接口。[保留勘误及核验](evidence/seam_slot_c200_v1/geometry_guard/errata_normal_60deg_20261016/ERRATUM.md)。这一约束未加入训练。

## 视觉、数值与研究定位

用户认为 SEAM 的整体视觉质量更好，这个观察与真实接续和小角改善相容；它不是人类盲评的已量化结论。原实验有 64 条实际非盲 AI_PROXY 记录，布局诊断有 144 条，容量检查有 16 条配对记录（覆盖 32 个网格），均随小证据集保留。此次仅检查归档图能正常显示，没有开展新一轮图审或更改标签。

图像能显示整体形态、C 用途和可见碎片，但隐藏重层、蓝色 C 遮挡下的冲突及微小裂缝不一定可见。FF 是**至少参与一个非法 F/F 面对的 free 面比例**，I 是**冻结 C 查询点的带容差冲突覆盖**；I 不是整个物体的自交率。可达面积、外观、FF 和 I 测量不同性质，改善其中一个不自动推翻另一个。

当前结论为：**保留 SEAM 的共享身份与接续能力，继续把 bulk 表面质量和 C 附近重复覆盖作为未解决的问题。** 四条已见 TRAIN C、固定 200 步、四噪声的证据不足以认定 DEV 泛化、概率校准、完整流形或论文主表的稳定优势。来源布局不能替换 C-only 推理，ALL_ON 与容量分支也没有晋级默认。

本次仅归档；没有启动 SEAM＋DEDUP、长训、RL、新损失、阈值扫描或模型切换。权重只保存身份与本地位置，[WEIGHTS.json](evidence/seam_slot_c200_v1/c200/WEIGHTS.json) 不包含权重本体。官方模型、历史 RAW/POST 与旧报告保持不变。
