## 结论

本轮同预算三臂比较没有确立 Bench 综合晋级候选。降低 COMMON 起点的主干学习率没有改善最终整体质量；从官方权重重新适配得到较低的 FF，但同时存在更高的条件冲突覆盖、小角面比例和明显的局部表面损伤。三臂最终在开放输入上的 bulk 可达面积 ≥30% 均为 TRAIN 0/14、DEV 0/26。这里的 A 是 fresh AdamW 对照，不等同于历史 CLEAN 恢复端点；本轮没有逐一重评所有历史模型。

**补充历史比较后，应保留一个有限正结果：A 相对此前 CLEAN1500＋旧布局，DEV 最终 FF/CF/I/小角分别降低 1.085/0.275/0.415/0.682 个百分点。** 但 C/F 合法边均数仍是3.25，主体接续仍未突破，单面边分量与非流形边还略增；TRAIN 的 I、小角和部分保面指标也并未一起改善。因此不能把本轮笼统记成“所有结果都更差”，也不能宣布 A 全面超过历史最强系统。第8节给出完整历史参照。

这支持把初始化与适配强度作为需要控制的变量，但不支持“把学习率调小就能救回 Bench”，也不证明 COMMON 已经不可逆地损坏，更不能据此要求 Chair 同步重训。Chair 代码、权重与默认模型未改变。本实验不自动延长或选择中间最好看的检查点。

## 0. 当前要解决的实际问题，以及方法怎样走到这里

### 0.1 任务与成功标准

输入是带真实坐标和连接关系的局部三角面集合 C，以及总面数 N；模型生成其余 free 面 F，组成完整 Bench。部位可以是座面、靠背、腿／支撑或部件组合。我们要求 C 保留、被合理用于成品，生成主体完整且几何代价可接受。来源完整网格只是训练监督和参考完成，不要求输出复制唯一来源款式。

需要分清三个层次：**C 被原样复制；C 与少量 seam 面接上；这些 seam 又与生成主体 bulk 接上。** 前一层成立不保证后一层成立。目前 Bench 最明确的局部收益在第二层，主要失败同时涉及用途、主体连接和表面质量。

### 0.2 已观察到的问题与证据边界

| 问题 | 已有实证 | 当前能下的结论 |
|---|---|---|
| 蓝色条件被另一层灰色主体替代、包在内部或错层 | 旧 Bench 与本轮双视角／位置截面均出现：灰座层高于蓝座面、灰腿架绕开蓝支撑、RAW 中已存在分层 | 有些失败在生成阶段已形成，局部焊接不能自动解决用途和宏观位置；不能仅因款式不同判失败 |
| C侧有合法边，主体仍未连接 | 历史 SEAM21000 原POST在DEV有22/32份合法C/F边，但bulk可达≥30%为0/26；本轮最终三臂都有24/32份合法C/F边，仍是0/26 | 共享原边槽解决了部分C端表达，尚未普遍建立seam→bulk共同边界 |
| 后处理降低FF，同时损失细腿、座板和表面 | 旧SEAM15000/21000的GEO删除4349/3652张free面，分别占50.27%/42.21%；本轮DEV最终平均删80–86张free面 | “FF下降”必须同时看有效面数、面积、支撑与图像；删面问题不能全部归因于半径过大 |
| 训练拟合与DEV监督误差分离 | COMMON普通条件训练0→12000：TRAIN all-free MSE 0.157445→0.110555，DEV 0.879781→1.144615；旧SEAM9000步后TRAIN tip 0.029562、DEV tip 2.758679 | 支持关注后训练专门化和迁移差距；不证明所有失败都由过拟合、COMMON损坏或数据量不足造成 |
| 布局召回提高，没有兑现主体接续 | CLEAN新头将DEV来源owner召回68.60%→94.21%，Null拒绝率65.63%→25.00%；同生成器的新布局增加C/F边，但FF/I更高，bulk仍0/26 | 分类准确度、激活更多边与终态控制成功不是同一目标；来源布局也不是所有合理生成的唯一答案 |
| 数据和评测覆盖有限 | 64父／277条多部位TRAIN条件，筛后58父／195条；DEV仅8父、反复用于开发，其中7父为官方test、1父为官方train但条件适配留出 | 增加条件数、缩放和噪声不等于增加独立形状；当前只能作开发面板上的配方判断 |

删面诊断还表明：旧GEO删除主要来自合并后同面顶点坍缩与精确重复，并非直接按面积阈值删除“木条”。被删面在PRE_GEO中最短边≤合并半径的比例为87.26%／84.15%；很多面进入GEO前已经很细。故生成、D0和合并各自可能贡献损伤，不能只改最后一层就宣称解决了全部问题。详见[旧删面与接触诊断](../r2_bench_post_rescue_diagnostic_v1/REPORT.md)。

初始TRAIN／DEV监督误差本来就不同。不能把全部差距都算成后训练造成；COMMON普通条件探针与SEAM探针的角色／分母也不同，不能将两个阶段的标量拼成同一精确曲线。本轮已在三臂内统一探针。上述误差是来源监督诊断，不是开放生成的唯一GT排名。

**仍未被证明的机制解释**包括：官方生成能力是否被不可逆破坏；Bench失败是否主要由数据覆盖不足；扩大父数或减小可训练容量是否足够；是否需要新的seam–bulk表示。当前证据能定位问题层次，不能给这些解释补上尚未完成的因果验证。

### 0.3 相对原MeshFlow，我们添加了什么

| 系统层 | 当前实际实现 | 能解决与不能保证的事情 |
|---|---|---|
| 原生成先验 | 类别专用的官方Bench MeshFlow生成器 | 提供原生三角面形状先验；原官方模型没有学过本项目的C/free任务 |
| Native/T1＋role＋Geo | 输入保留C与带噪free，区分角色和known/free状态，增加既有几何条件通路；FM仅监督有效free变量 | 建立显式几何条件接口；不能由C硬保持直接推导用途正确 |
| R2优化配方 | 来源free面先OT匹配，再HYBRID混噪，λ=0.25；同一free-only FM | 学习条件完成分布；没有加入新的FF、相交或接缝损失 |
| SEAM共享原边槽 | 训练从合法来源接口确定owner；seam面前两个角点引用C开放边端点，只生成第三点；其余bulk面保持自由生成，按角色限制匹配和有效坐标监督 | 让一部分C/F共边可直接表达；没有直接把seam第三点与bulk顶点共享为同一身份 |
| C-only布局 | 推理从C预测哪些边分配独立seam槽；本轮统一读取旧S15000的预测缓存 | 不向推理提供来源Y；预测布局不等于来源oracle，也不保证最佳生成布局 |
| 完整后处理 | 单次官方Bench D0→恢复C/seam锚点→GEO_C→来源绕序恢复/固定C定向→HINGE_OPP015→ALPHA→HOLE | 整理几何、表达方向并做受保护的局部接续；无法保证修复宏观用途替代或缺失主体 |

可以把当前流程写成：

```text
真实局部网格 C + 总面数 N
    → C-only 开放边布局
    → Native/T1 + role + Geo 条件生成
       ├─ seam：两角引用 C，只生成第三点
       └─ bulk：普通自由三角面
    → Euler50 得到 RAW
    → 单次 Bench D0 + C/seam 恢复 + GEO_C/定向
    → HINGE 1.5%L + ALPHA + HOLE
    → 分别评价 C 用途、主体接续、完整性及几何质量
```

本轮A/B/C共享以上架构、布局和后处理。**本轮的方法变化是初始化与主干更新强度，而不是再添加一个网络模块。**

### 0.4 训练谱系：各条分叉的历史不能混算

| 阶段 | 数据／生成器更新 | 优化器与初始化 | 这一阶段改变了什么 |
|---|---|---|---|
| 官方→COMMON12000 | 64 TRAIN父／277条件，普通条件12000步 | 官方EMA＋原条件初始化，fresh AdamW | 建立普通Native/T1＋role＋Geo条件能力 |
| COMMON→Native／SEAM | 相同64父多部位池；两分支各新增9000步至累计21000，15000为共同里程碑 | 恢复同一COMMON的模型、AdamW、RNG | 普通Native对比共享原边槽；SEAM另训练833参数逐边头 |
| COMMON→CLEAN1500 | 58父／195条件，新增1500至累计13500 | 恢复COMMON生成器AdamW/RNG；新布局头fresh | 有效接口筛选、xyz增强、18049参数上下文头、未加权BCE等整体配方变化 |
| COMMON→本轮A/B | 同一CLEAN输入流，新增各1500至累计13500 | 同COMMON模型，全部fresh AdamW | A主干1e-5，B主干2e-6；均使用旧预测布局 |
| 官方→本轮C | 同一CLEAN输入流，1500步 | 官方EMA＋原条件初始化，fresh AdamW | 绕过COMMON历史，直接进行相同SEAM条件适配；主干2e-6 |

各行是不同分叉，CLEAN1500和本轮A/B都没有继承旧SEAM21000。C也没有继承COMMON已经训练的role/Geo。C与B相同的是未来1500步预算，不是累计训练成本。

“CLEAN”在这里指**条件接口筛选**：277条TRAIN中排除44条闭合C、38条开放但无有效owner条件，留下195条、58父。它没有清除来源相交或重复面，仍保留69条多连通条件和41条腿／支撑条件。本轮沿用其原几何、C/Y划分、父采样和xyz增强；没有新增父、重三角化或引入部位语义标签。Chair历史的缺陷计数不能直接套到Bench。

这也是本轮比较的动机：在继续修改连接表示之前，检验**减弱COMMON上的主干更新**、或者**绕过COMMON重新建立条件能力**，能否让真实生成表现更好。实际结果见第2—5节，历史比较见第8节。

## 1. 实际执行的比较

| 臂 | 初始化 | 主干学习率 | role/Geo 学习率 | 新增更新 |
|---|---|---:|---:|---:|
| A | COMMON12000 live | 1e-5 | 1e-5 | 1500 |
| B | 同一 COMMON12000 live | 2e-6 | 1e-5 | 1500 |
| C | 官方 Bench EMA＋原条件模块初始化 | 2e-6 | 1e-5 | 1500 |

三臂均 fresh AdamW，β=(0.9,0.95)、eps=1e-8、weight decay=0、clip=1，batch 8 / microbatch 1。没有混入历史优化器动量。使用完全相同的 CLEAN1500 数据流：58 个 TRAIN 父、195 条条件；每臂 12,000 次实例曝光，各父 206–208 次。训练使用来源 owner 监督，原 free-only FM、OT 后 HYBRID 0.25；没有新增损失或占用头训练。

运行使用 BF16 前向、FP32 参数/优化器状态/积分，严格确定性算法、关闭 TF32、math SDPA，并在 CUDA 初始化前设置 `CUBLAS_WORKSPACE_CONFIG=:4096:8`。并行只改变调度，没有改变 batch、精度、输入随机流或固定噪声。

推理统一读取旧 SEAM_S15000 的冻结 C-only 预测布局，没有读取来源 owner 标签。全部 224 份 Euler50 RAW 保存后，才执行 224 次单次官方 Bench D0。后续统一恢复 C/seam，执行 GEO_C、来源定向及 HINGE_OPP015 → ALPHA → HOLE。

模型实际可训练参数为 130,401,155，其中主干 130,249,731，条件模块 151,424；不能将约 5.2 亿字节的 FP32 权重文件误写成 5.2 亿参数。

两个主对比的解释边界：

- **B−A**：同一 COMMON 初始化、同一未来预算下的主干学习率变化。
- **C−B**：完整初始化包变化，包括官方/COMMON 主干与对应条件模块历史；不是仅替换主干的单变量“遗忘证明”。

固定监督探针在 0/500/1000/1500 更新读取相同输入。自由生成的过程面板为同一 16 请求，检查 0/500/1500；它没有 SEAT_SURFACE 条件，但包含 2 个 SEAT_SUPPORT 请求，部位覆盖有限。最终主面板为 48 请求：4 TRAIN 父×2 条 C×2 噪声=16，8 DEV 父×2 条 C×2 噪声=32。不能把 16 请求过程均值与 48 请求终点均值拼成学习曲线。

## 3. RAW 与后处理不能混在一起解释

| DEV 阶段 | A FF / I / 小角 % | B FF / I / 小角 % | C FF / I / 小角 % |
|---|---|---|---|
| RAW | 94.387 / 12.894 / 36.092 | 95.158 / 11.540 / 35.758 | 91.636 / 15.337 / 37.343 |
| BASE_POST | 30.591 / 8.386 / 46.223 | 34.808 / 9.547 / 44.771 | 26.961 / 12.714 / 53.500 |
| CLEAN_FINAL_POST | 26.973 / 8.545 / 45.376 | 31.091 / 9.348 / 43.882 | 24.145 / 12.668 / 52.001 |

RAW 为独立角点的连续三角面表示，其 FF 是原评分器对该阶段的面对检测结果，不等于视觉上 94% 的表面都不可用。统一后处理大幅改变了角点合并、保留面数和相交关系；同时 DEV 平均原 free 预算为 169.25，最终只保留约 83–89 面。不能只凭 RAW→POST 的 FF 降幅断言主体更完整。

在 BASE→FINAL 的同面板比较中，三臂 FF 均下降，幅度约 2.8–3.7 pp；C/F 共边数基本不变，bulk 接续仍很弱。完整结果保留固定 BASE 分母、绝对面对数、删面和桥接账本，不把新增桥接面与原面混计。

实际图像反例包括：

- `5dda…/SEAT_SURFACE_1/n0`：A 的蓝色窄面仍高于灰色座板，B 将灰色实际座面生成在更低位置；C 的灰色腿部在后处理后显著丢失。
- `9d56…/LEG_SUPPORT_1/n1`：A 的 RAW 有可辨的条板座面与腿架，后处理后座板大幅变成细线框，不能用较少非法面对抵消这种损伤。
- `9d56…/SEAT_SURFACE_1/n0`：C 的木条长椅与腿架保留较好，A/B 的短腿后处理后显著削弱；这是局部视觉优势，不代表全组获胜。

## 8. 与此前Bench最强结果相比，究竟有无进展

### 8.1 “此前SOTA”在本报告中的含义

这里比较的是**本项目已运行的Bench历史系统**，不是外部论文的Bench公开榜单。历史没有预先选出一个同时在用途、接续、完整性、FF/CF/I上最好的模型，不能给每个指标分别挑一个模型，再把它拼成不存在的“SOTA”。

保留五个明确参照：

- **Native21000**：普通条件生成的整体质量／保面参照；没有SEAM角色，专属bulk接续记NA。
- **SEAM15000、SEAM21000**：分别有3000、9000步SEAM历史的完整系统；C侧接口有收益，DEV主体接续仍弱。
- **CLEAN1500＋旧布局**：最接近本轮A的参照，同起始生成器、58父／195条件、1500步日程和旧S15000预测布局；但旧模型恢复AdamW/RNG，本轮fresh，因此不是精确重放。
- **CLEAN1500＋新头**：同历史CLEAN生成器使用新布局，代表更高C侧接口数量及相应代价。

本次核对了两轮完整评测manifest：48条请求及顺序完全相同，C/N/K、父／条件身份、噪声数组hash、来源映射、查询及旧布局缓存全部一致；共同23个评分／后处理源码hash一致。旧系统使用上轮已经实际执行的相同CPU链终态，与本轮 **CLEAN_FINAL_POST 对 CLEAN_FINAL_POST** 比较。不是用旧BASE对新FINAL，也没有新跑历史模型。

两份逐输出表合计1152行（8系统×48请求×3阶段），按噪声→条件→父等权重新汇总。质量字段全组平衡，与逐输出均值相同；seam专属指标保留NA。完整RAW/BASE/FINAL及TRAIN/DEV表见[历史对比附表](document_revisions/historical_context_v1/tables.md)；[可复算数值与逐父差值](document_revisions/historical_context_v1/historical_comparison.json)绑定原表hash。

### 8.4 目前应怎样定位这次结果

**如果问“有没有比之前Bench更好的局部结果”：有，A相对CLEAN旧布局的DEV质量比例有一组小幅同向改善，C也有更低FF。**

**如果问“有没有可全面替换历史Bench系统的新最佳模型”：目前没有。** 更高C侧接口、更低FF、更完整有效表面及主体接续尚未集中到同一模型上；原来用户指出的蓝C被替代、错层、细腿／板面损伤也没有被本轮稳定消除。不能把来源监督loss更低当成已经解决这些问题。

因此保留A作为本轮同步比较参照及有限质量候选，保留旧Native／SEAM／CLEAN的不同优势证据，不切换默认、不删除历史正例。B/C的这次固定1500步方案未形成综合晋级证据；这限制的是当前配方判断，不是对所有官方初始化、低学习率、数据扩展或Bench生成的否定。

本轮也没有为“Chair必须跟着重训”提供依据。Chair与Bench的条件覆盖、训练历史和类别先验不同，应保留Chair既有结果，而不是由Bench失败反向推翻它。
