# Bench：HINGE 与 GEO_C 删面快速诊断

2026-10-19。状态：两项检查完成，零训练、零模型调用、零 GPU 计算。保留原资产和原评分；新产物均在本独立目录。

**结论：HINGE 1.5%L 能改善 Bench 的部分局部几何，但这次没有把它救成稳定的主体接续。删面问题则确有“D0 先把许多面压细，GEO_C 再合并坍缩”的阶段证据，不能简化成原本正常的木条仅被最后一道半径误杀。** 下一步最值得针对的是细结构在去噪与合并过程中的保留，而不是直接追加训练或扩大绑定半径。本报告不启动下一项实验。

## 1. 范围与比较口径

- 读取已保存的 `SEAM_S15000`、`SEAM_S21000`，每阶段48请求，完全相同的24条C×2固定噪声。TRAIN为4父16请求，DEV为8父32请求。
- 每阶段8份闭合C（TRAIN2、DEV6），seam接续指标为NA；适用接续指标的请求为40份（TRAIN14、DEV26）。几何质量和删面仍对全部48份计算。
- HINGE复用已保留的反向绕序守卫版本：`fraction_L=.015, require_opposite_winding=True`。读取原POST，不重跑D0；没有增加ALPHA、补洞或其他策略。
- 候选全部运行原Bench评分和既有补充拓扑指标，形成**192行×135数值字段**的原/新配对表。原结果、查询数组、评分定义不变。
- 质量均值采用“噪声→条件→父”等权；接续均值跳过NA。比例分母均在逐输出表保留。本文I是 `ConflictCov_C`，即C有限表面查询冲突覆盖，**不是全网格自交率**；CF/FF是非法面对影响的free面比例。
- Bench是从官方Bench EMA开始的类别专用后训练，不是Chair权重零样本迁移。两个Bench终点间占用头也继续训练；与Chair还存在数据部位、父数量、类别D0等差异。本轮不能单独证明“换类别”或某一训练配置造成失败。

## 2. HINGE：局部收益成立，主体接续没有获救

下表均为父等权均值；计数行直接使用40个适用请求。

| 指标 | S15000 原POST → HINGE | S21000 原POST → HINGE |
|---|---:|---:|
| FF ↓ | 32.5366% → 30.9549% | 32.5775% → 30.5535% |
| CF ↓ | 7.5681% → 7.5681% | 8.0554% → 8.0554% |
| I ↓ | 10.3851% → 11.0067% | 11.1827% → 11.1928% |
| 沿合法共边可达bulk面积 ↑ | 0.0490% → 0.7101% | 0.3238% → 0.9808% |
| 合法共边可达bulk≥30% | 0/40 → 0/40 | 0/40 → 0/40 |
| 合法图单面孤岛数/输出 ↓ | 26.5417 → 22.4375 | 25.8750 → 21.9583 |
| free小角面<5° ↓ | 44.4744% → 44.0664% | 46.2954% → 45.9068% |
| 非流形边数/输出 ↓ | 2.7708 → 2.7708 | 2.7292 → 2.7292 |

两终点分别接受230、253次绑定。原合法CF边188/188、202/202全保留；原合法FF边2295/2295、2938/2938全保留，新增合法FF边274、305条。没有新增非法CF/FF面对，没有额外删面，也没有新增CF边。

新增FF边中，bulk–bulk占264/274、293/305（约96%）；seam–bulk仅9、8条。真正进入队列的seam–bulk候选37、31个，接受8、7个，其余主要被小角恶化、坍缩或法向变化拒绝。总接受量不能当成主体接续改善次数。最大bulk可达分别为26.9649%、26.7570%，均发生于TRAIN `3db1…COMBO_PART_ASSEMBLY`；DEV最大值仅2.1766%、5.7025%，均为 `2d1e…BACK n0`。因此少数局部改善是真实的，并非所有输出完全无变化。角色明细见 [缓存补充账本](hinge/cached_followup/summary.json)。

**“没有新增非法面对”不等于I一定不变。** 原冲突面对的几何覆盖仍可改变，查询距离/覆盖指标与面对集合不是同一件事。S15000的I增加0.6215个百分点必须保留，不能称全面无代价提升。HINGE的收益主要体现为局部free连接与FF整理，未兑现为大块bulk从C经seam的共边接续。

## 3. 确有不少bulk“挂在tip上”，但共点不能当成接好

独立诊断只读取原索引网格和原合法性缓存：从已合法连到C的seam出发，找到它的**原第三角点**；排除落到C顶点上的tip；允许一次精确索引共点跳转到bulk，之后仅沿合法bulk–bulk共边传播。两面必须恰好共一个顶点，且原面对分类是 `shared_vertex_contact`。没有使用距离阈值把附近点冒充共点，也没有移动几何。

这是新版本的**点接触诊断**，不是原接续指标，不用于宣称成功。独立复核已核对原角序映射、FF索引、NA和面积计算。

| 诊断（原POST） | S15000 | S21000 |
|---|---:|---:|
| 有合法seam-tip/bulk单点接触的请求 | 29/40 | 30/40 |
| 原共边或至多一次点跳，可达bulk≥30%的请求 | 9/40 | 11/40 |
| 原合法共边bulk可达面积，父等权 | 0.0490% | 0.3238% |
| 原共边与至多一次点跳的可达bulk并集，父等权 | 14.6903% | 19.3949% |
| 其中原共边尚未到达的增量面积，父等权 | 14.6413% | 19.0710% |

TRAIN中描述性≥30%为5/14→5/14，DEV为4/26→6/26。它说明一部分保留bulk已接触seam的tip；但本次实际HINGE仍没有将任一请求推过30%合法共边阈值，不能把点跳表当作HINGE的效果或可实现上限。

特别是S21000的DEV `f5d…__BACK_SURFACE_1__n1`：点跳后可达52.9612%，但160张free已删147张，只剩13张；图上腿几乎消失。**剩余面积中的高可达比例，不认证主体完整。**

证据：[逐输出](point_contact/per_output.csv)、[逐tip接触](point_contact/tip_bulk_contacts.csv)、[可达bulk面ID](point_contact/point_bulk_faces.csv)、[独立验收](audits/point_contact_independent_review.json)。

## 4. 删面账本：合并触发，很多面在D0后已被压细

准确的平均free预算是180.25张。用户提到的72–84张，对应S21000不同集合均值，不是逐例范围。

| 集合 | S15000平均删除 | S21000平均删除 | S21000平均保留 |
|---|---:|---:|---:|
| TRAIN | 101.5000 | 84.1875 | 118.0625 |
| DEV | 85.1563 | 72.0313 | 97.2188 |
| ALL | 90.6042 | 76.0833 | 104.1667 |

GEO_C实际合并半径为 `R=0.04197095609838` 模型单位，约0.456%L。它**不直接按三角形面积或“木条宽度”删面**：先按原固定代表点规则合并，再删除重复顶点、严格共线或精确重复面。本轮96份原映射均能精确复核，无须重新聚类。

| 删除原因/阶段量 | S15000 | S21000 |
|---|---:|---:|
| 原free总数 | 8652 | 8652 |
| 删除总数 | 4349（50.27%） | 3652（42.21%） |
| 合并后同面顶点坍缩 | 3747 | 3016 |
| 合并后精确重复面 | 602 | 636 |
| 其中seam删除 | 19 | 12 |
| 其中bulk删除 | 4330 | 3640 |
| 被删面PRE_GEO面积和/全部free面积和 | 13.58% | 12.90% |
| 被删面PRE最短边≤R | 3795/4349（87.26%） | 3073/3652（84.15%） |
| 被删面在D0后首次达到最短边≤R | 2716 | 2318 |
| 更强例：RAW最短边≥2R，D0后≤R | 1594 | 1436 |
| 被删群体D0/RAW最短边比值中位数 | 0.1139 | 0.1259 |

所有被删面在PRE_GEO仍有非零面积；其中因重复删除的602/636张面，在PRE阶段尚未与最终保留的重复伙伴精确重合。精确删除条件在合并后才成立。不过其中许多面的尺度已经在D0阶段大幅收缩。S21000被删群体的最短边中位比值为0.1259，即通常已经缩至RAW的约八分之一；不是直到GEO才第一次出现细小几何。

也有632张S21000保留面满足PRE最短边≤R；S15000为651张。薄不必然被删，最终结果还依赖角点归属和代表点。重复面也未必有短边。三角形最短边/最小高不是物体木条的物理宽度，不能将这些统计自动解释成“正常木条误删率”。

面积和占比约13%，不能读成仅损失13%的真实可见表面：它不是表面并集覆盖率；重层可重复计面积，细腿面积小却可能对整体形状至关重要。

证据：[18,688槽位四阶段明细](deletion/per_face.csv)、[逐输出](deletion/per_output.csv)、[阶段面积](deletion/per_output_stage_area.csv)、[完整删面归因](deletion/FINDINGS.md)。

## 5. 实际看图与可支持的机制

为三条固定请求绘制并实际打开了RAW、D0后恢复锚点的PRE_GEO、原POST三阶段同尺度表面及位置截面，记录为非盲 `AI_PROXY`。另核查了5张既有阶段比较页。没有把未看的96份HINGE输出写成视觉成功。

- `f5d…BACK n1`：RAW可见座背及细腿，PRE_GEO腿已接近线状，POST腿几乎消失。147/160张free被删，其中142张合并坍缩、5张重复。说明此例支撑损伤不能只归因于最后的删除规则。
- `9fd…SEAT n0`：RAW腿有可见宽度，PRE已线化，POST剩断续细支撑；蓝C与生成座层的高度偏差在RAW已存在，是另一个问题。
- `1dd…SEAT n0`：删115/182张free，但箱式主体在三个阶段仍保留。反证“删面多就一定毁掉主体”。

位置截面只观察其穿过的有限区域；不穿过腿的截面不能单独证明无腿。图像不认证精确拓扑或三维无相交。

## 6. 对“Bench还能不能救”的回答

**本次便宜补救只获得局部收益，没有解决核心接续。** Bench并非完全没有使用C：存在C侧合法seam接口，也有29/40、30/40请求的tip共点接触；但现有HINGE不能把这种接触稳定转成大片共边连通。

**细结构损伤是值得处理的具体问题，但尚不能称为整个跨类别差距的唯一原因。** 已有阶段证据支持：一部分RAW可见支撑在D0后变细，随后的GEO合并将其坍缩。另一方面，RAW中已有错层/冗余，闭合与多部位条件、布局变化也与Chair不同。这两项CPU检查没有检验各自的训练因果。

如果只选一个后续假说：**在保留当前D0去噪收益的同时，避免将细支撑压入GEO坍缩尺度，能否增加保留的支撑表面和主体完整性，而不显著抬高FF/I？** 应以当前固定缓存和已定位的支撑实例作配对检查，并保留完整48请求质量代价；不应只以删面数减少为成功，也不建议直接用更大绑定半径或继续延长训练代替这个问题。

原完整后处理链把终点RAW FF（TRAIN93.174%、DEV94.958%）降到POST33.140%、32.296%，收益仍很大。这是D0+GEO+导出的联合效果，并无单独D0全组评分。**本报告不支持简单取消D0或跳过清理。**
