# R2_BENCH_CLEAN_MULTIPART_SEAM_V1 实际实验报告

执行日期：2026-10-20。主终点：新增1500次更新 / global13500。状态以同目录 `completion.json` 为最终凭据。

**结论：本轮完成了预定训练和完整评价，但没有把 Bench 的主体接续救回来。** 新配方的 DEV 固定监督探针优于旧3000/9000步 SEAM，新的 C-only 头也大幅提高来源 owner 召回；然而新模型在26份开放 DEV 请求上，最终合法 seam→bulk 可达面积全部为0。新头相对同一生成器的旧布局，增加 C/F 共边，却增加了 DEV FF、I 和小角率。不能将它作为 Bench 泛化成功或全面质量升级。

可保留的结果有明确边界：标准 CPU 级联在本面板满足几何安全合同，并减少部分非法 FF 与单面边连通分量；个别新模型的箱式主体更完整。但这些改善没有替代缺失的主体连接，且部分细腿、座板在 D0/GEO 后仍变薄或残缺。没有选择较好看的1000步权重，没有追加训练、切换默认模型、清理权重、commit或push。
