# Bench 宽池组权重匹配：1500步实际结果

实验：`R2_BENCH_GROUP_WEIGHT_MATCH_V1`；日期：2026-10-27。唯一新增候选为 `M / W_MATCHED1500`。

**结论：M不晋级，不替换窄池B。把宽池W的HIGH组MSE系数恢复到窄池B的水平，没有恢复整体生成质量或DEV采用能力。** 保留有限正结果：新增四父中三父的FINAL FF下降，旧父部分CF/FF改善，`4cd/n1`后处理端撑更完整。但新增结构的RAW→POST支撑损失仍在，DEV三轴交集仍0/8；OLD与HIGH留出的I出现明显代价。不能把这轮说成完全没有任何改善，也不能只据FF下降认定升级。

训练、固定评价、真实图审均实际完成：1500更新，46份新RAW及46次单次官方D0；B/W既有资产只读复用。414行×177字段、138页两视角与两固定截面、276格本轮实际非盲AI_PROXY图审已保存。没有额外训练臂、科学重试、重抽噪声或挑选checkpoint。

## 1. 这次到底改了什么

本轮承接自然N与宽HIGH扩覆盖结果，单独检验一个可控解释：**宽池新增父的N更高，使按全部有效free坐标平均的FM给HIGH组更大的系数；恢复该系数能否减轻退化？** 它不是新数据试验，也不是SEAM改动。旧曝光比例、辅助梯度限制及条件课程的结果不被改写。

|身份|数据/操作|起点与终点|
|---|---|---|
|P0|曝光实验 `B_75_25`；共同live生成器、匹配AdamW/RNG|global21000/native9000|
|B|`NATURAL_HIGH`，26父，HIGH两父；既有数值参照|同P0＋1500→global22500|
|W|`WIDE_HIGH`，30父，HIGH六父；直接对照|同P0＋1500→global22500|
|M|重放W的12000实例，只改HIGH更新的组MSE系数|同P0＋1500→global22500/native10500|

**M不从B或W的22500终点继续训练。** 数据、父对象、条件、N/K、面身份、增强、时间与随机流均和W对应。OLD9000实例、FOCUS1500实例、HIGH1500实例不变；HIGH六父仍各250次，未恢复B两父各750次曝光。

Native/T1＋role＋Geo、free-only FM、OT后HYBRID0.25保持不变；batch8/micro1、lr1e-5、AdamW(0.9,0.95)、wd0、clip1，BF16前向/FP32参数及积分，严格确定性、SDPA math、禁TF32。N合同128..799，实际最大776。没有SEAM、占用头调用、新辅助loss或新后端。

在750个含HIGH的更新中，以共同OLD有效自由标量数为mO，窄B该步HIGH计数为mHB，宽W计数为mHW：

```text
rho = mHB / mHW
DB = mO + mHB; DW = mO + mHW
L_M = (SSE_OLD + rho * SSE_HIGH) / DB
```

实现继续使用原helper的DW分母，OLD微批乘DW/DB，HIGH微批乘DW/DB×rho；8个微批累加后一步更新，不再除8。其余750个FOCUS更新原公式不变。全部系数在开训前按计数冻结，不根据DEV或模型误差选择。

## 6. 本轮能决定什么

组权重匹配已实际生效，且没有由数据流或预算变化混入对照。但在这次固定1500步、单训练随机流、46请求小面板上，它只改变了局部几何质量，没有解决RAW采用与POST保形之间的主要矛盾，也没恢复DEV能力。

因此降低“宽池只是因为HIGH平均系数变大而退化”作为充分解释的优先级，**不继续扫系数或自动延长M**。这不是证明所有归一化都无效，也不是否定自然N准入；HIGH六父各250次曝光的覆盖/学习充分性，本轮并未改变。单条loss曲线、同父两噪声与AI_PROXY均不足以支持广泛泛化或显著性结论。

保留M终点和证据供复查，保留B/W既有身份及自然N的已确认能力；不把M、B或W自动改成maintained CLI默认。后续如继续，应针对已记录的真实RAW组织与支撑面处理损失重新冻结独立问题，而不是据本轮小幅FF收益直接叠加新训练。此处不启动任何下一轮。
