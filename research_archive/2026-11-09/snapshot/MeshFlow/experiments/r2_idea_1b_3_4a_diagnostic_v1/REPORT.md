所有47条件都有真实接口。单边面覆盖98.33%的接口面、96.72%的合法边。C开放边数范围4—22，六个条件超过16边，因此附件中的固定8—16个槽不能自动覆盖“每条原边一个槽”。

这支持真实监督可行性，但有四项实现条件：

1. **固定原边和原顶点索引。** 原边两端直接引用C；只预测边界弧长或复制坐标，会留下 T-junction 或同坐标不同 ID，不能保证共享整条边。
2. **同一张面只实例化一次。** 六张双边接口面若逐边各生成一张，就会重复。已保存一个确定性的面 owner／其他边别名标签示例，并验证 owner＋bulk 可重建原面数；这不是已训练好的最佳分配机制。
3. **Null、第三点引用和总面数合同。** 34条来源 Null 是该参考完成的标签，不能升级成所有合理完成都必须相同的答案。第三点若本来属于C，还需要其离散引用。未占用槽不能靠导出退化面充数。
4. **限制匹配角色。** 八份实际 OT 缓存的端点标记与原ID均能往返恢复，但原无约束面 Hungarian 与六种角排列会交换边角色。只搬运 mask 不够；固定边槽必须有允许的面/角匹配，且明确 Null 与其余 free 面如何分配。

六父来源标签中，610的4条边均有合法来源接续，608有3条、另一条无合法来源邻面；2d有16条边对应13张面，恰好包含3张双边面。这只说明参考完成能提供标签，不代表生成器已经做到，更不要求开放生成复刻原椅子款式。

九个显式 CPU 正反控均符合预期：正确索引条带有合法接口；线段中点 T-junction、只复制坐标、同边两个占用槽、第三点退化、重复C面及向C内部共面重叠均不能算成功。还有一个关键反例：**很小的翻片可以合法连在C上，同时大块free主体仍然断开。** 因而共享端点确实消除指定边的坐标对齐要求，却不保证整体主体、无交、流形或水密。

与R10的区别是从生成状态开始就使用确定的原边身份，不在终态猜伙伴后搬动角点。这是实质变化，未被R10等价覆盖；但第三点、占用、剩余主体连接仍然需要学习。

## 4A：合法的新路径成立，但不能沿用旧 U 和直线终点公式

在冻结 FULL 训练计划的前四条真实记录上，复用原 OT 缓存、HYBRID 起点、增强及身份映射；每条检查t=0.1、0.3、0.5、0.7、0.9，共20个状态。具体记录在读取扰动结果前锁定，包含两条clean和两条原宽度增强。没有重新抽生成噪声、重新求OT或调用模型。

令 X(t)=(1-t)Z_H+tY，U=Y-Z_H。仅对有效free定义：

```text
g(t) = 4t(1-t)
S(t) = I + g(t)A
b(t) = g(t)d
X_tilde(t) = S(t)X(t) + b(t)
U_tilde(t) = S(t)U + g'(t)A X(t) + g'(t)d
```

模型Y轴是竖轴，A仅扰动水平X/Z；水平尺度参数限±5%，平移向量范数限2%L。A/d在同一路径上保持固定。g(0)=g(1)=0，起点和终点不变；C始终不变。新路径必须使用上面的真实导数，而不是继续监督旧U。

| 实际检查 | 结果 |
|---|---:|
| 路径端点、C、源面/角序、接口mask | 4/4通过 |
| 解析导数与中心差分最大绝对差 | 9.63e-11 |
| 新目标能量 / 原目标能量 | 0.9208—1.1223 |
| 仍使用旧U造成的速度RMS差异 | 0.00959—0.31445模型单位 |
| 即使正确速度完全已知，旧直线终点公式的最大偏差 | 7.8435%L |
| 逆变换修正后终点最大坐标误差 | 8.88e-16 |

导数与代数检查用FP64，归档状态用FP32；这不是BF16训练精度认证。实际状态最大偏移2.2648%L：2%L限制的是平移部分，叠加尺度后的位移没有2%L统一保证。

旧 `X_tilde+(1-t)v` 不是这条曲线的正确终点重表达。训练时可利用已知A/d构造：

```text
X_base = inverse(S) (X_tilde - b)
U_base_hat = inverse(S) (v - g' A X_base - g' d)
Y_hat = X_base + (1-t) U_base_hat
```

因此新端点误差为 `(1-t) inverse(S) (v-U_tilde)`；原 `(1-t)^2 × velocity_MSE` 也不能直接沿用。生产样本校验器还强制 `U=Y-Z`，需要独立路径版本，不能放松原校验来绕过。相关接入位置已经列出，但本轮没有修改生产训练入口。

**这不是 DAgger，也没有证明网络被迫更依赖C。** 它只验证一条端点保持、速度一致的新概率路径可以落地。它未采集当前模型的错误状态，不保证覆盖局部错层、拓扑缺失或真实 rollout 分布。生成采用、接续及质量收益均为UNKNOWN。
