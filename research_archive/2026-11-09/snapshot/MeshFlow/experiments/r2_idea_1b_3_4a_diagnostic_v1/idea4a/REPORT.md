## 锁定的路径

仅对 `valid & ~known`：

```
X(t) = (1-t) Z_H + t Y_OT
U = Y_OT - Z_H
g(t) = 4t(1-t),  g'(t) = 4(1-2t)
S(t) = I + g(t) A
b(t) = g(t) d
X_tilde(t) = S(t) X(t) + b(t)
U_tilde(t) = S(t) U + g'(t) A X(t) + g'(t) d
```

`A=diag(a_x,0,a_z)`，每个 a 独立固定抽自 [-.05,.05]；每路径 d 从 X/Z 半径 .02L 的圆盘均匀抽取，Y分量为0。**.02L约束整个平移向量范数，不是各轴分别.02L。** 使用世界原点缩放，不额外引入 C 中心坐标。常数 A/d 在一个路径所有 t 下不变，由 CPU `default_rng(2026101604)` 预先锁定，数值写入 `registration.json`。L沿用原定义 `sqrt(3)*2/.3762=9.2081382646`。

g(0)=g(1)=0，因此起点噪声、终点 OT 目标都不变。S的所有特征值在[.95,1.05]，全程可逆。这里是改变条件概率路径，监督是它的真实导数；随机 A/d 可作为路径元数据，FM回归学习给定状态/条件/时间下的条件平均速度。它没有收集当前模型 rollout 的错误状态，也没有专家逐状态反馈或迭代聚合，**不是 DAgger**。

C在所有时间逐位等于原 context，known 速度保持0；valid/known、source IDs、角点排列、接口mask与free分母不改。缩放和平移同时作用所有free角点，坐标变换与原面/角点排列可交换。原 width augmentation 先于该路径，不被替换。

2.26485%L是本次有限样本实际观测最大值；.02L只限定平移部分，不限制叠加缩放后的总位移，也不代表任意高幅度噪声角点都有这项上界。尺度实际抽值与各路径平移范数另见 `data_contract_checks.csv`，没有在看到结果后调幅度。

原 stored U 是FP32减法，和此数学诊断FP64相减最大差1.19e-7—2.38e-7；导数差分使用FP64，不能把9.63e-11误当成BF16训练精度认证。归档的扰动状态/目标NPZ转为FP32，原source arrays保持原FP32。

### 旧 endpoint 诊断必须改

即使模型预测完全正确的新速度，`X_tilde+(1-t)U_tilde` 也一般不是 Y。最大例子为 d645…/t=.1：此时状态扰动仅0.8902%L，但旧直线外推错误7.8435%L。该错误来自公式不适用，不是模型失败。

允许使用训练时已知的 A/d 做下列诊断，不把它们作为未知推理标签：

```
X_base = S^-1 (X_tilde - b)
U_base_hat = S^-1 (v_pred - g' A X_base - g' d)
Y_hat = X_base + (1-t) U_base_hat
```

因此端点误差是 `(1-t) S^-1 (v_pred-U_tilde)`，不再直接是 `(1-t)(v_pred-U_tilde)`。固定解析残差 [.1,0,-.1]（不是模型输出）下，正确端点MSE/旧公式MSE为0.93160—1.03299，证实旧 `(1-t)^2 * vMSE` 也不可不改就横比。逐时间计算保存在同一CSV，没有增加样本或模型调用。

## 已知边界与下一步判据

- 这四条检查证明代码/数学路径有可落地的一致形式，不证明它覆盖真实rollout错误，也不证明座面用途、轮廓、接合或CF/FF/I会改善。
- coherent全free仿射扰动不是局部缺边、错误拓扑、复制座面或非刚性错位的完整模拟；也不能由此宣布 exposure bias 是唯一根因。
- 未重新审核全47条来源几何。原风险标签原样保留，扰动未把原目标变成更好的监督。
- 若以后授权训练，需要配对实际生成来判断是否可兑现，并将新的目标能量与原直线FM区别记录。本诊断不自动启动训练，也不自动加大幅度、扩样本或更改默认模型。
