# D0 防拍平：局部 I 收益成立，FF 与接续覆盖保持

日期：2026-10-17。范围：原 C-only SEAM_SLOT_C200 的 16 个固定请求，读取既有 RAW 与单次 D0 后硬锚恢复的 PRE_GEO。**零新生成、零 D0 前向、零模型前向/反向、零 GPU 计算。** 新执行 16 次原 GEO_C 与来源定向、16 次原质量评分；没有容量保护、拉普拉斯平滑或底边平均位移补偿。

**结论：只拒绝 D0 对特定 seam 第三点的法向压平，已经可以降低两个请求的冲突覆盖，且没有损失本面板的既有合法接续。** I 宏均值从 3.3020% 降到 1.8555%；3f/n2 从 42.5293% 降到 23.3887%，仍是明显坏尾。FF 每例完全不变，不能将这次结果称为整体表面质量问题已解决。

## 冻结的单项干预

每张已激活 seam 只使用第三点与重心两个探针。对每个探针，先按**真实有限三角面距离**在完整 C 中选最近面，平局按原 C 面索引；再检查正交投影的三个重心坐标均大于 1e-6。共享底边本身排除，owner C 面保留，避免漏掉正好覆盖 owner 面的内翻。

同时要求：第三点在 owner 边局部标架中向内（r>0）、seam 与所选 C 面的无向法向点积大于 cos15°、距离小于 0.02L。L 固定为 9.2081382646 模型单位。门内风险为 `(1-d/(0.02L))²`，取两个探针的最大值。它是本次独立代理，不是原 I 评分器，更不是覆盖的充要条件。

对 D0 干预，固定 PRE_GEO 为各探针选定的 C 面，RAW/PRE 均对同一面评价。只在风险增加且第三点法向高度绝对值缩小时，恢复 RAW 的有符号法向高度、保留 PRE_GEO 切向分量；多个探针可触发时按风险增量、距离、面索引和探针顺序确定性选一次。法向跨零也按原有符号恢复，不将高度钳到某个选好的新值。

16 请求中，144 个激活 seam 观察有 7 个第三点触发，分布 6 请求。最大位移 0.169414 模型单位，约 1.840%L；C 和全部固定端点逐字节不动，bulk 输入角点不动。没有另加位移门限或参数扫描。完整逐槽与两个探针的前后状态见 [movement.csv](movement.csv)。

## 389 个来源接口与训练损失门禁

[source_gate.json](source_gate.json) 实际读取 50 条条件的 389 个已存合法接口：本代理触发 **0/389**，其中原四训练 C 为 **0/62**。所有逐接口、逐探针结果均保存，没有只保留通过项。这支持在这套来源几何上没有观察到误伤；它不证明任意合法近接表面都不会触发，也不将单条来源共边合法升级为整张来源面无缺陷认证。

与训练臂协调后，用相同的真实有限面选择、1e-6 内投影、r>0、cos15°、0.02L 门进行 CPU 张量核对。训练 loss 使用 `sum(max(0,0.02-d/L)^2)/(2S)`，分母是全部登记 seam 探针，不是命中数。50 条来源条件共 389 边均 loss=0、梯度=0。五个解析例包括向上/向下垂直侧壁、向外共面、向内近共面、向内精确共面；前 3 个放行，后 2 个正确激活。

精确共面例 loss=0.0004，第三点梯度为 `[0,0,+0.00289599]`；梯度下降选择 −C 法向。这里使用事前确定的 detached signed escape：h≤0 选负侧，h>0 选正侧。这个选择解决通常 abs/norm 在零处可能给出零梯度的问题，**不代表物理上负侧必然是正确完成方向**。最近面、内投影、角度与侧别门均离散并停止梯度；两探针可能漏过面内局部覆盖，也可能通过越过门而降低代理。不能将门禁通过等同于训练会降低 I。

实际调用是 55 次 CPU 几何张量求值及 autograd 检查（50 来源批＋5解析例），不是神经网络前向或训练更新。[loss_gate.json](loss_gate.json) 绑定实际训练 loss 源文件 SHA256 `7c60d6c5a3e61dcf941bdaa59e3f99677492aa26f1e5efa47a7cb28d5cc9137e`。
