## 3. 数据怎样构造

先在父对象级建立一个版本化完整目标 M，再从**同一份 M** 提取 C，并令 Y 为其严格面集合补集。没有独立归一化 C，没有用另一个几何版本的 Y 拼接。原件和目标变更映射各自保存。

允许的操作包括精确零面积清理、显式记录的重合副本处理、来源绕序整理、表面保持细分，以及独立登记的高面数 QEM 简化。**没有以“面积小”为由删除正面积三角形，也没有把坐标改变伪装为原面原样保留。** 双面重复表达在新目标里折叠时保留来源记录及可视核查，不宣称所有双面薄壁都是错误。

高面数简化使用隔离安装的 fast-simplification 0.1.12；训练环境没有变更。QEM 操作与 collapse 记录参照[官方用法](https://pyvista.github.io/fast-simplification/)及[重放说明](https://pyvista.github.io/fast-simplification/examples/replay.html)。两次固定提案分别保存，第二次没有覆盖第一次失败结果。

简化准入要求：N=128..256；新目标没有当前检测器认定的非法有限面对、未决面对、非流形边、绕序矛盾或精确零面积面；面积比例在 [0.98,1.02]；双向固定顶点／重心／边中点到有限表面的最大距离、包围盒最大偏移均不超过 0.25%L；边连通分量数量不变；最后实际查看原／新模型。**这是离散探针保真检查，不是连续 Hausdorff 上界证明，也不是完整顶点流形性认证。**

部位候选由几何规则提出，随后实际图审决定是否接受。没有把 BFS 结果直接改名为座面或靠背。检查图包含完整 M、区域、C、Y 及 C+Y；标注说明区分表面、完整部件与组合。例如：

- 完整座板、背板、腿／端架、箱形底座可保留；合理的整组木条也可保留。
- 只有下半截腿、悬空对侧残片、把扶手误叫靠背、把座板底面误叫座面等候选排除。
- 同一个 C 面集合被两个候选名称重复提出时，只保留一个合适标签。
- 闭合部件没有开放边也保留，不为满足 SEAM 人工切开。
- 标签只供数据组织与审阅，**不作为模型输入**。推理输入仅提供 C／N 及允许的元数据，不含未知 Y、来源 owner 标签或完整父几何。

新增 21 个几何合格父的原／新对照和全部 85 条条件提案检查图已实际查看，审阅者记为 **AI_PROXY**，非人类盲评。首批 18 条沿用原封存图审。图上生成时的 NOT_REVIEWED 字样没有静默改写；最终决定以审阅 JSON 与正式清单为准。

## 5. 实际 CPU 训练打包核验

新增 63 条全部执行了一次真实生产 CPU OT 打包，完成 63/63；首批 18 条复用原始 PASS 收据和封存哈希，总计 81/81。新增核验用了 126 个 CPU 噪声数组，只用于打包合同检查，不是模型生成输出。

核验复用原生产实现，检查 C/Y 分区及来源面覆盖、规范化与逆角序、owner/alias、角点固定与 free-only FM 掩码、OT 后 HYBRID0.25 的构造。没有因候选类型不同而偷偷修改评分器或训练匹配定义。新增检查实际用时约 6.54 秒；不能将该耗时当作训练或全数据制作时间。

资源按阶段实测记录在 ledger：几何父审计采用 4 个独立 CPU worker，每个数值线程为 1；渲染独立限线程；最后验收为单 worker。RTX 5080 的现有显存占用仅被读取，没有启动 GPU worker 或干扰用户进程。

工程事件均保留：高面数审计 worker 缺少 Path 导入，在几何审计前失败后修复；最终父表为避免覆盖早期 parents.csv 改用 parents_admission.csv；共享 CSV 辅助函数的换行幂等比较问题由新目录的字节比较包装修正。旧实现及旧文件不变，没有隐瞒模型重试或重算训练。

## 6. 这批数据能说明什么、还缺什么

**可以说明**：已产出 25 父／81 条可进入现有生产数据合同的、更接近真实部件输入的 Bench 数据；完整目标、C/Y 和来源身份一并准备，原缺陷与拒绝原因可追溯。

**不能说明**：数据已达到 47–67 父规模、模型已经泛化、生成 FF/I 会降低，或 25 个来源 ID 就代表 25 个独立款式家族。当前仅排除相同来源与精确几何重复；近似款式家族独立性仍 UNKNOWN。严格几何筛选也可能偏向简单形状，靠背只有 10 个父，复杂细木条等结构不能称充分覆盖。

Chair 的 47 父 FULL、67 父混合适配可作为实际规模参照，不是有效数据量的理论下限。后续若匹配平均每父曝光，应使用

`Bench更新数 = Chair更新数 × (Bench父数 / Chair父数) × (Chair有效batch / Bench有效batch)`。

这个比例只对齐曝光，不会自动补足 Bench 的来源质量、款式和部位覆盖；也不能把同父新增噪声或细分版本当成新增独立椅子。因此本轮没有直接按 25 父启动训练。

下一步数据工作应针对剩下的真实缺口：修复可保真的来源完整目标，或补充新的真实来源，优先完整靠背、腿／端架与复杂长椅结构。单纯复制这 81 条、增加随机裁面或再放宽准入门槛不能完成扩父目标。当前有界自动补充已停止，原 47–67 父目标明确记录为数据数量阻塞。
