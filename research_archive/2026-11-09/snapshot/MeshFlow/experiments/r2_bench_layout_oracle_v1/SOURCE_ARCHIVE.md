# 本轮源码快照

此快照用于复核 `R2_BENCH_LAYOUT_ORACLE_V1` 的实际实现，不包含权重或数据。最终报告和新增审阅材料可以继续保存于实验目录；已封存的 `source_archive/`、`code.diff`、`source_hashes.json` 不应随报告更新而重写。

- `source_archive/`：266 个小源码文件，合计 2,739,981 字节（约 2.61 MiB）。包括本轮独立包、实际评分器与后处理、生成器和 D0 小源码，以及登记的训练/推理依赖和静态本地 Python 导入依赖。
- `source_hashes.json`：记录每份原路径、归档相对路径、字节数、SHA-256、来源登记及角色。186 个已有冻结登记的源码哈希全部核对通过；其他静态依赖属于当前快照，不额外宣称它们已经经过历史冻结核验。
- `code.diff`：只把本轮 13 个独立包文件和 1 个归档工具表示为 `/dev/null` 新增文件；不混入整个工作区的历史未提交内容，不把继承源码表示成新方法改动。

继承源码保持原样；归档复制逐文件重新核对 SHA-256。外部小评分源码 `E:/MeshFlow-Control/...` 放在 `_external/E/MeshFlow-Control/...`，保留来源身份，不伪装为本仓库的新实现。快照使用保守的登记/静态依赖闭包，因此可能包含未在某次运行分支执行的辅助函数；它不是动态函数覆盖率证明，也不打包第三方 Python 安装环境。

归档时只读核对的 Git HEAD 为 `7af33f892b8fb6194fbc54748b6010cf54507169`，命令使用临时 `-c safe.directory=E:/MeshFlow`。当时追踪文件 diff 仅列出已有 `r2/README.md`；该修改不纳入本轮 `code.diff`。没有修改 Git 配置、索引，没有 commit 或 push。

本归档操作没有执行模型前向、反向、优化器更新或 GPU 工作，没有复制权重、网格和训练数据。生成入口是 `archive_tools/archive_sources.py`；它在输出已存在时拒绝覆盖。后续若必须封存新增代码，另建补充快照并说明与本快照的关系。
