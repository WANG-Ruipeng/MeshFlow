# R2_BENCH_LAYOUT_ORACLE_V1：方法与比较合同

本轮检验：**在相同 Bench 条件生成器起点和更新预算下，少量正确的来源结构范围信息，能否改善 RAW 中围绕 C 的主体组织，并在统一后端后保住收益。**

这是 `SOURCE_PRIVILEGED_COARSE_REGIONS` 实验。来源完整体用于提供粗布局 P，属于额外信息；结果不等于只输入 C 的部署能力，也不是严格数学上界。本轮既不训练从 C 预测 P 的模型，也不实现完整部件生成、部件数量预测、拓扑预测或双侧接头生成。

本文件描述冻结的方法与预算，不预先宣告实验成功或训练已经完成。执行状态、实际成本和最终数值由运行账本与最终报告记录。

## 1. 起点与两条训练臂

两臂均继承同一保留的 EXPOSURE live 生成器及其匹配的 AdamW、随机状态：

- 来源：`experiments/r2_bench_four_routes_v1/exposure/training/M_PLUS3000/checkpoint_step3000.pt`。
- 来源累计步数：global25500，COMMON12000＋Native13500；无 EMA/live 混接。
- 来源文件 SHA256：`3c1e9e1db0f9a462632bd70a91b5acaa4bef1dd40ad20ad90a194ab17bbd49fd`。
- 每臂新增 1000 次更新，预定终点 global26500／Native14500；不按生成图像挑选中间检查点。

| 训练臂 | 生成器输入 | 优化范围 |
|---|---|---|
| PLAIN | 原始 C、当前 free 状态、t、总 N | 原 Native/T1＋role＋Geo 全参数续训 |
| LAYOUT | 相同输入，另加粗来源区域 P，按登记日程整组缺失 | 相同原参数＋新增布局读取分支 |

两臂共享完整目标、C、实际 N、父曝光、CLEAN/X_WIDTH 配对、时间、噪声、HYBRID 噪声和角点排列身份。没有为候选新增父、重建目标、修复源网格、改面数或加入 LOW 版本。

## 2. P 的信息内容与来源

固定两槽，顺序为 `BACK_REGION`、`SUPPORT_REGION`。每槽为 8 维 float32：

\[
p_j=\left[(m_j-o_C)/L,\; (u_j-l_j)/L,\; e_j\right],
\qquad m_j=(u_j+l_j)/2,
\]

其中：

- \(l_j,u_j\) 是该类别已核验、非 C 的来源区域联合轴对齐包围盒；传入的是**完整跨度**，不是半跨度。
- \(o_C\) 是当前 C 三角形按面积加权的表面中心。
- \(L=2\sqrt3/0.3762\approx9.2081382646\) 为固定模型长度；不随输出包围盒改变。
- \(e_j\) 是 BACK／SUPPORT 的二维 one-hot。
- 另传 `bool[2]` 有效掩码。无可靠区域的槽是 UNKNOWN，不能解释为该部位不存在。

一个 SUPPORT_REGION 可以包含座壳下部、端架、底座或支撑组合；它不保证对应单条腿、一个连通分量或全部支撑。每类区域取联合范围，因此同一框可能包住多个分离结构及中间空隙。两个框不能表达完整的部件数目、内部空洞、精细姿态或全部连接关系。

模型不接收来源面 ID、目标逐角点坐标、源顶点连接或 free 槽到部件的对应。面 ID 和区域几何只保存在审计文件中，用来复核框的来源。粗框本身仍是来自未知完整目标的额外信息，不能因信息量较低而把它叫作 C-only。

数据共覆盖 33 个唯一训练／评价条件：26 个条件继承已接受的区域记录，复用前要求完整目标三角数组逐项相同；另外 7 个训练父通过实际三视图检查接受了粗支撑区域。7 个新区域包含 27eb79 和 6 个 HIGH 父，其 BACK 槽保持 UNKNOWN。新检查是非盲 AI_PROXY 来源整理，不是独立人类图审，也不是生成输出质量判断。

每个框排除当前 C 的源面。历史版本不一致的区域不转移，不因名称像“腿”就接受其语义。详细来源、已知缺口和实际图审见 [数据合同](data/DATA_CONTRACT.md)、[区域记录](data/layout_records.json) 和 [新来源区域图审](data/manual_source_review.json)。

## 3. 坐标、增强与缺失输入

原生成器继续在原世界／模型坐标中运行。只把 P 的中心写成相对 C 中心的偏移；没有旋转到新的 C 框架，也没有缩放整个生成状态。此方案不声称 SIM(3) 等变性。

X_WIDTH 增强中，P 的绝对 x 上下界与 C/Y 同乘该样本的正 alpha，再从实际 C 重新计算中心和 token。预训练准备对 33 个条件的 alpha=0.9、1.0、1.1 做了独立数组核对，P 与变换后来源区域重算一致。

LAYOUT 的名义整布局缺失率为 20%；在冻结的 8000 个训练实例中，实际 **1662/8000＝20.775%** 全部掩码为 false，其余 6338 个实例保留可用 P。同一 CLEAN/X_WIDTH 配对共享缺失标志，即 4000 对中的 831 对整对缺失。缺失样本不是“来源没有支撑／靠背”的负标签。

训练日程由实例身份预先决定缺失，不在模型前向中新增随机 dropout。PLAIN 使用同一父和随机流日程，但不读取 P。

## 4. 新增布局读取模块

新增参数仅属于 `layout_branch.`，共 **111,424** 个。单次 64 维、4 头交叉注意力位于 Native 的坐标、role 和 Geo embedding 之后、12 层原主干之前。

对当前每个角点 hidden \(h_i\) 与坐标 \(x_i\)，查询为：

\[
q_i=W_h\operatorname{LN}(h_i)+W_x(x_i-o_C)/L.
\]

P 经两层带 SiLU 的小型编码器得到 key/value，再按有效区域做 4 头 attention。所得上下文通过零初始化的输出矩阵 \(W_o\) 投影回原 hidden 维度：

\[
h'_i=h_i+W_o\operatorname{Attn}(q_i,K(P),V(P)).
\]

只有有效 free 角点接收残差。C 角点、padding 和整组缺失样本保留原 hidden；P 不增加网格面、不占 N、不锁定 F 坐标，也不直接保证接触或接续。

当只有一个有效区域时，attention 的值汇总为该区域的同一编码；此时新增分支主要提供全局区域条件，不能宣称已经对每个 free 角点做出了局部部件归属。后续主干仍负责将区域信息与位置／已有条件结合。

原时间调制、count 条件、T1 known 时间、Geo 和 12 层主干运算保留。新增分支以 FP32 运算，加回后转换为继承的 hidden dtype；原前向继续 BF16，参数与积分状态 FP32。分支保持 eval，仍可求梯度。

输出矩阵初始为零。CPU 缩小宽度的真实 DiT 算子检查确认：初始有 P 的输出及输入 VJP 与原路径一致；分支权重非零后，全缺失 P 仍有严格零增量。这是实现合同，不是生成质量保证。生产规模实际调用由正式训练／采样账本记录，不把缩小 CPU fixture 冒称大模型实验。

实现见 [model.py](../../r2/pilots/bench_layout_oracle_v1/model.py)，核验范围见 [CPU模型门禁](audits/model_cpu_gate.json)。

## 5. 损失、优化器与曝光

继续使用原 free-only Flow Matching、原 free OT 后 HYBRID0.25、batch8／microbatch1、确定性 SDPA math、TF32关闭及原 free 分母。没有添加布局回归损失、相交损失、连接损失或新教师。

原生成器所有参数继续训练，其 AdamW 完整继承 EXPOSURE 的参数身份、moment 与累计步数。新增布局分支另有 fresh AdamW，局部步数从0到1000；两优化器使用相同 `lr=1e-5, betas=(0.9,0.95), eps=1e-8, weight_decay=0`。同一完整 batch 的梯度共同做原阈值的梯度裁剪，再在一次登记的更新内分别执行两个优化器。新增分支不占用或重置原参数的优化器状态。

原 30 个 TRAIN 父全部保留：OLD22、FOCUS2、HIGH6。每臂 8000 实例的曝光仍为 OLD6000、FOCUS1000、HIGH1000；各 FOCUS 父500次，各 OLD 父272或274次，各 HIGH 父166或168次。继续采用登记的原组 FM 系数，不能把此设计说成30父全局均匀曝光。

PLAIN 与 LAYOUT 的第一层比较包含新增支路及额外结构信息这项完整方法变化，并非等参数量消融。下面的同权重 NULL 对照用于进一步检查推理时 P 是否有增量。

## 6. 固定评价与同权重 NULL

复用六父、每父原两份固定噪声，共12请求：熟悉 FOCUS 父 a8e987、27eb79，熟悉 HIGH 父 bcb4f5，历史 DEV 父459f90、f495bd，以及当前训练留出 df6fd3。旧 DEV 不是新的独立测试集；当前适配未见与官方预训练未见不是同一概念。

| 标签 | 权重 | P |
|---|---|---|
| EXPOSURE | 原冻结起点的已有输出，只读复用 | 无 |
| PLAIN1000 | 普通续训固定终点 | 无 |
| LAYOUT1000 | 布局续训固定终点 | 正确来源粗区域 |
| LAYOUT_NULL | 与 LAYOUT1000 **完全相同的权重** | 两槽均屏蔽 |

LAYOUT_NULL 的缺失情况在训练中已有明确覆盖。LAYOUT1000 与 NULL 的同噪声比较检查当前权重对 P 的实际利用；它不单独识别训练期间额外监督、参数容量或优化轨迹的全部作用。

新生成固定为三标签×12请求＝36份 RAW，Euler50共1800次逻辑向量场调用。全部新 RAW 保存之后才执行36次单次官方 Bench D0。没有新噪声、重抽、错误布局扫描或结果出炉后换请求。

所有标签分别保留 RAW、BASE_POST 与 CLEAN_FINAL_POST。统一后端为：单次官方 Bench D0 → GEO_C／来源绕序恢复 → HINGE_OPP015 → ALPHA → HOLE；不因为来源布局候选而改变后端门槛，也不加入 RBF、多次去噪或新接头。

预定108条新评分与36条复用评分，共144行原177字段。保留原物理查询、相同视角与位置截面，实际图审标为 AI_PROXY；不能由指标自动生成视觉标签。

## 7. 判断与停止规则

主要问题是同一输出是否同时满足合理采用 C、主体合理、主要支撑保留；观察 RAW 中灰色替代座面、结构错位和碎片是否改善，再观察这些结构经过后端是否保留。CF／FF／I、小角、面积与删面、合法接口及逐父变化作为完整代价一并报告。

不以贴近唯一来源款式作为开放生成成功标准；也不把“框相符”“有响应”“FM下降”单独当作成功。I沿用当前C查询域定义，不是全网格冲突率。低FF若同时出现支撑被删除或大幅表面损失，不能直接判质量升级。

如果额外来源布局在多个请求上带来可控代价的 RAW 组织收益，才有依据继续研究只凭 C 的多解布局预测。若仅对熟悉父有效，应记录其适配范围；若 RAW 改善而后端损伤，分别保留两阶段结论。若本实现和1000步预算未见收益，不自动延长、不训练更大的预测器，也不能宣称所有布局表示已被证伪。

固定终点与评价完成后停止。默认模型、原数据、评分器、历史结果保持；本轮没有自动清理、commit或push。
