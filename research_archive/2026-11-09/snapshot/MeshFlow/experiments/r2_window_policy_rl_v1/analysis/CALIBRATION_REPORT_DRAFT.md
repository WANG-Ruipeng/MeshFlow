**窗口轨迹 RL：冻结基座噪声校准报告草稿**

记录日期：2026-10-16。范围仅为校准完成、真实盲审解盲及训练准入；本文不读取或报告后续 RL 训练和最终评价结果。写作仅使用既有文件，新增模型调用、训练更新、几何重评分均为 0。

校准结论是：三档随机窗口噪声均通过事前登记的工程准入门，按“全部通过者中选最小 σ”选择 **S005（σ=0.005）**，窗口固定为 Euler 第 10–29 步。S005 的 POST 合法 CF 接口输出为 25/64，与确定性 FULL_DET 的 25/64 相同；它保留 24/25 个基线正例，同时新增 1 个正例。因此目前证据支持开展已授权的有限训练，**尚未证明随机注噪提升连接率，更没有证明 RL 已经带来收益**。[实际完整门](decode_gate.json)、[数值汇总](calibration_quantitative.json)。

**协议与执行范围。** 用户附件规定先做冻结 FULL_S6000 标定，再决定是否训练；附件没有实际测量结果。其最近的历史路线为 NFT 端点回归适配；本轮拟训练目标转为窗口内随机动作的 score-function 梯度。校准本身始终加载原冻结 FULL_S6000、reference 模式，未加载训练后的 NFT/SELF_FM 适配器，也没有优化参数。

本轮采用 8 条原 TRAIN C，每条 8 个预登记初始噪声，共 64 个请求；比较 FULL_DET、S005、S010、S020 四种设置。每个请求的 C、初始 Gaussian 和窗口转移 Gaussian 数组按哈希配对，四种设置仅改变是否注噪及 σ。σ 为**每步状态转移的常数标准差，单位为模型坐标**，并非乘上 sqrt(Δt) 前的系数。Euler50、Δt=0.02 不变，随机窗口 20 步，噪声仅作用于 d=9(N−K) 个有效 free 坐标；已知 C 不进入噪声或概率维度。

从现有 256 份采样 receipt 累计得到 256 次新 rollout、12,800 次生成器前向，全部 COMPLETE、reference 模式，全部 51 状态 C 逐位保持及已登记采样合同通过。执行证据还包含 256 次单次官方 D0、256 份 GEO_C/来源定向 POST、512 份原版 RAW/POST 评分。512 评分行全部 PASS 且 C 保持为真；没有丢弃失败结果以缩小分母。64 个确定性输出明确记为 DETERMINISTIC_NOT_DEFINED，不伪造 σ=0 的概率密度；192 个随机输出使用完整联合 Gaussian 密度，并通过数值有限性门。校准阶段优化器更新数为 0。[预登记](../registration.json)、[逐输出原评分汇总](calibration_per_output_stage.csv)。

所有下表都保留原 64 请求分母。每条 C 恰为 8 次，逐输出宏均与先对每条 C 取 8 次平均、再对 8 条 C 等权平均一致；不是把不同 face 数的输出合并成一个总体分母。

**事前工程门及实际选择。** 门槛为混合奖励条件至少 4/8；平均连接率至少为 DET 的 80%；配对保留 DET 正例至少 75%；POST 平均 CF、FF、I 相对 DET 的增量分别不超过 +2、+3、+1 个百分点；主体 YES 最多减少 2/64，新主体损坏上界最多 2；C 保持、数值有限及原评分/receipt 合同全部通过。DET 与候选各至少需要 56/64 个确定的主体标签，DET YES→候选 UNKNOWN 计入潜在新损坏。若无档通过就停止，不训练。这些是本轮预登记的有限工程筛选阈值，**不是附件已给出的实测结论，也不是文献保证或通用质量标准**。[冻结缺失值及主体口径](../gate_contract.json)。

**真实盲审、采用与同输出联合。** 两名 AI_PROXY 各实际查看 32 页完整原图、各评 128 个匿名输出；合计 64 页、256 输出。每份输出只有一名分工评阅者，不是双评阅者一致性研究。图审时模型身份和分数隐藏，C 与 RAW/POST 可见；采用与主体分别判定 YES/NO/UNKNOWN。主体允许合理不同椅型、板式/弯曲支撑、开放背，不以来源 GT 样式、固定四腿或局部无缺陷作为 YES 条件；图像不认证拓扑合法性、机械稳定性或人类接受度。

四档 RAW 的合法 CF 均为 0/64；POST 的 24–25/64 来自同一冻结“生成＋单次 D0＋GEO_C＋来源定向”流程，不能归因于 RAW 已直接生成共享边。以 DET 为例，FF 宏均由 RAW 的 85.7883% 降至 POST 的 13.6508%，但伴随平均删除 34.641 个 free 面；S005 为 85.6609%→14.2122%，平均删除 35.125 个。此处不能仅凭 FF 降低就宣布完整成品改善，也不声称变化只由删面造成。[完整尾部分布](calibration_all_geometry_tails.csv)、[全部配对](calibration_paired_stage.csv)。
