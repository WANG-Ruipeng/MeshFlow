# Actual image review protocol

Frozen before any RELATION_V1_S1500 evaluation output is available. This is a nonblind AI_PROXY review of all 144 registered comparison pages (48 requests × RAW/BASE_POST/CLEAN_FINAL_POST), with three model cells per page. It is not an independent human study or a new held-out test.

Use the two inherited views and both fixed-position sections. Do not grade resemblance to the unique source completion. Blue C is the provided input, orange is SEAM, gray is BULK and green is an added bridge. Section endpoints alone do not prove cracks, disconnected topology or floating surfaces.

For each actual model/stage cell record the following existing five-axis vocabulary:

- overall_shape: REASONABLE / INCOMPLETE / UNCERTAIN
- C_use: PLAUSIBLE / REPLACED_OR_IGNORED / UNCERTAIN
- support_retention: PRESENT / MISSING_OR_DAMAGED / UNCERTAIN
- visible_fragment_or_gap: YES / NO_OBVIOUS / UNCERTAIN
- layering_or_fold: YES / NO_OBVIOUS / UNCERTAIN

The first three axes describe a plausible complete Bench, the input's participation, and visible support structure. A visually complete shape can still replace or ignore C. Assign UNCERTAIN when occlusion, finite sections, sparse input semantics or projection prevents a reliable judgment. NO_OBVIOUS is not a certificate of defect absence. Apparent folds/fragments are visual observations, not exact geometric-intersection/connectivity claims.

Each row must retain request_id, parent_id, condition_id, label, stage, page_id, image path and SHA256, actual-view source, reviewer_kind=AI_PROXY, blind=false, actually_viewed=true, the five axes and a concise observation. Review all three columns in the same round; do not convert old USER text reviews to numerical labels. Keep original historical reviews unchanged.

Reviewers may use contact sheets to navigate; when recording a cell they must inspect the corresponding full comparison page or a sufficiently detailed view of it. Do not assign image labels from metric values. Exact topology, CF/FF/I and deleted-face costs remain separate numeric evidence. Root review may add an explicitly documented adjudication row instead of silently overwriting a reviewer's original observation.

Historical TRAIN denotes the four parents seen during COMMON12000 and is a regression group. All 48 requests are outside the new 26-parent adaptation pool; historical DEV is reported separately. Do not call the whole panel unseen across all training history.

No image filtering, best-checkpoint selection, additional sampling, new noise, model calls or scorer changes are authorized by this review.
