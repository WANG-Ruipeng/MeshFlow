## 2. 为什么采用这些超参数

本轮选择的是已稳定完成、便于比较的既有配方，**没有执行超参数搜索，也不声称最优或已经收敛**。

- 起点：`A_COMMON_LR1E5/checkpoint_step0.pt`，COMMON global12000的live参数、空AdamW及相同RNG。与A和旧USER v2起点完全一致；不是从旧USER v2的1500终点继续。
- 生成器实测参数量 **130,401,155（约130.4M）**，引用旧相同初始化收据；不能把约521MB的FP32生成器文件误写成521M参数。参数量本身不能推出26父足够或1500步最优。
- 模型/目标：原Native/T1＋role＋Geo＋同步owner-only SEAM；原free-only角点FM、受限OT后HYBRID0.25。没有新增占用头训练、几何loss、异步时间、平移或参数。
- 优化器：全参数AdamW，lr1e-5、betas(.9,.95)、eps1e-8、wd0、clip1。旧Bench强度实验中仅降低主干lr至2e-6没有带来整体升级，因此这轮不同时换学习率。
- batch8/micro1：每步4个不同父，每个父一份原尺度和一份共同XYZ U[.92,1.08]增强。父打乱均衡、父内部位/条件轮换；仅新清单导致新日程。父选择与噪声不能声称逐实例和旧USER完全配对，因为父数/条件池已经改变。
- BF16前向、FP32参数/优化器/积分、SDPA math、TF32关闭、严格确定性、CUBLAS=:4096:8保持。
- 固定1500更新，到global13500，12000前向/反向；没有额外神经探针。选择该预算是为了直接比较旧USER/A，而不是承诺训练充分。只交预定step1500主结果，不回看挑最佳中间点。

旧USER同配方实际训练约2259秒，RAW48约202秒、D0约62秒；这只是资源和工作量参照。本轮数值线程、其它用户进程及资源观察会影响墙钟，不能当隔离硬件benchmark。实际新loss曲线/曝光/调用量必须以新账本为准。

## 3. 哪些因素可直接比较，哪些不能

主参照为 **USER_V2_S1500**；A_S1500为次参照。新训练与旧USER共用初始化、优化器超参、模型、损失、更新数和评测。旧81条完整目标/条件不变，因此差异比旧A→USER v2更集中于本次覆盖增补；但仍同时包含一个新父、四父的新条件，以及父/部位曝光重新分配。

不可以把结果单独归因为“曲面”“输入部位标签”“干净数据”“独立父数”“过拟合降低”中的任意一项。尤其COMMON12000含旧数据历史，本轮不是从官方生成器开始的全干净训练。

A训练池为58父/195条，旧USER为25父/81条，本轮为26父/91条。A可以说明历史系统位置，但与本轮有更大的目标/条件分布差异，不能代替本轮对旧USER的主要比较。

评测使用同一48请求、同一C/N/K、OLD_S15000预测布局、保存的高斯噪声、查询、相机、画框和front/side截面；旧模型输出不重生成。全部新48 RAW完成后才执行单次官方D0，并统一恢复C/seam→GEO_C/来源定向→BASE_POST→HINGE_OPP015→ALPHA→HOLE→CLEAN_FINAL_POST。

三阶段合计144新增评分行。旧USER和A各144行只读复用，完整三模型表共432行。相同评分字段/后处理定义必须逐源hash核对；不使用旧失真的汇总 `boundary_edges` 字段：沿用修正collector，输入边界另记 `C_boundary_edges`，原网格字段不覆盖。

## 6. 旧图审schema不能混为同一套成功率

旧A有五轴逐模型/阶段记录，位于 `r2_bench_adaptation_strength_v1/visual_review/validated_records.json`：

| 轴 | 实际枚举值 |
|---|---|
| overall_shape | REASONABLE / INCOMPLETE / UNCERTAIN |
| C_use | PLAUSIBLE / REPLACED_OR_IGNORED / UNCERTAIN |
| support_retention | PRESENT / MISSING_OR_DAMAGED / UNCERTAIN |
| visible_fragment_or_gap | YES / NO_OBVIOUS / UNCERTAIN |
| layering_or_fold | YES / NO_OBVIOUS / UNCERTAIN |

记录绑定request/model/stage/page、图像与receipt/hash，`reviewer_kind=AI_PROXY`、`blind=false`、`actually_viewed=true`。旧A DEV最终各轴计数依次为整体18/5/9、用途13/7/12、支撑24/7/1、碎片18/1/13、错层18/3/11；这是旧当轮实际图审，不应与新评阅直接拼成同一轮盲评统计。

旧USER不同：实际看12张父级联系图，覆盖144个A/USER配对页面，另看5页原分辨率。`actual_review.csv` 保存跨阶段文字观察、图片hash、联系图hash、是否原分辨率查看；`numerical_adoption_label=NOT_ASSIGNED`，`independent_human_rating=false`。因此不能从旧USER资料凭空补出13/32之类的采用计数，也不能把144行当144个独立人类打分。

本轮新三模型图册必须实际查看后才写观察。可以沿用清楚的文字观察与不确定标签；若使用五轴标签，须对三列同轮实际评阅，不能把旧USER文本自动转换为新数字。截图尺度和断面可帮助判断主体/C空间关系，但细裂缝、拓扑与是否真实漂浮不能仅凭截面端点认证。

## 7. 后续报告的解释边界

应先回答：相对旧USER v2，新数据方案是否在多个固定条件/噪声上改善整体形状及C用途，且没有被碎片、缺面、FF/I或保面代价抵消。其次再看A参照。保持RAW与两POST阶段分开，逐父/部位、逐条件/噪声记录实际得失。

无论结果如何，都不能由这一条1500步臂宣布全局最优、普遍泛化、大规模扩父完成，或已经唯一证明问题出在数据。更新总数相同不代表逐父/条件曝光相同；本轮父曝光下降约3.75%–4.17%，新条件曝光取代了部分旧条件曝光。

本文件截至写入只准备历史证据与合同说明；RELATION_V1_S1500终点质量、实际训练调用、图审和胜负结论均待主流程完成后另行记录。
