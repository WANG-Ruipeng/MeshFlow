# 冻结 EXPOSURE：同一条件表面的三角划分与面数嵌入检验

状态：完成；日期：2026-10-28。零训练，未更换默认模型或后端。

**真实模型存在三角划分表示敏感性，也存在面数嵌入档位敏感性；把 C 的面数增加到四倍没有形成稳定的采用或质量收益。** 这轮把云端小模型的假说推进到了真实 EXPOSURE，但没有证明 softmax 数量稀释是唯一原因，更没有验证计数归一化修复。

最清楚的反例是 bcb/n1：同一物理 C、同一 free 噪声、同一 free 面数，且面数嵌入档位不变，仅细分 C 就让原来合理采用蓝色座面的弧形框架变成异向的灰色座板/支架，蓝 C 与主体关系变差。另一方面，bcb/n0 仍保留原组织，f495 有更清楚暴露并使用蓝 C 的局部视觉信号。不能把这解释成“加面必好”或“加面必坏”。

## 判断与下一步边界

1. 云端“小K读取可能有优化困难”的假说，在真实模型上得到更具体的关联证据：输入表面表达方式确实会影响生成，且可能影响采用；不是只有代理小模型才有变化。
2. 但“多给几张面就能修好”“459都由小K造成”“直接加log(F/K)一定有效”均不获支持。本轮不是新的质量正结果，不替换EXPOSURE。
3. 若继续，优先目标应是**同一物理条件在不同合法三角划分下的用途稳定性**，而非最大化C注意力或要求同噪声复制完全相同款式。方法候选需分别处理几何表示与N计数条件；不能把count档位变化偷混入K效果，也不能未经验证全面消除模型对真实N的响应。
4. 只建议一个后续可检验假说：训练时让同一C表面出现配对合法划分，是否能降低“划分改变导致采用失败”的转移，同时保住原划分的质量。它尚未训练；如何控制N与free预算应另行冻结。不能据本轮自动重开R16/R28读取支路或碰撞loss。

本轮到此停止，不增加噪声、训练、D0、后端修复、自动清理、commit或push。
