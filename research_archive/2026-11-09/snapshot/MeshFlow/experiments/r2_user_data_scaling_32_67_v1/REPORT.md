# R2 USER 数据覆盖：32父对67父，完成报告

状态：**COMPLETE**。科学主终点为两臂各6000更新，全部420个逻辑RAW、420个POST、840条评分和840条实际图审完成。报告生成时间：2026-10-12T10:10:23.592710+00:00。本轮已结束科学计算；不切默认模型，不commit或push。

**结论：扩大到67父带来了部分相交、折片质量收益，但尚未可靠提高新USER输入的采用和接续。** 它是值得保留的数据覆盖信号，不能记为“扩大父池已经解决控制”，也不足以直接把下一笔预算全部投入256父。反过来，本次也不能否定更大规模的价值：这里只比较一个嵌套子集、一条训练流、同样6000步。

新32父的POST中，EXPANDED相对SMALL：CF −0.700个百分点、FF −2.532个百分点；I反而+0.648个百分点。严格A-VMR从4.191%降至3.165%，合法接口输出仍为7/128；图审明确采用C从59到63份，但明确未采用也从30到33份。改善主要落在部分几何质量与靠背输入，不是普遍接合成功。

## 2. 两臂实际怎样训练

从同一官方Chair生成器EMA及同一Native/T1＋role＋Geo初始化开始，fresh AdamW，累计step0→6000；不从旧R2或USER_MIX续训。194个参数张量、130,401,155个参数；继承182个官方主干张量，role／Geo出口为零，所有参数FP32并可训练。零出口不承诺带C前向与无条件模型逐位等价。

固定R2全程clean/width混合＋全程HYBRID0.25，USER-only FM；batch8、microbatch1、每批8不同父、4clean和4共同X宽度U[0.9,1.1]增强。先用原Gaussian做free-only OT再混噪，不重新OT；FM用本批有效free标量总分母 `9*sum(N-K)`。AdamW lr=1e−5、betas=(0.9,0.95)、weight_decay=0、clip=1；无scheduler、无训练EMA、无辅助头。模型eval模式但参数参与梯度，确定性数学SDPA；BF16前向、FP32参数/优化器/积分、TF32关闭、严格确定性、CUBLAS配置固定。

预检16次真实更新另计且丢弃，包含160F/128B；16个一致性fixture通过。03:27:42 UTC在正式训练之前锁定6000步，没有降为4000，没有按效果挑best。每2000步轮换单GPU worker，恢复各自完整优化器及RNG。固定4000及6000完整权重均保留。两臂正式各48000F/48000B/6000更新，合计12000更新；失败调用0、待结算0、模型重试0。

## 7. 下一步只优先验证一个问题

**优先做来源完成目标质量的受控小对照，暂不把直接扩到256父／更大N当成已验证的修复方案。** 保留当前模型、R2配方、父集与用户C；先对已确认的Y重复/穿插建立可追溯的原目标与可信修正目标，再在相同预算下比较。不能可靠修正的记录为未决，不为了“干净”删除整类结构。此处仅提出下一轮假说，本轮不执行修网、训练、新loss或默认切换。

检验假说：增加不同椅子已经减少一部分折片与FF，但完成目标中的错误层或连接答案可能限制C采用与接续；若保持C及父身份的目标质量修正能降低I_dup和明确替代/错层，同时提高多个父的合法接口且不增加主体/支撑缺失，这条解释获得支持。若只降几何冲突而采用/接口仍不改善，应撤回“主要是目标质量”的解释，转向条件到连接的生成机制。当前按Y标签的关联只是提出这一假说的依据，不是已经验证的因果关系。

本轮对七项问题的回答是：独立父确实增加；整体采用证据混合且座面未解决；接续没有普遍提升；CF/FF/折片有收益但I和严格匹配有代价；对HIST也有取舍；训练覆盖确实被学习但泛化到接合不足；下一笔预算优先验证目标质量，不自动扩大任务。
