# Bench 完整座面结构覆盖与旧池回放

本轮用户授权保留 `R2_BENCH_FULL_SEAT_CURRICULUM_V1` 的 Native6000 与 SEAM3000，并在其基础上测试新增结构数据。SEAM3000 是当前用户选定的 Bench 研究参考；这不等于所有指标或未见父上均优于旧结果，也不改变维护中的 Chair CLI 默认。

## 问题与范围

从 Native6000（累计18000更新）接出一条普通条件生成候选，检验加入其他完整座面结构、并回放原22父后，是否扩大 RAW 的合理采用与主体组织覆盖，并保住已学能力。训练只使用原 Native/T1、role、Geo、free-only FM、OT 后 HYBRID0.25，不新增网络、loss、头训练、平移增强、去噪器改动或自动 SEAM 续训。

这一轮是工程版本比较。候选比冻结起点增加了更新，并改变数据与采样分布；不能把结果单独归因于新增父。原 SEAM3000 是表示不同的现状参照，Native6000 才是直接前后对照。

## 数据

保留原22父全部合格完整座面，不依生成效果挑回放样本。优先从现有可信完整目标制作不在该22父池中的完整座面 C；K≥2、N128..256，C/Y 必须来自同一目标和坐标框架。新 C 保存原面ID、原绕序、完整目标身份与继承的质量证据，实际审阅 M/C/Y。

原目标只读，不为达到数量删结构或强行压面。原 DEV 和此前已锁定留出父不进入训练。按父冻结新增训练与留出身份后再产生评测噪声。区分“新于22父课程池”“新于COMMON12000起点”“历史适配见过”和“官方预训练未知”；同父变体不计新增独立父，不把独立来源ID当成款式完全独立的证明。

本轮不以冻结旧占用头预测正确作为 Native 数据准入条件。候选只生成普通 free，无占用头调用。若无法形成至少两个合格新池父，保留实际制作与阻塞证据，不把原22父重复训练称扩覆盖。

## 训练

本轮实际增量锁定为 a8e987、27eb79 两个新于当前 COMMON/Native 谱系的训练父，df6fd3 为该谱系未见留出；三者均属于官方训练来源，且在项目其他历史分支中出现过。a8e987 与 df6fd3 保留来源 T-junction：C 有限面无非法相交或正面积重叠，但不是共形流形。原 QUARANTINE 记录保持；本轮 Native 三角面输入单独准入，不认证索引共边，不修改目标或 C。3e4f4c 与 d9de3b 因完整座面语义不符不录用。

用户已明确选择 1,500 步。两个 NEW 父各曝光3,000次，原22父合计曝光6,000次；这是少量结构的密集适配，不是大规模扩父。新增评测3条C、每条2噪声；保留旧24请求。新增RAW/D0各36份，复用旧48份，三阶段总评分252条。

初始预算为一臂新增1500更新，以开训前 `budget.json` 和 registration 为权威。起点为 Native6000 完整 live checkpoint，继承匹配 AdamW、参数组顺序与 RNG；新分支局部步0，对应累计18000。预定终点评价，不挑 best，不自动加长。

每步4个不同父：旧池2父、新池2父；每父 identity 和 x-width U[0.9,1.1] 各一例，batch8/micro1。各池内父均衡；固定采样流与每例噪声、epsilon、时间、排列种子。记录实际每父曝光，2:2 是本轮工程配额，不是已验证最优比例。

其余沿上一轮：lr1e-5、AdamW betas(0.9,0.95)、weight_decay0、clip1、BF16前向、FP32参数/优化器/积分、math SDPA、严格确定性、禁用TF32，CUDA前设置 CUBLAS_WORKSPACE_CONFIG=:4096:8。

## 评价与判读

旧24请求、固定噪声、查询点和截面全部保留。冻结 Native6000 和 SEAM3000 的旧产物直接引用；新增父请求对冻结 Native6000 和候选使用相同输入与噪声。具体父级划分、数量与调用预算在开训前冻结，不根据结果换父或噪声。

仍为 Euler50 → 单次官方 Bench D0 → GEO_C/来源定向 → HINGE_OPP015 → ALPHA → HOLE，全部新增 RAW 保存后才做 D0。原评分器保持只读，保留逐输出全字段、分母、NA与失败。Native 的 seam 专属量为 NA。

主判读同时看 C 合理采用、完整主体、主要支撑是否在同一输出成立；CF、FF、I、小角、碎片、面积和删面作为代价。固定两视角和原位截面，实际非盲 AI_PROXY 评阅单独记录。训练池、追加留出和旧 DEV 分开报告；后处理损伤不算生成器尚未学会，删得更多也不自动算质量更好。

## 资源、恢复、边界

每个GPU派发前保存真实资源，至少保留 max(2GiB,10%总显存) 余量；训练只一条已授权臂。独立冻结参考采样在训练代表性峰值后按实测余量决定是否并行，CPU工作限制线程。WDDM进程峰值不可得时记NA，设备占用不冒充进程峰值。

所有更新/前反向/采样/D0、尝试和资源留账。只从完整一致游标恢复，不静默重算丢失更新或自动重试模型调用。保护原权重、数据、评分器和报告；本轮不清理旧资产、不切默认、不commit/push。固定数据、训练、评价、实际图审和报告完成后停止。
