# Bench 完整座面课程：方法与证据边界

本说明记录本轮已冻结的方法、已核验的数据身份与历史谱系，供最终报告复用。它不报告尚未完成的训练、自由生成、评分或输出图审结果，也不据训练损失提前判断课程有效、收敛或模型晋级。预算、身份与停止条件以 [training_registration.json](training_registration.json) 和 [PROTOCOL.md](PROTOCOL.md) 为准。

## 数据任务与 22 父训练池

本轮任务是以真实来源三角面 C 为条件，生成保留并采用 C 的多样完整 Bench。训练仍从同一来源网格取补集 Y，保留已有面身份和坐标版本；来源 Y 提供训练监督，不能据此要求开放生成唯一复原该来源的款式、背板或支撑结构。

候选来自已可信的 USER/RELATION 资产在 `r2_bench_newdata_joint_v1/data/manifest.json` 中的活动训练池。逐条检查全部 **25 条 SEAT_SURFACE / 24 个父**，最终纳入 **22 条 C / 22 个父**，每父一条最完整座面，K≥2。所选 N 为 128–256、K 为 2–51。本轮没有创建新几何版本、修网格、重新采样、重切父级划分或将 DEV 移入训练；NEW27 的座面加靠背壳条件不在这 25 条单独座面候选中。不同 UID 不等于已经证明不同形状家族；已有近重复/家族独立性未知记录仍保留。

“完整座面”指真实坐面区域的完整上表面，不要求是矩形、平面或单连通片，也不要求包括向下转折的侧支撑、厚度、底面、靠背和扶手。保留的输入包括完整 L 型两翼、整组平行座板、非矩形轮廓、圆端座面、完整弧形座面及三湾座面连同自然隆起分隔。不能把“完整的一条木板”自动等同于“完整的一套座面”，也不能因一个实际座面本来很窄便予以排除。

明确排除的 3 条如下；排除依据是本轮完整座面任务范围，不是生成结果、占用头预测或某项评分：

| 原条件 | 实际范围与排除理由 |
|---|---|
| `d9de3b770e53a41d5b7bc62e486d578c__SEAT_SURFACE_1__V2` | 座面前部矩形条带，未包含整个坐面范围。 |
| `a8e987a6a6486b962d6c8e51365a5a87__SINGLE_SLAT_TOP_FULL__REL_V1` | 多条座板中的一条中央木条；其余坐面仍属于 Y。 |

全部 25 条都生成并实际查看了同一来源坐标系下的 M/C/Y 对照图，包含两斜视和顶视；根代理另实际复核了 7 条重点输入。图审是非盲 AI_PROXY 输入语义审阅，不是独立人工评价。V1 绘图存在 C/Y 分集合深度排序遮挡，保留作历史；实际最终审阅使用修正的 V2，每张记录 PNG 哈希、观察与决定。V2 斜视仍可能有三角形画家排序伪影，判定同时核对 C-only、Y-only 与顶视，不把绘图遮挡当几何缺失。

CPU 准备只验证既有文件哈希、case/input/paired 数组身份、C/Y 对来源面的互斥完备分割、预 OT 坐标倍率及既有 owner/alias 标签形状。它没有重新完成全网格质量认证。原行中的历史 `PENDING` 等状态保留其原语义；本轮独立准入由 `curriculum_decision`、实际图审及 CPU gate 表达，不改写旧文件。

## Chair 历史参照与本轮实质差别

历史 Chair 的 `PLAIN_S2000` 是“不加 couple 辅助项的 SEAM”终点，不是从官方只进行 2000 步普通 Native 训练。已保存报告与旁车给出的生成器直系谱系是：

| 阶段 | 数据和新增更新 | 累计生成器更新 |
|---|---|---:|
| 官方 Chair EMA → EXP67 | USER-only 的 67 父、194 条座面/靠背 FULL/HALF 条件；fresh AdamW，6000 步 | 6000 |
| EXP67 → FULL_S6000 | 47 个训练父的完整座面；恢复匹配 AdamW，新增 6000 步普通条件训练 | 12000 |
| FULL → SEAM_SLOT_C200 | 4 条熟悉完整座面，新增 200 步 | 12200 |
| SEAM200 → B_POOL47 | 47 父，新增 800 步 | 13000 |
| B_POOL47 → PLAIN_S2000 | 同池普通 SEAM 续训，新增 2000 步 | 15000 |

该 Chair 终点有累计 3000 步 SEAM；推理使用另一条 LONG 分支保存的 C-only 头预测布局，LONG 不是这个终点的直接生成器父检查点。EXP67 中 clean/width 混合是宽度增强，不是把旧条件、20/40 裁剪或无条件 replay 混入这条成功直系链。EXP67 的实际父抽样也不是本轮全程 4 父成对策略：其报告记录每批 8 个不同父、4 clean 和 4 width；后续完整座面阶段的父成对策略才是本轮直接沿用的组织方式。

Bench 最初已经实际执行官方 Bench EMA → COMMON12000，再从同一终点分叉普通 Native 和 SEAM，各新增 9000 步至 global21000。那一轮全部阶段使用 64 父、277 条多部位条件，SEAM 另持续训练 833 参数头；它并非只做过一次短 1500 步试验。其 [原完成报告](../r2_bench_parts_convergence_v1/REPORT.md) 明确按预算上限结束，不能改称两臂均已收敛。最近 USER/RELATION/NEWDATA 的 1500 步配置也不是将完整座面 Native6000→SEAM3000 串行执行的同一课程。

本轮沿用相同主干与原训练机制，改变的是完整座面任务组织、阶段顺序及固定头政策等整体配方。起点 COMMON 已经接受过 Bench 多部位条件训练；本轮并未从官方重新构造 Chair 的全部前史，也未复制四 C 的 200 步启动或另训 LONG 头。因此它不是只换类别的严格单变量实验，也不能把可能的差异唯一归因于数据、头、优化器或过拟合。后期 Chair 的 47 SEAT+31 BACK 多部位试验又有不同起点和 18049 参数头，不应与本轮固定 833 头混为同一配方。

历史依据：[Chair/Bench 可比性核查](../r2_bench_parts_convergence_v1/CHAIR_COMPARABILITY.md)、[EXP67 完成报告](../r2_user_data_scaling_32_67_v1/REPORT.md)、[Chair 后期多部位报告](../r2_chair_multipart_seam_v1/REPORT.md)。这些历史报告描述各自实验，不覆盖本轮冻结合同。

## 本轮固定训练合同

从原 `r2_bench_parts_convergence_v1/training/COMMON/step12000.pt` 恢复生成器、匹配的单组 AdamW 动量和 RNG。普通 Native 新增 **6000** 步至 global18000，随后在同一 22/22 池上新增 **3000** 步 SEAM 至 global21000，阶段切换保持生成器、优化器和 RNG 连续；不重置 AdamW，不按效果选 best 或增加训练探针。

batch8、microbatch1，每批 4 个不同父，每父 identity 与 x-width U[0.9,1.1] 各一份；无 y/z 缩放或平移。固定 [schedule.json](data/schedule.json) 共 9000 更新、72000 实例，计划每父合计 3272–3274 次；Native 阶段每父 2180–2182 次，SEAM 阶段每父 1090–1094 次。实际曝光仍必须逐样本与计划核对，计划数不能充当完成数。

Native/T1＋role＋Geo、原 Gaussian、`t=sigmoid(N(0,1))`、来源角色约束 OT 后 HYBRID0.25 和 free-only FM 保持原定义。AdamW lr=1e-5、betas=(0.9,0.95)、eps=1e-8、weight_decay=0、clip=1。BF16 前向、FP32 参数/优化器/积分；eval-mode 训练；严格确定性、TF32 关闭、SDPA math、CUDA 初始化前设置 `CUBLAS_WORKSPACE_CONFIG=:4096:8`。

若一个样本有 N 面、K 个条件面，Native 的有效自由标量为 `9(N−K)`。SEAM 训练按来源 owner 标签激活 S 个原边槽，固定各槽前两个角点、监督第三点，bulk 仍监督全部角点；自由标量为 `9(N−K)−6S`，其中 seam-tip 为 `3S`、bulk 为 `9(N−K−S)`。FM 使用整批自由标量总分母，不将每个样本 MSE 等权平均冒充该目标。来源 owner 是训练目标的监督信息，不代表开放生成的唯一正确邻接选择。

占用头固定为已有 Bench OLD_S15000 头：833 参数、原 24 维 C-only 几何特征、logit≥0 阈值。训练不进行头前向、头反向或头更新，也不按旧头预测筛选训练 C。SEAM 推理使用该冻结头的 C-only 预测；来源 Y/owner 不用于纠正推理布局。训练 owner 布局和推理预测布局可能不同，需要在解释中保留这种差异。

训练汇总仅从已保存日志计算首末 100 步 `sum(SSE)/sum(count)`，保留 all-free、seam-tip、bulk、端点误差、部位和时间桶分母；Native seam-tip 没有自由标量时记 NA。变化中的训练实例窗口不是固定探针，更不是自由生成质量或收敛证明。工具不增加模型调用：[summarize_training.py](../../r2/pilots/bench_full_seat_curriculum_v1/summarize_training.py)。

## 24 请求的固定评价

三份预定权重分别为 COMMON_S12000、NATIVE_S6000、SEAM_S3000。每模型同一 **12 条 C × 2 噪声 = 24 请求**；共 72 份 RAW，随后各一次 Bench D0，共 72 次 D0。每次生成 Euler50，预登记生成前向共 3600；SEAM 头最多按 12 条 C 各调用一次，两个噪声共享该 C 的预测布局。COMMON/Native 推理零头调用。

| 分层 | 条件/父数 | 每模型请求数 | 输入父前缀 |
|---|---:|---:|---|
| CURRENT_TRAIN | 8 / 8 | 16 | 35948e、4cd23a、6b894c、7b58a3、838c48、91e169、943dde、9e429b |
| DEV | 4 / 4 | 8 | 2d1e5e、459f90、f495bd、fd355d |

完整身份、输入文件、查询及噪声哈希由 [eval_manifest.json](eval_manifest.json) 固定。训练层选例覆盖规则长座面、L 型、整组条板、非矩形和弯曲座面；DEV 从既有父级开发集合的完整座面中选取。选择发生在本轮生成之前，依据输入元数据与来源图审，不依据本轮输出。每条 C 固定 2048 个 C 查询点，尺度常数 L0=9.208138264587333；不按生成结果重新归一化或挑截面。

三个模型使用完全相同的 C/N、噪声数组字节、查询和显示坐标系。相同噪声不表示相同的有效自由坐标角色：COMMON/Native 所有 free 角点均自由；SEAM 按冻结头预测构造硬边槽，因此部分角点被锚定，seam/bulk 分区及自由标量数会改变。这是阶段机制的明示差别，不能把逐槽误差或不同留存面积分母当成完全相同变量直接比较。

全部 72 份 RAW 保存完毕后才进入 D0。保留 RAW、BASE_POST、CLEAN_FINAL_POST 三层记录；BASE_POST 使用单次官方 Bench D0、恢复 C/SEAM 锚点、原 GEO_C 与来源 C 定向；最终层统一 HINGE_OPP015→ALPHA→HOLE。类别匹配 D0 是方法共性，但 Bench D0 与 Chair D0 不是同一权重，已有 fixed_std 记录分别为 0.05 与 0.02；本轮不据这个常数重新抽噪声。

评价展示固定两个斜视：azimuth −60°/120°、elevation 23°。每条条件的来源 C+Y 只在生成之前用于冻结显示范围和两个中央 front/side 截面；图库读取保存的 `front_positions[1]` 与 `side_positions[1]`，跨权重、噪声和后处理阶段不移动平面以追逐局部效果。数据准入图的三视角与这套输出评价展示是两个不同用途的记录。来源 Y 不进入模型，也不据来源样式定义唯一成功。

所有适用原指标、逐输出值和 NA/LOW_SUPPORT/UNKNOWN 原因均保留；按同噪声请求配对，再在条件内汇总、父等权，并分别展示训练与 DEV。合法接口、可达 bulk、完整主体、主要支撑、碎片/裂口和 C 采用需要共同解释，不能用一项接口改善抵消主体损失。bulk 比例需同时披露本阶段留存面积与 RAW 保留率，删面改变分母不能自动计作改善。I 是 C 支持域冲突覆盖，不是整网格自交率；CF proper、CF illegal、FF illegal 与全网格 Ri 不混称。坐标保持也不单独证明原顶点 ID 连通保持。实际输出 AI_PROXY 图审另存每图哈希与真实查看记录，不能由数值或头预测代填。

## 开发边界与停止条件

CURRENT_TRAIN 是本轮实际训练 C 的新噪声检验；DEV 父未进入本轮课程，但这些父已经在历史实验中反复观察，属于开发证据，不是独立、未触碰测试集。官方预训练是否见过来源父不由本轮划分证明。两份噪声、三个保存阶段和三个模型输出不会增加独立父样本数；本轮训练 22 父、评价 DEV 4 父的规模限制必须保留。

本轮固定终点和完整质量链用于检验整个课程候选，不自动归因任一组件，不外推为全部 Bench、全部条件部位或全部形状家族。没有来源 GT 的输出不计算来源复原成功；无必需接口时不强设接续要求，无暴露要求时不追求最大暴露。解释遵循 [持续指标政策](../../native_t1/docs/control_metrics.md)。

资源并发仅对已登记独立工作开放；Native→SEAM 的训练依赖不允许打乱。GPU 并发前按实测显存、计算利用率和 CPU/RAM 留余量，WDDM 缺少进程显存时明确 NA；并行整设备峰值不冒称单进程峰值。失败调用、未完成步骤、资源等待及精确恢复均留账，不静默重试或扩预算。完成固定训练、评价和报告后停止；不因此更换默认模型、删除旧资产或 commit/push。
