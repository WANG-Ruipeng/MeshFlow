# Bench 完整座面课程：Native 6000 → SEAM 3000

实验：`R2_BENCH_FULL_SEAT_CURRICULUM_V1`。日期：2026-10-23。

> 报告状态：两段训练、全部采样、216行评分、72页图库及216单元实际图审均完成。正式完成与产物哈希见本目录 `COMPLETE.json`。

## 结论

**沿 Chair 的“完整座面普通条件训练，再进入 SEAM”顺序，确实改善了部分熟悉 Bench 条件的组织与几何质量，但没有得到可靠的 DEV 主体接续升级。** 本轮保留新权重和真实正例，不将其整体晋级为默认模型。

最清楚的数值结果是：同一固定面板、同一最终后处理下，训练父 FF 从 COMMON 的 **34.58%** 降到 Native 的 **14.57%**、SEAM 的 **10.25%**；训练父 CF 从 **13.23% → 9.33% → 2.09%**。但 DEV 的 SEAM FF 为 **27.21%**，高于 Native 的 **24.05%**，与 COMMON 的 **26.87%**接近；DEV 小角面比例从 COMMON 的 **30.13%** 上升到 SEAM 的 **55.88%**。后两项不能由接口改善抵消。

SEAM 最终在 **24/24** 请求上有合法 C/F 共边，但从 C 经合法共边进入 bulk 的可达面积达到30%的只有 **训练 2/16、DEV 0/8**；两个训练达标输出都来自 **91e169 同一父**。因此，“原边槽接住了 C”与“生成主体已经接进来”仍是两件事。

实际图审也有明确的正反两面：训练条件 RAW 的 C 用途合理计数为 **2/16 → 14/16 → 15/16**，说明普通完整座面阶段已带来大部分采用收益；但最终输出整体合理计数为 **14/16 → 8/16 → 9/16**，新模型部分支撑在BASE处理后缺损。DEV 的用途合理计数为 **4/8 → 1/8 → 2/8**，不能宣称跨父改善。这些是非盲AI_PROXY观察，保留不确定标签。

这不是又一次仅写脚本的准备：已实际完成 **9000次更新、72000次训练前向和反向、72份Euler50生成、72次单次官方Bench D0**，无科学重试或追加训练。完整调用与输入身份账本保留。

## 接续收益具体落在哪里

SEAM在RAW阶段24/24有合法C/F共边，但bulk可达均为0；BASE_POST训练均值8.85%、达标1/16，最终17.30%、达标2/16。DEV三阶段均0/8达标，最终每份的bulk可达均为0。

两个最终高可达结果是91e169的n0/n1：**98.88% / 99.91%**。它们最终只保留 **11 / 12张bulk面**，bulk面积为 **11.345 / 14.380**；分别删除87/151、86/151张原free面，小角面比例为78.13%/73.85%。不是98%以上的原始全部free面都被无损连接。n0的BASE可达仅6.13%，后续固定处理把它接到了现有较大bulk分量。这个局部正结果真实，但没有扩展到第二个训练父，更没有跨到DEV。小角比例是独立几何观察，不能直接等同肉眼碎片，也不据此宣布所有细分面均无用。

同时存在直接接口很长、主体仍未接进来的例子：7b58a3的合法C/F共边长度每份63.064，最终bulk可达仅2.64%/1.24%。**围着C长出seam，与seam接入bulk，仍需分别计账。**
