# 16份共面内部重三角化提案的独立CPU核对

**未发现导致16份面数不变的实现错误。当前网格确实没有该保守合同允许删除的共面片内部顶点。** 这一结论只适用于“保留全部patch边界顶点与索引，仅去除内部剖分”的冻结算法，不表示这些Bench无法用别的受控方式简化。

平面区域已经有大量多面片，但顶点全在各patch的边界上。对于没有内部顶点的单环三角剖分，保留全部边界顶点时原面数已经是边界顶点数减2；换对角线不能降低面数。多环和非简单边界按任务合同保持不变。

进一步排除了几种工程假象：

- 所有保存分组完整覆盖原面，每张原面恰好出现一次；每组满足冻结的种子法线与共面距离阈值。
- 11,682条双面邻接边中，4,714条同时满足局部法线与共面条件；其中跨越保存patch的边为0，没有发现合格直接邻面被遍历漏掉。
- 平面距离合格而法线未达阈值仅8条；法线合格而平面距离失败11条。没有放宽阈值或由这些计数推断放宽后一定有效。
- 已使用顶点的精确坐标重复余量为0；按源顶点索引和仅按精确坐标身份得到的开放边数均为669。因此没有“位置相同但源ID不同，造成全部平面被意外拆开”的证据。
- 16份结果的原顶点坐标逐位相同，原**有序**三角面多重集合完全保留。变化只有输出面排列，不是移动或删面后恰好补回相同N。

源码中的法线来自FP32坐标提升到FP64后的叉积并归一；`normal_dot_min=0.9999999999`、平面距离阈值约`9.20814e-7`模型单位与冻结协议一致。保留反向薄面、洞与边界是有意限制，不应为取得面数下降而在本轮静默取消。

结果：**本次没有新增满足N128..256的父，也没有新增baseline-ready训练资产。** 更强简化、允许删除边界共线顶点、重建部件或改变面预算都属于不同数据合同，本核对没有执行或批准这些变化。

复算入口：`python -B -m r2.data_tools.bench_deployment_tasks_v1.verify_planar_rebuild`。
逐父及逐patch证据：`per_parent.csv`、`per_patch.csv`；固定输入/源码hash：`COMPLETE.json`。独立数组核对耗时约0.57秒（含WSL进程约1.54秒），零新提案。
