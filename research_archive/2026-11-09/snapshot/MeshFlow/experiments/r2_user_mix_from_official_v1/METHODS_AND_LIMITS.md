# R2 USER 主导混合训练：方法与解释边界

实验：`R2_USER_MIX_FROM_OFFICIAL_V1`；单臂：`R2_USER_MIX`。本文只说明冻结设计、已经完成的数据准备及初始化证据，不包含模型效果结论。6000更新、12份新输出等数字是注册预算；实际完成情况以最终执行账本和审计为准。

## 数据与采样

训练沿用 **25个共同父对象、117条USER条件、395条OLD条件**。USER包括56条座面、61条靠背条件，OLD包括200条C20、195条C40条件。它们是同批完整椅子的不同条件划分，不是512把独立椅子。C由原三角面组成，Y为原面ID的严格补集；不修复、重三角化或增加父对象。seat/back及small/medium/full标签只用于构造与审阅，不输入模型。USER的区域面积档位不等于整椅面数占比，K允许变化。

每批8个不同父，固定6 USER＋2 OLD：3 USER clean、3 USER宽度增强、1 OLD clean、1 OLD宽度增强；OLD每批各含一条C20和C40。父对象等曝光，再在对应父的合法条件池中均匀抽取。宽度增强只沿x轴，系数在[0.9,1.1]内，C和完整目标同步变换。HOLD及DEV条件不训练。

6000批的冻结计划共有48,000次曝光，每父1,920次，其中USER 1,440次、OLD 480次；总计USER 36,000次、OLD 12,000次。**75%／25%是槽位数量配比，不是固定loss权重或梯度贡献比例。** FM每批除以该批全部有效free标量数。完整物化流中，USER含61,961,499个free标量，OLD含15,072,480个，总计77,033,979个，累计占比为 **80.434%／19.566%**。该占比也不等于实际梯度占比，且不是逐批占比的简单平均。

CPU准备回执记录48,000次OT尝试及48,000次返回，物化48,000份Gaussian和48,000份epsilon；零模型加载、前向、反向及优化器更新。物化完成不意味着训练已经消费完全部样本。依据：[输入注册](data/input_registration.json)、[曝光统计](data/actual_exposures.json)、[准备回执](data/precompute_receipt.json)。

## 继承的来源缺陷

USER主池继承原数据准备结果，不能称为“干净数据”。此前审计检出的14个相交／重叠父仍在25父中；完整来源共保留310对确认问题和3对未决问题。源面ID互斥并不保证C与Y在几何上不穿插或重复覆盖，也不能据此认定历史训练失败的原因。未知项继续保留UNKNOWN；不同条件重复引用同一面对，不应累计成独立缺陷。

来源说明：[DATA_PREPARATION_REPORT.md](E:/MeshFlow-Control-artifacts/experiments/chair_r2_user_conditions_v1/DATA_PREPARATION_REPORT.md)。这些是继承的审计证据，本附件未新增几何诊断。

## 初始化与训练合同

加载同一官方Chair **EMA**，建立Native/T1＋role＋Geo，从条件训练step0开始，采用新的AdamW状态。没有从START、旧R2或R2_CONT_USER继续恢复动量。初始化回执确认主干严格继承，role与Geo出口均为零，Geo seed为1010，无B、teacher、辅助head或readout；零出口不承诺带C的条件前向与原无条件前向相同。

固定6000更新、batch8、microbatch1；AdamW学习率1e-5、betas=(0.9,0.95)、weight decay=0、梯度裁剪1。全程free-only FM和HYBRID λ=0.25，沿用原free-only OT后混噪的顺序与训练坐标。BF16前向、FP32参数与积分，TF32关闭，SDPA math，严格确定性设置。只采用固定6000终点，中间500步滚动检查点用于安全恢复，不按图片挑选。

正式预算为48,000次训练前向、48,000次反向、6000次优化器更新；不追加预检模型调用、教师调用或额外训练臂。安全恢复要求完整更新、输入游标和调用账本一致；不静默重放已尝试更新。依据：[冻结协议](registration.json)、[初始化回执](training/R2_USER_MIX/attempts/initial/initialization_audit.json)、[冻结源hash](code_manifest.json)。

## USER评价及历史对照

使用既有 **6个DEV父／6条条件：2座面、4靠背，每条2份固定噪声**。直接读取先前保存的C、Gaussian和C查询点，不重新抽样。新模型生成12份Euler50 RAW，共600次采样前向；历史R2_FROZEN、R2_CONT_OLD、R2_CONT_USER各复用12份同请求RAW与同口径评分，合计48份输出。标准Gaussian为推理free起点，C硬保持；无POST，无旧随机裁剪回归生成。图集预算24张，包含同请求四模型、两视角及中性／C着色显示。

主判断是C是否合理参与完整形状，以及整体形状是否合理。这个开发面板已被反复观察，只有2条座面，不能充当独立未见测试或充分覆盖未来椅腿／多种靠背输入。与条件训练父分离，也不意味着在官方预训练中未见。旧随机裁剪能力不作为本轮晋级门槛。

历史R2_FROZEN使用26父、6000步；两份CONT先经历原R2，再在25父上续训1000步，累计7000步。本轮为25父、官方初始化后的6000步。这些比较可帮助判断新候选是否值得继续，**不能单独归因于75/25配比、提前注入USER或某一个数据因素**，也不证明该比例最优。依据：[评价注册](evaluation/registration.json)、[历史复用回执](evaluation/reuse_receipt.json)。

## 指标含义与不适用项

固定尺度L=√3×2/0.3762≈9.208138，不随输出bbox改变；每条C复用2048个面积查询点。先平均同条件两份噪声，再按六父等权，座面／靠背与档位仅作描述分组，保存完整逐输出、配对与尾部结果。

| 证据 | 可支持的解释与限制 |
|---|---|
| C逐位保持、51态、面数与有限性 | 执行合同；不等于合理采用C，不认证原vertex-ID连接。 |
| CF proper及另列CF illegal | C—free穿越／非法交候选的面对数与受影响free面比例；两种定义不混名，比例分母为N−K。 |
| FF illegal | free之间proper穿越或正面积共面重叠的受影响面比例；不等于完整物体合理性。 |
| I、I_cross、I_dup及交集 | C面积查询上的穿越影响带／近平行覆盖候选并集；分母为全C查询权重。I_dup可能标记合法薄壁，不能直接当作“重复座面率”或C采用率。 |
| 小角、退化、拓扑描述 | 离散几何代价；RAW三角汤的分量数量不能直接等同明显碎片，也不认证水密。 |
| 同条件free两两表面距离 | 两份候选的变化幅度；更大不必然更合理，不作唯一来源GT排名。 |

S记`NA_NO_REGISTERED_REQUIRED_INTERFACE`，E记`NA_NO_EXPOSURE_TASK`，来源重建记`NA_NOT_UNIQUE_GENERATIVE_TARGET`；水密认证为未实现。本轮无人工评分，图像审阅必须单列 **AI_PROXY**，分别记录整体质量与C用途，并允许不确定。低CF／FF／I、C精确复制或图片渲染完成，均不能代替实际用途判断。指标政策见[完整指标库](../../native_t1/docs/control_metrics.md)。
