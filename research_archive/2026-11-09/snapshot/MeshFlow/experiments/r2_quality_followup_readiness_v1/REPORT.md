## A：混合条件比例

本地 C20 全池有 32 父、250 条；真正匹配历史 R2 的 26 父中，C20 为 208 条、C40 为 203 条，N=133–245。USER_LARGE_67 有 67 父、194 条，N=133–256，K=1–54；这不等于全部满足当前 K≥2 的规则输入合同。所有 647 个唯一条件文件的登记哈希核对通过，无缺文件。

历史 R2 的 26 父与 USER67 有 **25 个共同父**。逐父实际 NPZ 中 full_target、pre_ot_full、model_vertices 和 source_face_vertex_ids 均一致，N 也一致，详见 `shared_parent_inventory.csv`。因此有一个可控制父与完整来源几何的共同子集；直接把历史 26 父与 USER67 混起来则同时改变父覆盖，不再只是条件类型比例。未为此构造任何新 C、OT 或噪声。

最近路线是 R2 的 C20/C40 混合/课程，以及后来 USER 条件续训与数据扩展。旧 R2 已实现各半 C20/C40、配对父与增强流；只改变这个比例并不自动成为新方法。这里可证伪的问题是：在相同父和来源几何上，少量历史裁剪条件是否能改善 USER 完成的整体质量，同时保留 C 用途与接续。要正式做，需先固定一个比例和总预算，保持父均衡、FM/HYBRID/精度不变，不能见图再改比例。

若基座采用普通 Native/R2，现成条件可复用。若采用 SEAM，共享原边槽还要求开放边数不超过 free 槽数，来源邻面必须有可表示的 owner 分配。当前 `slot_data.py` 对一张来源 free 面拥有多条 C 边、第三点引用 C 的情形并未给出通用支持；不能仅因 NPZ 存在，就称 C20/C40 已经可以直接接进 SEAM。此项是待核验的表示合同，不在本次物化数据。

## B：延长 SEAM 训练

CPU mmap 实际读取了 `r2_seam_slot_c200_v1/checkpoints/SEAM_SLOT_C200_step200.pt`：global_step=12200、local_step=200；生成器 AdamW 有 194 个状态，步数均为 12200；占用头优化器有 4 个状态，步数均为 200；参数名列表、RNG 与头状态均在。检查点与两份推理导出的文件 SHA256 和原 WEIGHTS.json 一致，内部登记 state hashes 也匹配。没有加载网络到 GPU，没有执行恢复训练。

最近证据是 R31 四条件 200 步的接续正信号及这次占用布局干预。延长训练不能同时修 BCE、改推理占用阈值、改 GEO 或改训练池，否则无法解释变化。历史 FULL_S6000 已表明更长训练可改善用途/轮廓，但不保证联合接续和 FF/I 同时改善；R28 的同预算轮廓读取也未扩终点成功覆盖。

现有入口写死 200 步及原缓存数据流，不是合法的新增长训入口。要续训，应另立 registration，明确从 12200 开始、保留匹配 AdamW/RNG、登记新增流与固定评测，不覆盖旧实验。若冻结占用头，不能简单把 head 设为 None：旧训练代码用这个条件分支选择 seam_forward，会意外取消共享槽路径。预算与是否更新头目前未定；本次不启动。

## C：第三点防护及角度反例

从冻结 `source_per_edge.csv` 的局部坐标重新计算

`cos(angle) = -r / sqrt(r²+h²)`。

389 条的最大复算误差为 5.56e−16。**严格角度 >135° 会误拒 1/389 合法来源接口；当前四 C 的 62 条是 0/62。** 使用 cos<−0.7 也误拒同一条。150° 门禁在这一有限来源池中为 0/389；这不是替用户选择新阈值，更不证明通用安全。

反例是 `5420d4699cf0125fd08f8c5dee475682__SEAT_FULL` edge0，来源 C face23 / Y face24，已登记 shared_edge_contact、反向共边。角度144.53936°，cos=−0.814514，r=0.961582，h=0.684893。不能把“合法侧壁都 h<0 或 r≤0”当合同；389 条中有90条 h>1e−12、19条 r>1e−12。原来源绕序并未再次认证为物体全局外向。

角度只描述一条铰接边的局部折角。合法凹折也能大于135°；另一方面，法向相同或垂直的两张有限三角面仍可能与其他 C 面穿插。局部坐标 (a,r,h) 是可逆换基，单独采用它并不会禁止内翻；硬限制符号又可能排除合法来源完成。距离阈值还须关联 C 的有限三角面，不能用无限平面近距离替代非法重叠。

最近的机制不是空白：R04 中 `guided_native_geometry_corrector.py` 已有 verified_pair 触发、有限三角面分离候选和精确 CF/FF 检验；R07 已试源顶点关系与时间门控，R09 已试有限边对应。若做新的训练辅助，实质变化应明确是“对当前预测中已确认非法的有限面对，沿合法可行方向给训练梯度”，而不是重复泛化斥力或把代理值下降等同接续改善。它仍可能撕开原有合法连接，不能承诺同时解决碎裂。

SEAM 有现成的 transported seam-third mask 和固定角点掩码，但当前 Yhat 只在 backward 后对 `prediction.detach()` 做日志。要实现惩罚，必须在 backward 前用活计算图构造 Yhat，同时让 C/固定底边保持常量；离散配对、非法门控与分离方向的 stop-gradient 约定要明确，不能把旧日志直接当可反传 loss。零间隔的分离量还可能让非法共面重叠取零损失。需要先定义有限非法门控、正且可行的间隔以及合法接触排除，再检查值与梯度；这些未在本次执行。
