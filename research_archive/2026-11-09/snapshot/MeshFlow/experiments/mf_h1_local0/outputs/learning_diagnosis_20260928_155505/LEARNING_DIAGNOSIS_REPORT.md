# Q 条件可学习性诊断报告

本轮执行了**新的训练**：Q_correct（A）和 Q_independent（B）各 1000 次更新，共 2000 次；不是零训练调试。只使用旧 train manifest 顺序前 4 个真实父对象及 12 组预先固定几何提示。结论限于这 4 个训练对象、训练 seed10、两个独立生成噪声 6101/6102，不代表泛化，也不检验 G 或 H1 优势。

三级证据分别判断：

| 层级 | 本轮结论 |
| --- | --- |
| 实现、稳定运行与梯度门禁 | 通过 |
| 是否存在条件响应 | A：正确提示 已记录循环配对中 24/24 非零，RMS范围 0.0198191–0.189159；B：独立提示 已记录循环配对中 24/24 非零，RMS范围 0.00451782–0.189229 |
| 是否建立有用条件映射 | 在当前预定1000步预算内未建立有效条件控制：A 的自由生成 guide 和完整表面误差均未改善 Base，平均绑定改善非正；即使存在非零条件响应，也不能解释为正确提示已学会控制对应目标。 |
| 是否证明H1或泛化 | 本轮不检验H1，未训练G；仅4个训练父对象，不作泛化结论 |

条件响应存在也不等于正确条件有用。上述响应只汇总终点已有24个同类型、同噪声循环配对；不新增评分、不构造额外配对，也不把24行当作24个独立父对象。

五个问题的直接回答：

1. **稳定配置是否进入实际路径：**是。训练、teacher、完整生成都记录严格 deterministic=True / warn_only=False、BF16 autocast、FP32 参数/积分坐标、TF32 关闭与 SDPA math；确定性反向门禁通过，未静默切换数值路径。

2. **加法实际保留多少：**旧 step200 已观测 correct 状态的 RMS(r_eff)/RMS(r) 范围为 0.206306–1.0056；在 r 非零元素中，加法后 h 不变比例为 38.27209%–99.59687%。四层及新 step1000 的具体值见下表。这个 RMS 比不是语义信息保留率；量化误差或高不变比例本身不能证明学习失败的根因。

3. **correct 是否胜 independent：**最终 step1000 的 B−A guide=0.0292838，B−A completion=-0.00961839，A−B 绑定改善=-0.0055495；4 个父对象中 A 的 guide 更低者 2/4。这些指标未一致支持 A 胜出。未做预注册显著性检验或 bootstrap，因此不作统计显著性声明；可学习性仍依据预定终点的效应幅度、父对象一致性、teacher 与自由生成证据判断。

4. **新噪声完整生成有无收益：**Base−A guide=-0.915687，Base−A completion=-1.78899；A guide 优于 Base 的父对象 0/4。未同时得到 guide 与完整表面误差均值下降。必须同时看负对照、父对象绑定和质量，不能用训练损失或非零坐标响应替代生成证据。

有用条件映射的终点判断：在当前预定1000步预算内未建立有效条件控制：A 的自由生成 guide 和完整表面误差均未改善 Base，平均绑定改善非正；即使存在非零条件响应，也不能解释为正确提示已学会控制对应目标。

5. **下一步扩数据还是定位学习：**先定位正确条件的学习与生成收益为何不足或不一致；当前证据不支持据此直接扩大数据，本轮不追加实验。

所有最终判断只使用预定 step1000；step0/200/500 用于呈现过程，未选择最佳 checkpoint、延长训练、调整损失或超参数。
