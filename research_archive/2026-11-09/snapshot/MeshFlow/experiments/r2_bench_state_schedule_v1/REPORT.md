# R2_BENCH_STATE_SCHEDULE_V1 实际实验报告

日期：2026-10-21。两臂各1500步、同48请求终点评价已经完成。简称：A为复用的 `A_S1500`，PERT为Idea 1 `PERTURBED_STATE_S1500`，ASYNC为Idea 2 `ASYNC_LEAD_SEAM_S1500`。

**结论：两项都实际试了，本轮均不替换基线。** PERT在DEV的最终网格上有真实但有限的FF收益：7/8父FF下降、平均少删8.5面；同时CF、I恶化，且没有解决接入bulk。ASYNC的DEV综合冲突指标变差，也没有带来主体接续突破。两者均保留终点权重和完整证据，不根据结果追加训练或组合两项。

本报告的“未晋级”限定于本轮实现、1500步预算和既有开发面板，不否定所有纠偏监督或异步生成方法。A是本次公平的同起点普通SEAM对照，不据此重新宣布它优于全部历史Bench模型。

## 1. 当前问题与本轮实际改动

Bench能生成可辨认的长椅，但仍会在给定蓝色C旁另生成灰色座面/背板；固定SEAM底边能保住C侧连接，却未稳定连接到bulk主体。薄片、细脚和木条在D0/GEO之后还可能明显变薄或消失。过去降低适配强度、改占用和局部后处理，没有把这些宏观问题一并解决。

本轮没有修改几何表示、增加网络参数或叠新几何loss，分别测试两个因素：

| 候选 | 训练变化 | 推理变化 | 必须保留的限定 |
|---|---|---|---|
| PERT / Idea 1 | 部分训练状态的free角点作质心方向偏移，监督其回到原终点 | 原同步Euler50 | 是偏移态终点纠偏回归，不是所构造路径的精确CFM导数 |
| ASYNC / Idea 2 | SEAM第三点用局部时钟 `s=min(t/0.7,1)`；bulk沿原t | tip前35步完成，冻结其自身生成值；bulk继续15步 | 不保证提前生成的tip正确；后段训练见真实tip，推理见生成tip |

最近的历史路线包括SEAM、LOCAL_NOISE和COUPLE。本轮分别改变训练输入态/纠偏目标和角色时间/积分；没有把旧的初始噪声或一环loss路线改名重做。下面直接给出两项Idea的含义和已执行实现；冻结定义另见 [PROTOCOL.md](PROTOCOL.md)，详细训练统计见 [方法与训练细节](REPORT_METHODS_DRAFT.md)。

### 1.1 先说明它们改在现有系统的什么位置

现有生成器把输入和待生成部分分成三类。**C**是用户提供的真实三角面，三个角点都固定；**SEAM**是一张底边引用C开放边的三角面，两个底边角点固定，只有第三点tip自由；**bulk**是其余自由三角面，三个角点均自由。所谓free变量包含SEAM tip和bulk角点，不仅指bulk。

本轮仍由同一个Native/T1＋role＋Geo生成器处理全部槽位。已有角点嵌入与role、面级自注意力、角点更新及C几何上下文通路均保留；两项没有另建生成器或新增网络参数。源owner/受限OT只参与训练任务构造，推理复用与A相同的已冻结C-only布局，不读取来源Y去决定应该生成哪些边。

训练先按原逻辑做匹配及HYBRID混噪。以下Y表示匹配并完成角点排列后的目标，即原实现 `x1`；Z_H表示原HYBRID起点 `x0`，不额外重抽噪声。普通A在可训练角点上使用：

```text
X_t = (1-t)*Z_H + t*Y
U   = Y-Z_H
loss = sum_free((v_theta-U)^2) / D_batch
```

`D_batch`是整个有效batch中原有可训练角点的标量坐标总数，每个自由角点计3个标量。C、SEAM固定底边和padding不进分母。两项均在原样本已经生成之后作变换，保持父对象、C、N、OT配对、目标身份及原随机流可配对。

### 1.2 Idea 1是什么：让模型练习从人为偏离的状态回到目标

**直观假说：**正常训练主要给模型看预先定义的噪声—目标插值状态，而实际rollout会积累预测误差。若在训练中增加一部分偏离原路径的状态，并给出回到原目标的监督，模型可能更会纠正推理偏差，减少另画灰座面或生成部分与C脱节的情况。

这是待检验的假说。我们没有证明坏例状态在原训练分布中概率为零，也没有证明整体质心平移就能复现“第二张座面”。因此实际名称使用 **偏移态终点纠偏回归**；本轮没有正负样本对比loss、判别器、在线rollout收集或DAgger数据聚合，不宜仅凭借鉴思路称为已经实现了那些算法。

**实际构造步骤：**

1. 读取原冻结schedule行，先调用原数据函数完成OT、角点排列、增强、HYBRID及原 `xt/u`。
2. 只对 `0.3≤t≤0.9` 的行，以0.25概率触发。对原行的规范JSON分别作gate/alpha域的SHA256映射，获得确定性抽样；不消费原Python/NumPy/torch随机流，不使用worker编号。
3. 计算 `μC`：C中全部三角角点坐标的算术平均；计算 `μYfree`：目标Y中全部有效可训练角点的算术平均，包含tip，排除固定底边及padding。这里不是独立顶点去重均值，也不是面积加权中心。均值以FP64累加，随后偏移及状态运算回FP32。
4. 取 `α∈[0.3,0.8)`，同一条样本的所有free角点使用同一个三维偏移 `d=α(μC−μYfree)`，再重写状态与监督：

```text
Xtilde[free] = X_t[free] + t*d
Ucorr[free]  = (Y[free]-Xtilde[free])/(1-t)
loss        = sum_free((v_theta(Xtilde,C,t,N)-Ucorr)^2) / D_batch
```

5. 固定C和SEAM底边不动；未触发样本连原u数组也不重算，逐字节保留。随后仍调用原 `seam_forward` 和原 `corner_masked_fm_loss`，八个microbatch累积梯度后按原clip/AdamW更新。

这样要求一步外推满足 `Xtilde+(1-t)*Ucorr=Y`（浮点误差内）。例如`t=0.6`时，状态增加`0.6d`，目标速度从U改为`U−1.5d`，使其指回未偏移的Y。

**数学上实际改变了什么：**在给定d时，`Xtilde=(1-t)Z_H+t(Y+d)`这条路径的导数是`U+d`，而使用的监督是`U−t/(1-t)*d`。两者不同；它不是端点保持的原CFM路径，也没有继承其边缘分布正确性的保证。靠近t=0.9时纠偏项会放大，因此必须同时看目标幅度和梯度裁剪。这里向C移动整个free状态，也会拉伸固定底边与tip之间的几何关系，不等于只构造一张局部重影面。

**推理如何用：**只有权重变化。PERT继续走原同步SEAM Euler50，输入仍是C、总N、冻结布局和原噪声，不用训练Y、质心偏移或额外纠偏步骤；D0与CPU后处理亦与A相同。能否自行纠错，必须由自由生成结果回答，而不是训练终点恒等式保证。

### 1.3 Idea 2是什么：让SEAM先稳定，再留时间让bulk继续生成

**直观假说：**原模型里SEAM tip与bulk同时从噪声演化到终点。若tip更早停止移动，bulk后段可能更容易围绕已经稳定的SEAM形成结构。实际实现是一套网络里的异步时间安排：前段SEAM和bulk仍一起生成，后段仅bulk继续移动；不是先独立生成一个完整SEAM模型，再启动第二个bulk模型。

**训练状态和监督：**固定`τ=0.7`，令` s(t)=min(t/τ,1)`。原Z_H、Y及OT身份不变，只重写tip插值：

```text
X_bulk = (1-t)*Z_H_bulk + t*Y_bulk
X_tip  = (1-s)*Z_H_tip  + s*Y_tip
U_bulk = Y_bulk-Z_H_bulk
U_tip  = Y_tip-Z_H_tip
loss = [sum_bulk((v-U)^2) + 1[t<0.7]*sum_tip((v-U)^2)] / D_batch
```

网络预测的是**局部时钟速度**，tip的target没有再乘`1/0.7`。`t≥0.7`时训练tip输入已等于真实Y_tip，关闭tip的直接速度loss；bulk仍训练。分母D_batch不因tip停训而缩小，因此这也改变了直接tip监督的有效权重/时间覆盖。late tip虽没有自身直接loss，仍作为输入参与共享网络计算；不能说与其有关的网络参数被冻结或不再受bulk loss影响。

**时间信息如何进入同一网络：**`async_core.forward`复用原参数，将时间嵌入分为1、s、t三份，并沿用原总面数N嵌入。在每层，面级attention的AdaLN调制按面身份选择时间；角点MLP及最终输出调制按角点身份选择时间：

| 位置 | 原A时间 | ASYNC时间 |
|---|---|---|
| C面／C角点 | 1 | 1 |
| SEAM面级attention调制 | t | s |
| SEAM两个固定底边角点 | 1 | 1 |
| SEAM自由tip的MLP／输出调制 | t | s |
| bulk面与角点 | t | t |

原role标记仍只依照固定角点身份；Geo仍只编码原输入C。没有新增距离attention bias、没有把tip写进known mask，也没有把整张SEAM改成C角色。

**采样和速度单位：**每步仍调用一次整生成器，总共50次。设`t_k=k/50`、`s_k=min(t_k/0.7,1)`：

```text
bulk_next = bulk + (1/50)*v_bulk
tip_next  = tip  + (s_{k+1}-s_k)*v_tip     # 只在Δs>0时写入
fixed_next = original_anchor_values
```

前35次更新tip的步长为`1/35`，bulk步长为`1/50`；第35次之后保留模型当时实际生成的tip，最后15次仅更新bulk。这样实现了`dX_tip/dt=s'(t)*v_tip`，没有漏掉时间链式因子，也没有在target和积分里双乘一次。轨迹保存全部51个状态，并逐位检查固定角点和后15步tip冻结。

**“冻结”只表示坐标暂时不动。** 它不表示tip已经正确、已与bulk共边、变成用户提供的几何，或满足法向/相交约束；训练后段看到真实tip而推理看到生成tip，分布差异仍在。冻结只持续到生成器rollout结束，后续D0仍可整理自由tip；恢复合同继续只锁C和原SEAM底边。由于每步仍跑整个模型，本轮不主张降低30%推理计算量。

同一次训练前向的终点日志使用bulk的`X+(1-t)v`、active tip的`X+(1-s)v`。后段真实tip的零误差不算学习收益。源码支持`τ=1`和无SEAM时回退原实现，CPU测试已核对；本次正式臂始终使用冻结的τ=0.7。

### 1.5 本轮结果对两个Idea分别意味着什么

PERT确实训练了新增状态：2328/12000实例触发，目标幅度和梯度记录可查。它在最终DEV的7/8父上降低FF，并少删面；但RAW冲突宏均没有改善、最终CF/I和部分蓝C用途变差。因此本轮只支持“这种纠偏训练能改变质量取舍”，不支持“已学会排斥重复座面”。

ASYNC确实执行了前35步tip演化和后15步冻结，训练tip误差也有下降；但最终DEV的CF/FF/I均恶化、≥30% bulk可达仍0/26。这说明**该时钟配置在本预算下没有把提前稳定tip兑现成主体接续**，不能从“时间到了1”推断“几何已到正确终点”。后文保留完整数值、图审与代价，既不把实现成功当方法成功，也不将此一配置扩大为所有异步方法的否定。
