# R2_BENCH_STATE_SCHEDULE_V1 实际实验报告

日期：2026-10-21。两臂各1500步、同48请求终点评价已经完成。简称：A为复用的 `A_S1500`，PERT为Idea 1 `PERTURBED_STATE_S1500`，ASYNC为Idea 2 `ASYNC_LEAD_SEAM_S1500`。

**结论：两项都实际试了，本轮均不替换基线。** PERT在DEV的最终网格上有真实但有限的FF收益：7/8父FF下降、平均少删8.5面；同时CF、I恶化，且没有解决接入bulk。ASYNC的DEV综合冲突指标变差，也没有带来主体接续突破。两者均保留终点权重和完整证据，不根据结果追加训练或组合两项。

本报告的“未晋级”限定于本轮实现、1500步预算和既有开发面板，不否定所有纠偏监督或异步生成方法。A是本次公平的同起点普通SEAM对照，不据此重新宣布它优于全部历史Bench模型。

## 1. 当前问题与本轮实际改动

Bench能生成可辨认的长椅，但仍会在给定蓝色C旁另生成灰色座面/背板；固定SEAM底边能保住C侧连接，却未稳定连接到bulk主体。薄片、细脚和木条在D0/GEO之后还可能明显变薄或消失。过去降低适配强度、改占用和局部后处理，没有把这些宏观问题一并解决。

本轮没有修改几何表示、增加网络参数或叠新几何loss，分别测试两个因素：

| 候选 | 训练变化 | 推理变化 | 必须保留的限定 |
|---|---|---|---|
| PERT / Idea 1 | 部分训练状态的free角点作质心方向偏移，监督其回到原终点 | 原同步Euler50 | 是偏移态终点纠偏回归，不是所构造路径的精确CFM导数 |
| ASYNC / Idea 2 | SEAM第三点用局部时钟 `s=min(t/0.7,1)`；bulk沿原t | tip前35步完成，冻结其自身生成值；bulk继续15步 | 不保证提前生成的tip正确；后段训练见真实tip，推理见生成tip |

最近的历史路线包括SEAM、LOCAL_NOISE和COUPLE。本轮分别改变训练输入态/纠偏目标和角色时间/积分；没有把旧的初始噪声或一环loss路线改名重做。完整实现定义见 [PROTOCOL.md](PROTOCOL.md)、[方法与训练细节](REPORT_METHODS_DRAFT.md)。

PERT仅在原时间 `0.3≤t≤0.9` 内以0.25概率触发，独立哈希随机流不推进原训练RNG。令 `d=α(μC−μYfree)`，`α∈[0.3,0.8)`，仅free使用：

```text
Xtilde = X + t*d
Ucorr  = (Y-Xtilde)/(1-t)
```

固定C/SEAM底边不动，未触发行保持原数组。该偏移路径的导数与Ucorr不相等，不能称为原FM的代数等价形式。偏移也不自动构成真实“重复座面”坏例。

ASYNC预测局部时钟速度 `Y-Z_H`，tip直接loss仅在 `t<0.7` 生效，bulk全程生效；分母仍为原全部有效free标量数。推理tip积分用 `Δs*v`，bulk用 `Δt*v`。原role和Geo的C mask不变，没有把生成SEAM冒充用户C。两臂均无额外网络参数。

## 2. 公平比较与实际完成预算

两臂均读取历史A的精确step0快照：**COMMON12000生成器＋与A一致的新空AdamW状态＋相同RNG**。不是从A1500终点续训，也不是从官方预训练第0步重跑。

| 项目 | 实际执行 |
|---|---|
| 训练池 | 58 TRAIN父、195条件，原目标与owner监督不变 |
| 输入流 | 与A相同的1500×8行，父/C/N/t/噪声/OT/HYBRID身份相同 |
| 曝光 | 每臂12,000实例，每父206–208次 |
| 模型 | Native/T1＋role＋Geo＋SEAM，130,401,155参数 |
| 优化 | batch8/micro1；AdamW两个组lr均1e−5；betas=.9/.95，eps1e−8，wd0，clip1 |
| 精度 | BF16前向，FP32参数/优化器状态/积分；严格确定性、TF32关闭、SDPA math |
| 更新 | 每臂1500；全局12001–13500；总3000次 |
| 训练调用 | 各12,000前向及12,000反向；总24,000前向及24,000反向 |
| 新生成 | 每臂48份RAW，总96份；Euler50总4800前向 |
| 去噪 | 每份一次官方Bench D0，总96次；全部RAW先保存 |
| 评分 | 新288行＋A原144行＝432行，三个阶段分开保留 |
| 终点选择 | 固定1500，不挑checkpoint；没有新增固定神经探针 |

固定48请求为12父×2条件×2噪声：TRAIN4父/16请求，DEV8父/32请求。DEV已经多轮观察过，属于开发证据，不能称新测试集泛化。接口适用分母为TRAIN14、DEV26，其余8份closed C记NA。

同C、N、C-only布局、噪声数组、查询、来源角序、相机、尺度与截面，统一处理：

```text
RAW → 单次官方Bench D0 → 恢复C和SEAM固定锚点
    → GEO_C＋来源定向 → BASE_POST
    → HINGE_OPP015 → ALPHA → HOLE → CLEAN_FINAL_POST
```

训练采用增量启动的两个独立worker。RTX5080总显存16,303 MiB，首臂前空闲12,973 MiB；首臂达到真实反向/AdamW负载后才开第二臂，训练时全设备观测峰值10,233 MiB，保留安全余量。没有OOM、数值失败、丢步重放或超预算科学调用。两臂墙钟2713.1/2982.3秒存在并发竞争，不与历史A孤立计时作效率排名。完整资源与调用账本保留于 `dispatch/`、`resume_resources/`、`training/`。

## 4. 接续没有出现主体级突破

| FINAL | 模型 | 有合法seam–bulk边请求 | 该类边总数 | ≥30% bulk可达请求 | bulk可达面积父宏均 |
|---|---|---:|---:|---:|---:|
| TRAIN | A | 2/14 | 12 | 0/14 | 0.3554% |
| TRAIN | PERT | 3/14 | 16 | 0/14 | 0.8226% |
| TRAIN | ASYNC | 3/14 | 12 | 0/14 | 0.5141% |
| DEV | A | 2/26 | 2 | 0/26 | 0.5436% |
| DEV | PERT | 3/26 | 3 | 0/26 | 0.0563% |
| DEV | ASYNC | 2/26 | 2 | 0/26 | 0.2851% |

30%沿用已有描述门槛，不是物体可用性证明。PERT DEV多一个有边请求，但原 `f5d370/SEAT_SURFACE_1/n0` 可达面积17.235%→0.0935%，总体可达面积反而降低。ASYNC同例为8.9684%。局部多一条边不能代替接入主体。

FINAL的C/F合法边总数TRAIN为A/PERT/ASYNC=83/82/86，DEV均104。ASYNC TRAIN的12条局部合法seam–bulk边中，11条实际连到合法C种子。C侧绑定和bulk连接必须分开判断。DEV三模型A-VMR@0.5%L均83.5417%、PMR均62.5%；高顶点匹配也没有自动兑现成主体接续。完整阈值表和分母均保留，closed C未当作接续失败。

## 5. 同位置视图与截面

图集在 [gallery/index.html](gallery/index.html)。每请求RAW/BASE_POST/FINAL各一页，每页包含三个模型的两视角和相同位置的两个有限截面。蓝=C，橙=SEAM，灰=bulk，绿=bridge。固定画框造成的裁切按原回执保留；有限截面端点不单独认证裂缝或拓扑。

实际观察已经看到下列有代表性的差异：

- `459f90/LEG_SUPPORT_1/n0,n1`：蓝色弯曲长条上方仍有悬浮、断裂的灰表面，三组及后处理阶段均未消除宏观分层。

- `9d5608/SEAT_SURFACE_1/n0`：冻结语义类型实际为BACK_SURFACE，历史ID未改。两候选比A形成更厚实的长椅与支撑，是局部视觉收益；蓝条与灰背上部仍需分开判断，不能据此外推整体控制成功。
- 同父 `SEAT_SURFACE_1/n1`：三组整体都形成可辨认的双层架状长凳，蓝C被新灰上板遮住，截面仍显示明显层间偏移。外形合理不等于C已被采用。

## 7. 下一步判断与停止范围

**本轮不晋级任何一个候选。** PERT保留“DEV FF与删面有限改善、C域冲突变差”的取舍证据；ASYNC保留为该固定时钟配置未改善终态的结果。尚无依据直接延长ASYNC、组合两个候选或宣称Bench问题已解决。

如果后续只选择一个值得继续检验的问题，应围绕PERT的收益与坏尾部：其降低FF的变化，能否在不增加C域冲突、不把蓝C另层替代的条件下保留。当前质心偏移并不等于真实重复部件错误，不能从本轮推断“再加大纠偏就会成功”。该问题留待另行设计，本轮到固定预算停止。
