# Bench 条件与主体关系覆盖核查

2026-10-22。结论：**值得继续做数据，但优先补完整部位的构造与跨父关系覆盖。当前证据不能把失败全部归因于父对象少，也不支持直接复制现有条件或继续调 EARLY FM 权重。**

本轮实际读取 USER v2 的 81 条 TRAIN、39 条 DEV 条件数组、184 份父对象准入记录，以及已完成训练的 12,000 条实例曝光日志；重新计算几何描述并实看 16 页数据对照图。全程 CPU，零模型调用、零训练、零新模型生成。原数据、评分器、权重和默认入口均未改动。最终图册入口是 [review.html](review.html)。

**最重要的新发现是条件构造比类别名称更窄。**

21 条 `SEAT_SURFACE` 输入全部近似共面，表面积加权最佳拟合平面误差最大只有 0.00130%L；10 条 `BACK_SURFACE` 也全部近似共面。它们并不等于覆盖了 21 种完整座板和 10 种完整靠背：其中有前缘带、L形长椅的一翼、两条背板中的上板，以及曲面靠背的外侧平面。完整目标有曲面和细木条，不代表模型见过相应的曲面或单条木条条件。

例如 `943dde` 的完整目标有弯曲的座背过渡，但旧提取器把 `SEAT` 候选选成了座面底部平面；该候选已正确被拦截。`9e429b` 的完整三湾座壳通过了已有目标几何与外形检查，却只造出了下半段端墙、细条等条件，因此整父未入训练。这是具体的构造遗漏，不需要靠增加网络参数来解释。[逐条件几何表](condition_descriptors.csv)、[候选对照图](gallery/candidate_9e429b.png)、[943dde 对照图](gallery/candidate_943dde.png)。

**实际曝光不是每种输入平均 480 次。**

训练日志与冻结采样表逐实例一致：1,500 次更新、batch 8、12,000 个实例，25 个父各 480 次。父内按部位与变体轮转，因此具体条件只有 80–480 次。以下为实例次数，free 坐标累计量另存表中，不能当成实际梯度贡献比例。

| 部位分类 | 条件数 | 来源父数 | 实际实例数 | 实例占比 |
|---|---:|---:|---:|---:|
| 座面表面 | 21 | 21 | 3200 | 26.67% |
| 靠背表面 | 10 | 10 | 1560 | 13.00% |
| 腿与支撑 | 22 | 16 | 3240 | 27.00% |
| 座面加靠背 | 7 | 7 | 920 | 7.67% |
| 座面加支撑 | 17 | 17 | 2560 | 21.33% |
| PART_ASSEMBLY | 3 | 3 | 360 | 3.00% |
| OTHER | 1 | 1 | 160 | 1.33% |

三类具名组合合计 27 条、32% 的实例，**不能只看 PART_ASSEMBLY 的 3% 就说几乎没有组合监督**。缺口更具体：三条 PART_ASSEMBLY 分别是两墩、两长墙、两纵框关系，并不等价于 `f495` 的长座面加中部短支撑关系。[实际曝光表](part_exposure.csv)、[三条组合图](gallery/train_named_assemblies.png)。

现有增强一半原样、一半对 C 和 Y 共同做 XYZ 各轴 0.92–1.08 缩放，没有平移、旋转或独立结构变化。它扩展形状比例，但不增加独立父，也不会把两端支撑变成中段支撑。原点附近的座面高度变化很有限；位于 y=0 的中心仍留在 y=0。不过训练座面中心本身已覆盖 y=-0.139 到 1.622，`5dda` 的 y=0.879 位于范围内，不能把该坏例简单说成没见过这个高度。

**坏例至少分为覆盖不匹配和已有示范仍不稳定两类。**

以下成功与失败标签复用原 USER 的固定两噪声图审；本轮新图审针对来源 M、C、Y 和训练近邻，不重判生成分数。标签指 C 的实际采用，不要求生成与来源款式相同。

| 条件 | 原两噪声 RAW 采用 | 本轮核对的输入与邻近训练关系 | 能支持的判断 |
|---|---|---|---|
| TRAIN 35948e 座面 | NO / YES | 精确条件已训练 120 次；异父 8967e6、c89d4c 也有相近完整座面 | 缺少示范不能解释全部失败，仍有同 C 跨噪声不稳定 |
| TRAIN 943dde 背面 | YES / PARTIAL | 完整外背平面；几何近邻还包括底座长墙 | 局部形状有用途多解性，不能按部位标签强求唯一用途 |
| TRAIN bf504b 支撑 | YES / YES | 大跨度 L形侧架，训练 160 次 | 证明熟悉大侧架有采用能力，不能直接外推到小腿侧面 |
| TRAIN 838c48 组合 | YES / YES | 顶面加两墩侧面，训练 120 次 | 熟悉的组合关系能学到，不等于任意组合迁移 |
| DEV 5dda 座面 | NO / NO | **一根完整木条的上表面**；最邻近 d9de3b 是另一位置的前缘带 | 不是整块座面泛化测试；应补整条木条与主体的跨父关系 |
| DEV 9d5608 背部 | PARTIAL / PARTIAL | **水平靠背顶盖**；几何最近的三例实际都是座面 | 当前十条背部条件没有同类水平顶盖；不能将该结果直接记成竖直背板失败 |
| DEV 2d1e5e 支撑 | NO / NO | 小 L形腿侧面加短横杆；训练近邻多为墩端面、U框或扶手 | 有支撑类监督，但尺寸与连接方式不匹配，需按完整部位补覆盖 |
| DEV f495bd 组合 | PARTIAL / PARTIAL | 长座面加中段短支撑；近邻多为侧框或座背组合 | 现有组合类别不能代表这类中段承托关系已充分见过 |

所有近邻均只用 C 的位置、范围、面积和无向法线矩筛选，不读取 Y 或生成结果排名。它是找检查图的粗筛工具；例如平板靠背和底座墙可能相近，所以**不是语义等价证明，也不是新控制评分**。完整 39 条 DEV 排名保留在 [C_neighbor_ranking.csv](C_neighbor_ranking.csv)，8 条重点条件见 [diagnostic_conditions.csv](diagnostic_conditions.csv)。

**可用目标和可用条件之间确有遗漏，但不是大量干净父在等着解封。**

184 份已有目标候选中，27 份通过原几何门槛，25 份进入主池。剩余两份：`9e429b` 是条件构造不合适；`f35697` 是完整目标座面大面积缺失，仍应暂存。其余 157 份在几何、保真或面数等门槛被拦截。重复原因包括非流形边 115 份、非法有限面对 101 份、未决面对 18 份，这些计数有重叠。[逐父准入表](parent_admission_audit.csv)。

四条标作 HOLD_ADAPTER 的条件，分属 `8967e6`、`dbd069`、`df6fd3`，其实际质量记录均是 `C_NONMANIFOLD_VERTICES`；不是 N 超限、不是模型不会处理组合。完整 M 通过已登记检查，不代表从中抽取的 C 自动拥有合法的顶点邻域。应重提完整连续部位并重新核验，不应仅改标签或绕过门槛。[条件拦截表](held_condition_records.csv)。

总览可见部分简单板式、箱式对象，也有木条、L形和装饰端架；这次只能确认曲面输入与若干部位关系被漏掉。**没有给全部 184 个原始目标做统一结构标签，尚不能量化“几何清洗淘汰复杂款式”的总体偏差。** 25 个不同来源 ID 也不等于 25 个独立款式；例如 7b58a3 与 c97683 外框很相似，款式家族独立性保持 UNKNOWN。[25父总览](gallery/accepted_targets_all25.png)。

**下一步优先制作完整部位条件，先从四个已定位来源验证构造方式。**

| 优先来源 | 当前状态 | 拟补的真实输入 | 独立父增量 |
|---|---|---|---:|
| a8e987 | 已在训练，当前只有支撑条件 | 整组木条及一根完整木条的表面 | 0 |
| 7b58a3 | 已有木条组和纵向框 | 单根完整木条、完整端架等明确部位 | 0 |
| 9e429b | 完整目标已有合格记录，旧 C 全被拦截 | 完整三湾座壳或整块端墙 | 最多 1，待新 C 验收 |
| 943dde | 已在训练，但座面候选选到下表面 | 真正的曲面座面上表面与内背过渡 | 0 |

这四父是**构造器的准备集合**，不是四个新增独立父，也没有把它们当作下一轮已冻结训练预算。其后可处理 df6fd3 的双座面、8967e6/dbd069 的组合拓扑，以及完整靠背顶盖。完整清单含全父 ID、原目标路径和状态，见 [candidate_actions.csv](candidate_actions.csv)。

每条新 C 应沿真实部件界线保留整块／整条表面，K≥2，允许规律木条组或完整多部件组合；从同一个可信 M 取得严格补集 Y。先记录具体部位范围，再用部位名归类，避免“水平顶盖”与“竖直背板”共用一项解释。不能单独移动 C 而仍把不相容的旧 Y 当答案，也不把随机截出的半条腿改名为完整支撑。

待补条件验收后，模型检验的假说是：**补入相同类型、不同来源的完整部位与主体关系，能否提高独立父上 C 被合理采用和主体完整的比例，同时保留旧好例。** 如果只在新增训练父改善，应记为新增覆盖的拟合；如果 35948e 一类已见条件仍跨噪声失效，也不能继续单靠“再加父”解释。旧 DEV 已反复参与设计，下一次确认性评测需另留来源／款式分组后的新父；来源只是参考完成，仍不要求复制其款式。
