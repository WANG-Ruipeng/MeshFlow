# Bench Best-of-4：固定窄池 B、无 GT 几何选优

本轮已完成 23 个条件的全部 92 份 RAW 候选、固定 n0／n1 与 SELECTED 的三阶段对照，以及 69 页、230 格实际非盲 AI_PROXY 图审。固定选择器降低了 RAW 的平均 FF，但没有建立完整成品的整体升级：FINAL 相对 n0 的 FF 仅下降 0.168 个百分点，相对 n1 反而上升 0.816 个百分点；I 和视觉三轴交集均出现代价。保留全部候选及正例，不把增加采样算成模型权重提升，也不据此更改默认模型或选择器。

**冻结方法与比较单位。** Generator 为窄池 `NATURAL_HIGH` B 的 global22500／local1500 live 权重，文件 SHA256 为 `b9a3979c84bb851489c49f8b1539618c6908d9f64b4b579cad4e51043264f2f8`；本轮没有训练。沿用 23 父、23 C 的既有 46 请求 n0／n1，另每 C 预登记两个新噪声 n2／n3。旧 B 的 38 份面板与其实际完成的 8 份宽池新增父评测均经身份核对后复用；未将不存在的输出算作缓存。每 C 的四个候选使用相同模型、C 和 N，仅噪声不同。SELECTED 分别与固定 n0、固定 n1 配对，比较单位是同一 C，不是假称同一噪声。

选择器在结果产生前冻结：有限坐标、正确 N/K、C 精确保留且至少一张有效 free 面才有资格；对 `CF_illegal_affected_free_fraction`、`FF_illegal_affected_free_fraction`、`1 − boundary_cover` 的可用项等权取均值，最小者胜出，同分按噪声 NPZ 的 SHA256 字典序。新 cover 只用 C 自身 bbox 对角线的 1% 为距离阈值，对每条 C 开边固定 8 个中点分层查询、按边长加权，查询到有效 F 三角面的最近距离；它与原全物体 L 尺度指标分开。有效面积阈值为 `1e-12 × C_bbox_diagonal²`。闭合 C 的 cover 为 NA，从均值中排除，不记零或成功。I 只报告，不参与选择；没有读取 Y、唯一来源款式或视觉标签，结果出现后未调参。这个几何代理不认证合理采用、拓扑接合或主体完整。

全部新 RAW 保存完成后才执行新增 D0。RAW 没有 D0／GEO；BASE_POST 为一次官方 D0、C 恢复和原 GEO 及源绕序处理后的结果；CLEAN_FINAL_POST 在 BASE 上继续原冻结 `HINGE_OPP015 → ALPHA → HOLE` CPU 流程。本报告简写为 RAW、BASE、FINAL，不将两个 POST 阶段混用。

全部四候选图审显示 17/23 C 至少存在一个三轴交集候选，而选择器选中 15/23；漏选有可用候选的两个 C 是 `617fa8`、`fd355d`。这是事后描述，不是用人评训练或调整选择器，也不是可部署 oracle 的成绩。RAW 相对 n0 新增交集 `35948e`、失去 `617fa8` 与 `fd355d`；相对 n1 只失去 `617fa8`，没有新增。FINAL 相对 n0 仍为新增 `35948e`、失去 `617fa8` 与 `fd355d`；相对 n1 失去 `4cd23a`、`617fa8`，没有新增。

具体观察保留正例与失败：

- `35948e` 选中的 n2 比坏 n0 更像合理采用蓝色座面的完整座椅；固定 n1 也已经合理，不能把这一例算成对两个参考都新增成功。
- `617fa8` 选中 n2 的灰顶盖替代蓝色厚座垫，相对两个固定噪声退步。该 C 本来闭合，不因没有开放接口而判失败；问题是可见部件用途被替代。
- `4cd23a` 的选中 n3 在 POST 中蓝面浮在灰箱顶面上；固定 n1 的使用更合理。
- FOCUS 的 `27eb79`、`a8e987` 在 RAW 有完整细腿框，POST 细框严重消失或缩成髮丝；`9e429b` 的宽端支撑、`bcb4f5` 的圆端连接也在 POST 大量损失。SELECTED 的 RAW→FINAL 三轴交集失去这四例及 `4cd23a`，15→10。
- `756108` 的选中 n3 在 POST 保留较宽端部，较固定噪声的碎条状支撑有局部改善，但 C 使用和层次仍不确定。`945214` 四个 RAW 都有灰座层压在蓝 C 上，POST 删去较多灰上层后也不足以认证合理采用。
- `77aa33` 的闭合蓝垫在箱体／框架上仍有合理作用，选中 n2 留有重条与缝隙。其 N776，以及闭合厚垫 `617fa8` 的 N724，均超过冻结窄池 B 本轮训练池的最大 N384；这是明确的评测外推边界，不能当作已训练到这些 N。

**删面与面积。** FINAL 相对各自 RAW 的 free 总面积比，先逐父算比再宏平均，n0／n1／SELECTED 为 60.355／57.191／59.499%；删除原生成 RAW 槽对应的 RAW 参考面积比例为 30.290／32.000／30.416%，原生成槽保留比例为 31.291／35.925／31.934%。FINAL 实际 free 面积宏均值为 21.756／20.923／23.054 模型单位平方；FINAL 面积与 RAW 面积先求总和再相除为 63.155／57.931／63.183%，与前述逐父比率口径不同。面积比包含移动、合并、删面与新增桥面影响，不是 GT 表面保留率，也不能认证腿框保留。逐生成槽去向同时保留 RAW 与 pre-GEO 坐标面积，见 [逐输出面积](results/delivery_v1/deletion_area_per_output.csv)、[逐槽账本](results/delivery_v1/deletion_fate_per_slot.csv)。

**NA、候选与多样性。** 92/92 RAW 都通过固定候选资格检查，没有失败后换候选或静默补跑；原 near-degenerate 比例为零，选择器的独立退化定义和分母仍逐候选保存。`617fa8`、`77aa33` 的 8 个候选 cover 为闭合 C 的 NA。I 的 LOW_SUPPORT 父为 `28b9f2`、`abf250`、`945214`、`af264c`，不纳入主 I 宏均值，但原值和状态完整保留。Native 的 seam→bulk 等字段保持 `NA_NOT_SEAM_REPRESENTATION`。边界邻近 cover 不混称原 A-VMR／PMR、S 或可靠采用率。所有 92 候选的分项、资格、噪声身份与原 I 在 [候选表](selection/candidates.csv)，23 个选择在 [赢家表](selection/winners.csv)；138 对同 C 候选的面积加权面心最近邻距离／C 对角线保存在 [多样性表](selection/diversity.csv)，只描述几何变化，不当作 TMD、语义多样性或合理变化的认证。

**实际成本与执行。** 本轮新增 46 RAW、2,300 次 Euler50 generator 前向，耗时 247.12 秒；新增 13 次单次 D0 耗时 55.63 秒，另 10 个选择复用已经存在的 D0。所有 46 个固定参考的 D0 已有缓存，实际独立 POST 输出共 59 份。新增 RAW 评分 46 格、POST 评分 26 格，共 72；另复用原 138 格评分，独立保存评分共 210 格。结果比较表 207 行包含复用身份，不能当作 207 次新评分。

CPU RAW 评分 3 workers／118.13 秒，POST 评分及原 CPU 链 3 workers／366.01 秒；RAW／POST 图册各 1 worker，合计 51.92 秒。调度使用当时实际 GPU／CPU 资源，采样与其他授权训练重叠，耗时不是隔离吞吐基准。新增 RAW 最后返回时间为 `2026-10-27T10:04:11.696251+00:00`，首次新增 D0 为 `2026-10-27T10:37:11.752953+00:00`，全 RAW 先于 D0 的屏障通过。模型采样、D0、评分均无失败或重试，训练更新为零。

若从无缓存部署同一 23 C，固定一个噪声需 23 RAW／1,150 generator 前向，Best-of-4 需 92 RAW／4,600 前向；两者都只给最后的 23 个输出各做一次 D0，选优还增加候选评分 CPU 成本。这是概念上的冷启动成本，不是本轮额外执行预算。实际复用与调用账本见 [成本](results/delivery_v1/costs.json)、[执行收口](audits/execution_closeout.json)、[冻结注册](registration.json)。

本轮证据支持“同一模型的多噪声候选有可利用变化”和“该固定几何选择器能压低 RAW FF”这两个有限结论；它未证实稳定的合理采用、主体完整或最终整体质量提升，也未隔离到模型权重变化。面板已有重复开发历史、条件数只有 23、图审为非盲 AI_PROXY；不将其外推为未见父的普遍收益。保持冻结规则、所有候选、矛盾代价、原始评分与源资产，未追加采样或训练。
