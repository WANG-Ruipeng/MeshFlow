# Idea 2：纯 C 角部补片规则与来源诊断

2026-10-17。固定规则已在 TRAIN47＋DEV3 全部50条原 C 上实际完成，零神经前向、零GPU调用、不改输入几何、不接入正式训练/推理。

**纯C相邻边枚举覆盖了9/9个来源alias-owner面，但预先冻结的5°最小角条件把这9个面全部拒绝；最终选中的33个几何可行补角均不是来源alias。** 因此本轮不能把该规则用作owner/alias自动分类器，也不能把结果解释成C几何无法枚举到来源角面。

## 固定合同

在来源标签诊断之前冻结代码和阈值：C有向开放边路径u→v→w产生反向三角(w,v,u)，三个顶点均引用C自己的身份。每个提议需面积>1e-12L²、最小角≥5°、q≤10，不重复C面，与全部C有限三角无已定义非法穿插/正面积重叠；共享边绕序相反，新增边与顶点link不出现非流形。

候选按q升序、面积降序、本地顶点ID排序，贪心执行每个角中心/原C开放边容量至多一次，并查提议之间的有限面对冲突与最终局部拓扑。没有法向必须向下、来源Y、父ID或DEV标签参与提议选择。先保存全部50条C-only几何结果，才读取来源标签作诊断。

输入若已有非流形/不一致绕序，本规则保守标BLOCKED，而不归因于新提议；本次50条均通过这项输入拓扑检查。它没有为完整原C进行独立无交认证，也未访问未知free来保证未来完整mesh无交。

## 实际结果

| 统计 | TRAIN47 | DEV3 |
|---|---:|---:|
| 枚举唯一三角候选 | 400 | 24 |
| 单个提议通过全部形状/C有限面/拓扑检查 | 47 | 0 |
| 通过与其他提议容量/冲突选择 | 33 | 0 |
| 来源alias-owner面 | 6 | 3 |
| 这些来源面被初始枚举覆盖 | 6/6 | 3/3 |
| 最终选中并匹配来源alias面 | 0/33 | 0/0 |
| 来源alias面召回 | 0/6 | 0/3 |
| 源alias提议precision | 0% | NA：未提议 |

33个选中提议中2个能与某张来源free面精确身份匹配，但它们不是已登记的合法alias-owner面；另31个不匹配来源free面。这里“false proposal”只指**不匹配该唯一来源完成的合法alias**，不能据此断言它是非法几何或不能属于另一合理完成。该结果恰好说明：几何可行的可选补角，并不等于来源布局里必须复用的一张面。

原C共有424条候选路径/唯一三角；拒绝漏斗为：112重复C面、10退化、163最小角<5°、92与C非法有限面对、14通过单候选检查但与先选提议争用C开放边；其余33接受。各角中心没有多个单候选可行提议，但14例共享边竞争说明联合选择仍有容量歧义。

## 为什么9个来源alias全没被保留

| 来源父 | 来源面ID | 最小角（度） | q |
|---|---|---|---|
| 5420 | 28 | 3.670 | 9.061 |
| 893c | 121、122 | 3.718、3.718 | 13.330、13.330 |
| 9715 | 86 | 4.356 | 7.678 |
| b192 | 142、145 | 3.683、3.703 | 9.321、10.503 |
| 2d（DEV） | 69、75、77 | 4.171、4.194、4.194 | 11.873、11.822、11.822 |

九例首个拒绝原因都是预先冻结的最小角<5°，不是初始枚举找不到对应面。部分同时q>10，但因为有序熔断，不能把未经执行的后续判据记成实际拒绝原因。

这暴露了“用通用小角质量门槛筛用户C角部”的实质取舍：已有来源支持关系里会包含细长补角面。**不能为了让这次precision/recall好看，事后把5°改到3°再称同一次成功验证。** 本轮保持所有候选和拒绝不变，未试放宽条件，也不把该规则混入两条3000步训练的正式推理。

## 历史解释边界

“couple是唯一消碎片的方法”超出旧证据。ABC的熟悉TRAIN明显碎片/折层为LONG1/16、A0/16，但全28分别3/28、3/28；可见裂口5→7、主体完整27→26。已有图审只支持熟悉子集的局部观测，不能保证全组无碎片或DEV更完整。[ABC实际图审](../../r2_seam_abc_v1/REPORT.md)

R07已试过同源副本一致性及时间门控等，couple不等于直接防碰撞。B47/SEAM背景下的配对长训是新的作用背景/预算，不是首次发明共享点一致性。[研究路线](../../../r2/docs/research_route_registry.json)

DEDUP确有POST FF−5.09个百分点的有限正信号，但伴随删面/裂口；后续低N没有保住FF/接口优势并未启动SEAM去重合流。原SEAM四父没有那种去重变化。不能用“全部FF都是脏重复面”“couple肯定消裂”替代新两臂的实际几何和图审。[去重报告](../../r2_target_cleanup_c200_v1/REPORT.md)、[后续N对照](../../r2_dedup_n_sensitivity_v1/REPORT.md)
