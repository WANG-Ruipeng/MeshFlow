# B_LONG_LAYOUT frozen CPU binding and DEV diagnosis

The input is the 28 saved B_LONG_LAYOUT outputs from `r2_seam_followup_v1/layout`: TRAIN 16 and DEV 12. There are exactly 56 geometry cells, two fixed caps (1.5%L and 2.0%L) per output. No model call, training, D0 rerun, noise, query resampling, source repair or new inference layout is authorized by this protocol.

The actual original GEO_C clusters are the units. A single deterministic queue combines free seam-tip/bulk-boundary vertex midpoint aliases and complete seam-lateral/bulk-boundary edge endpoint correspondences. Every original PRE_GEO member of a moved cluster must satisfy the cap. C anchors remain fixed. The independent adapter includes the reviewed current-root guard on both endpoints and after preceding pairs inside a candidate. The old 112-cell evidence remains read-only.

All original area, angle, shape factor, normal rotation, exact duplicate, nonmanifold, baseline legal C/F preservation, new illegal C/F and anchored-orientation guards remain. FF is measured, not a rejection gate. Cleanup, source orientation and all original 124 numerical metric fields are retained. Only actual legal shared edges count toward reachable bulk; vertex sharing alone does not.

The separate DEV diagnosis lists every retained seam tip and its two lateral edges. Tip states are FREE versus C_ANCHORED. It measures nearest free bulk-open vertex, finite bulk-open segment, finite side-to-segment distance, unsigned axis angle and minimum complete original-cluster endpoint displacement. Threshold funnels distinguish already anchored tips, closed lateral edges, angle failures, identity failures, representative gap and all-member motion failures. A finite-edge interior proximity is not an endpoint match.

The actual activated DEV layout has 16, 4 and 4 edges per parent (2d, 610, 608), repeated over four noises. Counts will be reported by parent and tip state, never replaced by a mean of eight. Source labels are only used to track the three 2d aliases (zero-based edge IDs 9, 12, 13) from RAW slots to retained/deleted POST faces, illegal pairs and legal free-component connections. They do not influence binding. Associations with collisions cannot establish causal obstruction.

Inputs, scripts and original scorer definitions are hashed before dispatch and verified after completion. The first authorized request measures actual CPU RSS and elapsed time. Up to two single-thread CPU workers follow only if measured RAM/load permit. Failed or partial cells stop without silent reruns. All candidate decisions, deleted source faces, original legal edges lost, newly illegal FF pairs and fixed-query values remain available. Visual review is separately pending; this CPU report does not assert visual success.
