# SEAM A/B/C：同预算训练与配对生成报告

执行日期：2026-10-17。状态：三臂训练、固定采样、单次官方 D0、统一评分和实际图审均完成。结果不改变维护默认，不自动延长训练，不提交或推送 Git。

**这三条具体配方均未形成可替代同预算 LONG 的整体升级。** A 降低了熟悉条件的 FF，但没有修复预定的断连，DEV 质量恶化。B 在固定 800 步扩池续训下得不偿失。C 在熟悉条件上出现本轮最强的 FF 正信号和两份新的较大主体连接，但裂口、碎片与部分旧连接退化；更关键的是，**C 的推理引用头在 28/28 请求上全部选择 Null，没有实际启用共享第三点引用**。因此不能把 C 的数值收益当成所提硬共享机制已经成功。

这也回答了“其他指标有没有下降”：有，而且不能用 FF/I 的平均收益掩盖。以下保留完整分组、逐请求和图审证据。

## 1. 实际执行的三条方法

| 臂 | 唯一主要变化 | 固定训练预算 | 输入流 |
| --- | --- | ---: | --- |
| LONG | 已完成的普通 SEAM 延长对照 | 原 SEAM200 + 800 更新 | 原四条 TRAIN C |
| A_COUPLE | 一步外推终点的 seam-tip / 同源 bulk 一环角点 MSE，λ=0.1 | SEAM200 + 800 更新 | 与 LONG 逐样本、OT、增强和随机量配对 |
| B_POOL47 | 将 SEAM 续训条件池扩至已有 47 个 TRAIN 完整座面父 | SEAM200 + 800 更新 | 父均衡，共 6400 实例 |
| C_SHARED_TIP | 训练中共享同源 tip 引用，推理用新 C-only 指针/Null 头预测引用 | SEAM200 + 800 更新 | 原四条 TRAIN C，与 LONG 同 OT 流 |

三臂均从同一保留 `SEAM_SLOT_C200_step200` 的 live 生成器、匹配 AdamW、占用头及其优化器/RNG 出发。起点文件 SHA256 为 `c0c26ad26d2123062d3fd38039227d6cd05e269b5ca16e312602c45266fb3d65`。最终是预定 SEAM 累计 step1000、生成器累计 global_step13000；没有按图或分数挑 checkpoint。

batch8 / micro1、原 FM、OT 后 HYBRID0.25、增强与精度沿用冻结合同。确定性算法严格开启，TF32 关闭，SDPA math，BF16 前向和 FP32 参数/积分。没有同时加入 LOCAL_NOISE、B 表征辅助、RBF、新 D0、容量保护后处理或其他附加约束。

A 按每个真实 tip 的相邻角点先平均，再按有效 tip 和三个坐标平均；两侧均可导，所有时间段使用同一 λ。没有在推理时提供来源对应。训练源对应经过 OT 和角序映射运输，不是用预测面最近邻临时制造监督。

B 的 47 父有 43 父各曝光 136 次、4 父各 138 次。400 条 C 开放边中，366 条有来源邻面；同一源面不能占多个生成槽，故以最小 C 边 ID 作为唯一 owner，最终 360 个 owner，另外 6 条为 alias。18 条来源接口的第三点属于 C，其中 12 条为 owner；本轮仍将其第三点作为自由变量。这是覆盖更广拓扑所必需的表示兼容规则，原四条 C 的数据不变。**因此 B 检验的是这套扩大 SEAM 条件覆盖的续训方案，不是只改变一个数字、其余逐样本完全相同的数据量实验。** 原主干历史上已经见过这些训练父；不能称为首次接触 47 个独立对象。

C 的 3970 参数指针头读取 C、N、预测占用布局、原始 Gaussian 噪声及边/相对特征，不读取评测 Y 或来源邻接标签。训练监督可用来源顶点身份，推理一次 argmax 后冻结引用，保留 Null 和同面冲突处理。训练别名角点实时跟随 tip，FM 仅监督独立自由标量；该分母不同于 LONG，不能直接拿总 FM 数字当成同一误差下降。指针头使用独立新 AdamW，原生成器恢复其匹配状态。没有做来源 oracle 推理，也没有看完结果修改阈值。

附件中“第三点死记 GT、抛弃 bulk”“收敛快慢差就是断裂原因”等仍是待检验解释。训练插值 MSE 的下降本身不能证明这些机制；共享一个顶点也不自动等于共享一条合法边、流形性或完整主体。

## 2. 面板、生成量与比较口径

四个熟悉 TRAIN 条件：73、3f、85、8c；三个 DEV 条件：2d、610、608。每条 C 均使用原有四份固定噪声，每模型 28 请求；TRAIN16 与 DEV12 分开。

实际新增 A/B/C 各 28 次 Euler50，冻结 LONG 新增 DEV12 次，共 **96 次新 rollout、4800 次生成器前向、96 次新官方单次 D0**。LONG 的 TRAIN16 RAW/POST 按身份与 hash 复用。所有 RAW 齐全后才进入 D0。占用头前向 24 次、C 指针前向 28 次另计。三臂各 800 次生成器更新和 6400 个训练实例；无模型失败重试、额外校准或预算外采样。

本轮 112 份逻辑输出分别评 RAW 与 POST，共 224 个评分单元；加上只读 SEAM200 的 TRAIN16 RAW/POST 历史结果，完整逐输出表为 256 行。历史 SEAM200 没有本轮 DEV 结果，不能补成同面板比较。主对照是同预算 LONG，不能把额外 800 步收益全部归给 A/B/C。

## 5. 训练学到了什么，哪些机制没有兑现

A 的耦合项在全部 800 更新非零，累计 99,200 个有效 tip 曝光。前 50 更新平均为 0.08129，末 50 为 0.05610。相同 t∈[0.4,0.6) 的末 50 更新，seam 第三点速度 MSE：LONG 0.016330、A 0.012504；bulk MSE：LONG 0.042882、A 0.043054。说明这项监督实际作用了，但不能据此声称自由生成接续已经改善；本轮固定请求给出了相反限制。

B 的自身扩池训练曲线中，seam 第三点误差由约 0.31447 降至 0.10351，bulk 约 0.04918→0.04869。不同池的误差不能与四条件 LONG 当成固定同查询比较。当前结果只否定“这一同预算扩池续训配方可直接升级”的判断，不证明 47 父永远没用，也不证明某父必须剔除。更广曝光同时影响占用头与生成器，本轮没有额外跑 oracle 布局或固定旧占用头消融来分离它们。

实际占用布局差异尤其重要：73/3f/85/8c 的激活边数，LONG/A/C 均为 22/6/9/11，B 为 22/0/5/1；DEV 2d/610/608 则由 16/4/4 变为 13/3/1。B 在 3f 完全没有激活 seam，不能把其四份主体接续归零全部解释为“第三点和 bulk 拉扯”。扩池后占用决策与生成质量的因果份额，本轮没有独立分离。

C 的对应预测没有学成：末 50 更新的 23,800 个真实非 Null 标签，正确预测 **0**；预测非 Null 只有 5 个，其中 4 个是对真实 Null 的误报、1 个选错 owner。总体约 87.28% 准确率主要来自 Null，不能作为成功指标。全 800 更新的真实非 Null 正确数仅 5/380,800。CE 从约 1.727 降至 0.687，并不能推翻上述事实。

冻结终点实际推理中，28 请求原始 argmax 非 Null=0、冲突回退=0、最终引用角点=0。**不是后处理弄丢了引用，是预测阶段没有选出引用。** 训练中执行了来源共享与独立变量 FM；推理中没有实际共享。故 C 的几何变化只能归为这套训练组织和权重变化后的结果，不能归功于“共享第三点在推理中防撕裂”。共享索引等式在空引用集合上的成立标为 `NA_NO_PREDICTED_REFERENCE`，不是连接保证的实证。

这限制了 C 的结论：本轮实现、训练和固定测试完成，但端到端学习对应失败；既没有验证所设想的推理硬共享收益，也没有证伪在正确可预测对应下硬共享的所有可能性。没有用来源标签替换预测，也没有临时提高召回阈值。

## 7. 决策与证据边界

**本轮不晋级 A/B/C，保留原 SEAM 与同预算 LONG 对照。** A 是有限的训练与局部视觉正信号；B 是此预算和这套扩池方案的负结果；C 是熟悉条件几何分布的局部正信号，伴随明确视觉代价和推理对应失败。三个判断不应合并成“所有共享方法无效”或“只要 FF 降了就成功”。

如果只选一个下一步，优先解决 **C 的非 Null 对应是否能从推理可用信息中学出**，先形成可验证的对应学习方案，再决定是否延长完整生成器训练。检验假说是：当前源 OT 后的一环标签与这个静态 C+初始噪声头之间的映射尚未被学习到；改进后的头必须在不偷看 Y 的固定请求上产生可核验的真实非 Null 引用，并且共享执行后没有把裂口和旧连接损失扩大，才有理由把硬共享当作有效候选。不能只靠总准确率或 CE 下降过关。本报告不自动启动该实验，也不把这一假说当成已查明的根因。

本轮只涉及四个熟悉 C 和三个 DEV C，不足以证明跨类别、多样性保持、全局流形性、水密性或所有指标非劣。来源形状用于训练和对应诊断，不作为开放生成的唯一款式答案。所有共边、面积和观测均保留定义；不使用一个综合分数抵消相反代价。

## 8. 执行、资源与交付

RTX 5080 / 16303 MiB，24 逻辑 CPU。按真实正式 F/B/AdamW 峰值增量派发，最多两个训练 worker；第三臂等待足够空闲后启动。允许独立登记采样与训练重叠，未改变 batch/精度来挤入更多任务。D0 在全部 RAW 齐全后分批派发。CPU 评分和渲染各最多两个 worker、每 worker 一个计算线程。WDDM 单进程显存不可用时保留 NA，PyTorch reserved 与整卡峰值均未冒充进程显存。详细墙钟和并发范围见 [资源汇总](training_analysis/final_resource_summary.md) 与 [调度账本](DISPATCH.md)，不能把并发墙钟当孤立性能比较。
