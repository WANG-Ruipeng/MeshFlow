# Bench USER v2：1500步实际训练与固定面板结果

实验：`R2_BENCH_USER_V2_TRAINING_V1`；2026-10-21。状态：训练、固定48请求生成、三阶段评分、实际图审均完成。正式终点为 `USER_V2_S1500`，未挑选中间检查点。

**结论：这版25父／81条件数据在当前1500步配方和旧固定面板上，没有形成整体升级。** 保留局部主体形状改善、DEV座面子组的FF/I下降和非流形边减少；同时保留总体DEV的FF/I、单面孤岛恶化，以及主体接续仍未突破的结果。数据制作完成不等于模型泛化已解决；本轮也不能证明所有干净/用户式数据无效。

## 1. 实际做了什么

| 项目 | 本轮实际合同 |
|---|---|
| 数据 | 25个TRAIN来源父，81条人类部件式C；座面21、靠背10、支撑22、组合28；K2..134、N128..256 |
| 数据验收边界 | 新版本完整目标及C/Y检查、实际图审、生产CPU OT打包收据；78条有owner，2条闭合C，1条开放无owner；不是任意真实用户输入认证 |
| 起点 | 与A、COVERAGE完全相同的COMMON12000 live生成器和fresh AdamW初始快照，不从两者1500终点继续 |
| 模型/目标 | 原Native/T1+role+Geo+同步owner-only SEAM，原free-only FM、受限OT后HYBRID0.25；没有新增占用头训练、模型参数或loss |
| 更新 | 新增1500步，到global13500；batch8/micro1，lr1e-5，BF16前向/FP32参数与积分，原确定性运行时 |
| 曝光 | 12000实例；25父每父实际480实例，父内轮换部位/条件；每步4父×原尺度及XYZ U[.92,1.08]增强 |
| 评价 | 同一48请求、C/N、OLD_S15000布局、噪声、查询和截面；48次Euler50、48次单次官方Bench D0 |
| 后处理 | 恢复C/seam→GEO_C及来源定向→BASE_POST→HINGE_OPP015→ALPHA→HOLE→CLEAN_FINAL_POST；三方法相同 |

原A为58父195条件，COVERAGE为79父321条件。本轮25父是实际通过的数据规模，**没有达到此前讨论的47–67父扩充目标**。这不是仅改变“脏/干净”的单变量实验：父身份、完整目标、条件分布、池规模和每父曝光一起改变了。COMMON12000仍带旧数据训练历史，不能称为从官方模型开始的全干净训练。

旧面板原标TRAIN的4父全部不在本轮25父中，以下保留标签并写作“历史TRAIN组”；它们可能出现在COMMON历史阶段，不能改称完全未见父测试。DEV8父未进本轮训练，但已经多次用于开发，不是新独立测试集。当前面板也不测这25父上的自由生成拟合能力。

## 2. 执行和完整性

独立只读复核通过：1500次更新、12000前向、12000反向全部闭合，无失败/未决训练调用；33个冻结训练代码文件、219个受保护输入文件hash一致。48新增RAW、48单次D0完成，144新增逐输出评分齐全；复用A与COVERAGE后共432行三模型证据。全部432行的C坐标精确保留标记为真，不能据此代替连接认证。

一个授权GPU训练worker，后续采样和D0依赖顺序执行；D0与独立RAW CPU评分重叠。没有为了并发增加训练臂/采样预算。训练子进程约37.74分钟，整个自动流水线约48.14分钟；RAW约202秒、D0约62秒、POST CPU约307秒。每阶段资源快照保留于 `workflow/*_resources.json`，训练资源记录在 `training/USER_V2_SEAM/`。日志最大PyTorch reserved为3,311,403,008字节；这是训练日志范围的张量缓存峰，不等同整个GPU进程/显存峰，也不是隔离硬件benchmark。

本次结果检查新增神经调用0、重评分0；仅读取既有证据、汇总并制作固定裁剪联系图。原评分/协议/模型产物未覆盖。原自动流水线停在“等待实际图审”的历史状态；最终状态另见 [CLOSEOUT.json](CLOSEOUT.json)。

RAW的FF受影响面比例接近饱和，不能据此判断每张面肉眼都明显穿插。新模型RAW有小幅数值收益，经过相同单次D0/几何链后相对优势没有保留；这提示阶段相互作用，但没有单独隔离D0与GEO的因果。FINAL相对本模型BASE能降低FF和单面孤岛，却仍没有修好宏观C错层。不能把整个问题归为“最后焊接阈值”。

## 8. 研究决定与可解释边界

保留这份经过核验的USER v2数据及1500终点作为数据方案证据；**不将USER_V2_S1500晋级为Bench综合baseline**。目前能说的是：同共同起点、更新预算和旧请求，数据方案整体改变带来有限座面/非流形收益，但没有修好跨部位采用、碎片和主体接续。

不能由本轮断言“根因一定是数据少”“干净数据无效”“模型已经过拟合”或“再训长一点就好”。本轮同时缩小父池、改变几何/条件覆盖，且继承旧COMMON历史；没有新独立测试，也没有当前25父的固定自由生成学习曲线。

若之后只选一个待验证问题，应先区分：**新数据在自己的真实部件任务上是否能兑现为完整生成，还是当前改善只停在训练插值误差**。这会决定是否值得继续补覆盖或调整适配；本报告不自动启动该检查、训练或改变模型。
