# Terminal reward NFT pilot evidence

REPORT.md is the root-authored report. This builder adds no scientific conclusions.

All final per-output CSVs, original actual reviews (including NO and UNKNOWN), training rewards/streams, complete original metric dictionaries/topology summaries and accounting tables, engineering failure/recovery records, complete analyses and the independent audit are included. Current code and the actual original scorer sources are included with their hashes; code.diff compares repository files to recorded Git HEAD. Engineering before files and their original diffs retain execution history.

Full score.json and repeated per-face/pair/query details, detailed event/polling telemetry, large base/D0 weights, adapters, mesh arrays, and full gallery images are external. Each external score/detail has an exact path/hash/byte inventory; compact per-score files enumerate retained and externalized JSON keys. Final adapters have separate paths and hashes. LOCAL_FULL_IMAGES.md and local_full_image_catalog.json cover every reviewed image, including negative and unknown cases. These links require the original local workspace. All36 final anonymous panels also receive uniform1440px previews, without outcome selection. Previews never substitute for full per-output evidence. PACKAGING_CONTRACT_V2.json records this packaging-only change.

CHECKSUMS.json hashes every other ZIP member. The external build receipt hashes the ZIP and CHECKSUMS.json. The ZIP is reopened, every member is hashed, and CRC/member coverage is checked. Actual ZIP size and whether the10MB target was exceeded are reported; evidence is never silently dropped to meet that target. This is a compact review package, not a standalone weight/data distribution.
