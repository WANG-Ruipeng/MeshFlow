# HYBRID RAW/D0 选择器：46 请求完整实测

本轮完成了固定 M 生成结果上的零模型 CPU 后端比较。**HYBRID 明显保住了被官方 D0 处理链丢掉的主体表面，但同时带回大量冲突；本版不能记作 FF/I 或综合几何质量的升级。** D0 直接移动角点，删面发生于后续 GEO 等步骤；本比较不把整链面丢失全部归因于 D0 直接删面。选择器更接近大范围保留 RAW，再执行既有几何整理，而不是精细的局部 RAW/D0 互补。

## 1. 实际执行和比较对象

- 输入：`r2_bench_group_weight_match_v1` 的同一 M、46 个固定请求，23 父，每父同一 C 的两份固定噪声。原 RAW、官方单次 D0 连续提议、输入、查询、相机及截面全部只读复用。
- 原比较流程 M：同一单次 D0 → GEO_C/来源定向 → HINGE_OPP015 → ALPHA → HOLE。
- 候选：原 D0 连续提议与 RAW 做预登记确定性选择 → 相同 GEO_C/来源定向及完整 CPU 后端。没有重新生成、重新去噪、训练、增加查询或改变后处理参数。
- 本臂实际新增 46 次 RAW-GEO 映射、46 次候选 GEO_C、92 份 BASE/FINAL 评分。RAW-GEO 只用于定义选择邻域，**没有额外评测一个完整 GEO_RAW 对照**。
- 全部 46 请求完成，92 新评分保留原 177 字段；138 原 M 的 RAW/BASE/FINAL 行只读复用，合计 230 行。全部候选 C 坐标保持检查通过。闭合 C 不强求开放接口；Native 的 SEAM 专属字段保留原 NA。

总科学预算及恢复收据见 [四路线最终执行账本](../audits/four_routes_execution_ledger_final.json)，所有终态门槛 PASS。没有模型调用、科学失败、科学重跑或额外案例。

## 2. 选择器实际做了什么

RAW 非退化自由面满足 `D0面积/RAW面积 < 0.35` 或 `D0最短边/RAW最短边 < 0.30` 即成为 seed；随后只扩张一次原 RAW-GEO 顶点簇一环。整个被选自由面使用 RAW 坐标，其余自由面使用已保存 D0 提议，C 字节不变。没有递归扩张、GT/部位筛选、阈值扫描或根据效果回退。

| 选择范围（请求等权；本面板亦父等权） | 实测 |
|---|---:|
| seed 占原 free 面数 | 79.65% |
| 一环后回 RAW 的 free 面数 | 93.77% |
| 回 RAW 的原 free 表面积 | 90.63% |
| 全部 free 面都回 RAW | 29/46 请求 |
| RAW/D0 混合边界簇 | 108 |
| 混合簇中坐标不重合 | 108 |

因此，不能把这次改善归因于“只把少量坏面换回去”。108 个混合边界也没有天然的接合保证；坐标分歧本身不是已证实的新增撕裂，需查看原合法共边账本。

## 4. 实际图审：表面恢复明确，用途错误仍在

固定同页三列 RAW/M_D0/HYBRID，实际查看 46 页、138 格，每格两视角和两个原截面。为非盲 AI_PROXY，不是独立人类认证；图审完成后才读取数值。全部五轴和不确定标签见 [原始记录](visual_review/actual_records.csv)。三轴为同一输出同时满足 `REASONABLE ∩ PLAUSIBLE ∩ PRESENT`，**不含“无碎片/无折层”条件，也不等于合法接续成功率**。

| 本轮新鲜图审 | RAW | M_D0 FINAL | HYBRID FINAL |
|---|---:|---:|---:|
| 三轴交集 | 30/46 | 15/46 | 30/46 |
| 主体合理 | 42 | 24 | 42 |
| C 用途合理 | 31 | 30 | 31 |
| 主要支撑表面保留 | 46 | 29 | 46 |
| 明确碎片/裂口 YES | 14 | 34 | 13 |
| 明确折层/重层 YES | 18 | 14 | 18 |

M→HYBRID 三轴新增15、保留15、丢失0、两者均不满足16；这些是请求身份配对，不是15个独立父改善。RAW与HYBRID三轴总数同为30，不能说选择器学出了新的生成能力。图审与其他分支若对同一旧几何存在阈值分歧，应披露而不改标签拼排行榜，见根目录 `audits/baseline_consistency/final_v1/`。

明显保形例包括 a8/27 的腿和端板、28b9 的座条厚度、abf 的端撑、af/n1 的靠背条及扶手、bcb/n0 的环形端撑、77 两噪声的基座/框架。相反，bcb/n1 的蓝色水平输入依然插在灰色靠背中段；多个 DEV、756 仍有另造灰座或错层。座下短线、薄壁内部多线等小尺度关系常为 UNCERTAIN，没有因整体完整就自动判无碎片/无交。

## 6. 实际 CPU 成本与一次调度恢复

原 run 总墙钟 **13,324.77秒（3.70小时）**，原 `pool_workers=1`；因为资源字段适配导致保守退回串行，不能写成“实测CPU资源不足”。随后显式内存暂停原慢 worker 与 renderer，由最多2个活跃几何 worker 首次执行剩余5个未开始请求。五份结果全部核哈希后恢复原进程，原队列只读取原完成收据，不重复 GEO/评分。实际记录为 **original_pool_workers=1、recovery_active_geometry_peak=2**，旧 receipt 不改。

af/n0 请求墙钟 9,696.13秒，包含精确登记的约3,949.59秒暂停；扣除该显式暂停后的墙钟上界约5,746.54秒（95.78分钟），**仍不是纯CPU时间或独立吞吐基准**。全46请求墙钟中位数53.28秒，长尾使“几分钟快速后端”的原预估不成立。
