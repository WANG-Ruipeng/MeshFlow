# 四个方向的实际比较合同

本页说明本轮做了什么，不预告结果。最终判断见完成后的 `REPORT.md`。本轮只执行用户批准的 1.1、2.1、2.2、3.1，没有把它们串成一个同时改变多项的方案。

## 起点和比较对象

| 方向 | 实际起点 | 固定操作 | 主要比较 |
|---|---|---|---|
| 1.1 HYBRID | 冻结 M 的同一份 RAW 和单次 D0 提议 | CPU 选择整张自由面使用 RAW 或 D0，然后走同一几何链 | HYBRID FINAL 对原 M FINAL；同一 RAW |
| 2.1 EXPOSURE | M 的 global22500，匹配的 live 参数、AdamW、RNG | 新增 3000 次 Native 更新，原组损失分配和采样政策不变 | 固定终点 global25500 对冻结 M |
| 2.2 BESTOF4 | 冻结窄池 B，global22500 | 每条 C 四份固定噪声，按登记的几何规则选一个 | SELECTED 分别对 FIXED_N0、FIXED_N1 |
| 3.1 SEAM | 窄池 B 的 global22500，匹配的 live 参数、AdamW、RNG | 原版 source-owner SEAM 新增 1500 次更新，旧 C-only 小头冻结 | 固定终点 global24000 对冻结 B |

M 使用 30 父池，B 和本轮 SEAM 使用 26 父窄池。这不是四组同起点的单因素训练比较。EXPOSURE 增加计算量；SEAM 同时增加训练并改用已有表示；Best-of-4 增加推理成本；HYBRID 改变后端几何。这些边界都保留在结论中。

## 1.1：按收缩程度选 RAW/D0

只读 M 的 46 份保存结果，不调用任何模型。有效 RAW 面满足面积大于 `1e-12 L²` 且各边长度为正。D0/RAW 面积比小于 0.35，或最小边长比小于 0.30，构成种子。沿原 GEO(RAW) 角点簇只扩展一环。被选面的三个角点全部取 RAW，其余自由面全部取已恢复 C 的 D0 提议。C 不变。

这不是语义支撑检测：它也可能选中折层，或因为邻接扩张让大部分自由面回退到 RAW。需要同时检查支撑保留、选中比例、混合边界、原共边损失、新非法面对和删面损失。RAW-C 原有微小间隔与 RAW-D0 混合边界分开；不能把前者全部称作新撕裂。

## 2.1：补足曝光

新 3000 步共 24000 个实例，OLD/FOCUS/HIGH 为 18000/3000/3000。六个 HIGH 父各新增 500 次，连同 M 已有的 250 次，累计 750 次。父对象顺序和增强沿原固定 1500 步流重复两遍，但噪声、HYBRID epsilon、时间和排列种子重新登记且不复用历史实例。

保持 batch8/microbatch1、lr1e-5、原 AdamW、HYBRID0.25、原 FM 和组均方误差系数。全局步数从 22500 到 25500；不是 fresh AdamW，也不是从官方权重重启。保留 weighted objective 和 unweighted FM 两条曲线，不能用前者冒充原 FM。终点预定，不挑中间检查点。

## 2.2：几何 Best-of-4

23 条 C 各有两个历史 B 输出，新增两个独立固定噪声，共 92 个候选。新增 46 份 Euler50 RAW，全部保存后才选择。所有候选都保留，不按图片或来源 Y 换赢家。

选择规则最小化可用三项的等权平均：原 RAW 非法 CF 受影响自由面比例、原 RAW 非法 FF 受影响自由面比例、`1−C边界近邻覆盖率`。覆盖率是本轮独立定义：每条真实 C 开放边取 8 个中点分层样点，按边长加权；到有限自由三角面的距离门限为 C 自身包围盒对角线的 1%。闭合 C 的这一项为 NA，不补零。平局由冻结噪声 hash 排序。

不把 I、图审或来源形状重建加入排名。几何靠近不等于 C 被合理采用，因此所有四候选 RAW 和选择后的 POST 均做实际图审。只对选中的新噪声执行 D0；历史赢家复用既有 D0，避免为未选候选额外耗费预算。

## 3.1：原版 SEAM 继续训练

训练时用来源 owner 关系组织 seam 槽和 bulk 目标，保持原受限 OT、锚点 mask 和第三点 FM。推理只用 C、N 及冻结的既有 C-only 头，不读 Y，不使用来源 oracle，不训练新头，不增加 couple/shared-noise 等机制。闭合 C 不调用小头。

训练完整保存原目标面；无法作为 owner 的关系仍留在原 bulk，不复制、删改来源面来制造可表示性。原 SEAM 的角点掩码接口扩展到已审计的 N128..799 范围，N800 仍不允许。

## 统一评价

23 父、每父一条 C、每条两个原固定噪声，构成 46 请求主面板。组别分别保留：OLD、FOCUS、DEV、HOLDOUT、HIGH_TRAIN、HIGH_HOLDOUT、NEW_WIDE_TRAIN。最后一组沿用旧名称；这四父被 M 看过，但没有被窄池 B/SEAM 看过。旧开发面板经过多轮观察，不能称为独立最终测试集。

RAW、单次官方 D0 加 GEO_C 的 BASE_POST、相同 HINGE_OPP015 → ALPHA → HOLE 的 CLEAN_FINAL_POST 分开。来源角序恢复合同一致，保存原 C。完整 177 字段、原分母和适用状态保留；I 的 LOW_SUPPORT 不补零，闭合 C 不要求开放接续。使用来源数据核对身份和训练匹配，不以复原唯一来源款式判生成成功。

实际图审检查两视角和两个固定位置截面，五轴分别记录：整体完整合理、C 用途、主要支撑、可见碎片/裂口、重层/折叠。允许不确定，图审为非匿名 AI_PROXY，不称作独立人类评审。数值不能自动生成图审标签；视觉三轴通过也不认证零相交。

## 执行与恢复

两个训练进程各有独立模型、优化器、随机流和输出目录。每次 GPU 派发前测实际资源；在保留至少 2 GiB 额外余量的基础上逐个启动。CPU 评分和图审可以并行。并发耗时不当成隔离性能基准。

所有科学调用记账。仅完整、安全保存的更新边界可精确恢复；不静默重放失败调用、不改精度或 batch 凑并发、不自动延长。完成四项后停止；不清理旧资产、不替换默认模型、不 commit/push。
