# Bench 条件控制迁移：训练与推理合同

本轮检验 **MeshflowCrtl 的条件适配方法能否用于 Chair 以外的 Bench 类别**。两个新模型都从官方 Bench 生成器开始训练；这不属于 Chair 权重对 Bench 的零样本泛化，也不构成跨所有类别的能力证明。本文记录已冻结的方法合同；最终实际调用数、完成状态和结果以训练审计与评价报告为准。

## 数据与评测身份

- 数据来自本地官方 Bench（ShapeNet `02828884`）资产，每父保留一个现成网格版本，`N=128..256`。不修复或去重训练目标的面；原有目标缺陷保留并记录。
- 64 个独立训练父、8 个条件训练未见的 DEV 父；确切父、官方 train/test 身份和几何身份见 `data/manifest.json`。DEV 中是否在官方生成器预训练阶段出现过，单独标记，不能把“条件训练未见”一概写成“预训练未见”。
- 每父一条 `PLANAR_FULL` 条件，实际定义是从来源网格选择连贯、规则、近共面的区域，`K>=2`，优先较宽的水平区域。它可能是顶面、侧面或底面；不将其自动称为语义完整座面。
- C 保留真实来源面和顶点身份、原角序及其内部规范化逆映射。C 内部有限三角面核查通过不等于完整来源目标无自交。
- 冻结评测为 4 个训练父和全部 8 个 DEV 父，每条 C 两份固定标准高斯噪声，共每臂 24、两臂 48 个请求。每个配对请求使用同一保存噪声数组，不按模型结果换父、换 C 或换噪声。

## 两臂唯一核心差别

| 项目 | PLAIN | SEAM |
|---|---|---|
| 条件接口 | Native/T1 + role + Geo | 同一接口，加共享原边槽的角点约束 |
| 输入 C | 相同来源 C，采样中硬保持 | 相同来源 C，采样中硬保持 |
| free 表示 | 所有 free 三角面三个角点自由生成 | 激活 seam 槽的两个角点引用 C 开放边端点，第三点自由生成；其余为 bulk |
| 训练匹配 | 全部 free 面的原嵌套 OT | 来源 owner 面固定到对应 seam 槽，其余 bulk 单独 OT |
| FM 分母 | `9(N-K)`，在有效 batch 全部 free 标量上平均 | `9(N-K)-6S`，在有效 batch 全部自由标量上平均 |
| 独立小头 | 无 | 833 参数 C-only 占用头；仅 BCE，不向生成器反传 |

SEAM 的训练来源面若同时接触两条 C 边，只为预定 owner 分配一次 seam 槽；alias 不再分配重复 seam 面。第三点即使属于 C 的来源顶点，也仍作为自由第三点预测，不给推理额外来源答案。推理占用仅由 C 几何/拓扑、请求 N 和小头预测决定；不查阅未知完整目标、来源 owner 布局或父 ID。

## 共同初始化与优化

两臂均加载 `output/120m-ot-v-bench/checkpoints/01000000.pt` 的官方 **EMA**，然后建立相同 Native/T1 + role + Geo。官方文件 SHA256 为 `00fc5ddb5bc5690cd53fe4f092ee3320e23437a287464fa5639120c2bb82a505`。

实际 CPU 双初始化审计确认：两臂完整条件模型初态 SHA256 均为 `28e1dc6903c28820f9bd39a99eb9bdadc1f4c6289af4a686dfb664e4ce996132`；生成器共 130,401,155 参数，role 和 Geo 出口严格为零。零出口不意味着带 C 的 T1 前向与无条件模型逐位等价。没有加载任何 Chair 的 START、R2、FULL 或 SEAM 权重。

- 每臂预定 3,000 次优化器更新，有效 batch 8、microbatch 1。每 batch 从同一打乱父对象流取 4 个父，各有一个原尺度实例和一个 x 轴 `[0.9,1.1]` 缩放实例；两臂父、增强、时间、原始高斯噪声、HYBRID epsilon 及排列种子完全配对。
- 新 AdamW 从第 0 步开始；生成器 `lr=1e-5`、betas `(0.9,0.95)`、weight decay 0、梯度范数裁剪 1。全生成器参数更新，无新辅助几何 loss、teacher、READOUT、B、couple 或 RL。
- 原 free-only FM；先按各自有效 free 角色执行 OT，再做全程 `HYBRID lambda=0.25`。两臂因自由度和角色不同，OT 匹配本来就不相同，不复用不对应的匹配答案。
- SEAM 占用头独立 fresh AdamW，`lr=0.001`、betas `(0.9,0.95)`、weight decay 0、裁剪 1。沿用原加权 BCE 定义，按冻结训练池的 311 个 owner、118 个 inactive 标签计算 `[negative,positive]=[1.8177966101694916,0.6897106109324759]`。推理固定 `logit>=0`，不使用 DEV 校准阈值。
- BF16 前向，FP32 参数、AdamW 和积分；严格确定性算法、TF32 关闭、SDPA math，CUDA 初始化前设置 `CUBLAS_WORKSPACE_CONFIG=:4096:8`。没有为并行降低 batch、精度或面数预算。
- 保存 step1000、固定主终点 step3000 和滚动恢复检查点。主结果只使用 step3000，不能看图选择中间终点。若发生未完成调用或检查点落后于已消费更新，禁止静默回退重放。

## 推理与后处理

两臂从同一保存的标准 Gaussian free 数组出发，以 Euler50 积分；推理不使用 HYBRID 混噪。SEAM 每条 C 只预测一次布局，两份噪声共用该布局。逐步保持 C，SEAM 还保持预测激活槽的两个锚点；保存全部 51 个状态和 RAW 来源角点映射。

全部 48 份 RAW 完成后，使用同一份官方 **Bench** D0 单次处理，随后恢复原 C 和对应 seam 锚点，再执行原 GEO_C 和来源绕序导出。Bench D0 是类别匹配的独立资产，不冒用 Chair D0。RAW/POST 分开评价；本轮不加入 HINGE、额外簇绑定、RBF、多次去噪或其他后处理变量。

采用、整体完整性和碎片/裂口的图审应保留实际评阅记录，不能从数值分数自动生成成功标签。来源完整 Bench 只是一个可能完成，不用它的唯一款式作为开放生成的成功标准。

## 预算与解释边界

3,000×8 对每臂是 24,000 次训练样本曝光，64 父平均 375 次；真实逐父分布及随机种子以 `training_audit/paired_exposure_full.csv` 与 `exposure_per_parent.csv` 为准。两臂共享输入流但不共享模型、优化器或可变 RNG。

并行由真实资源测量决定：先启动一个已授权正式 worker，测过包含反向与 AdamW 的更新，再增量启动第二个。allocator 峰值与整进程显存分别解释；并行墙钟不作为隔离性能 benchmark。

训练曲线上的 FM 分母和自由角色不同；FM 数值不能单独证明哪种模型生成质量更好。SEAM 的第三点误差对 PLAIN 为 NA。最终以配对 RAW/POST 输出、合法接口和可达区域、FF/CF/I、有效面和碎片代价及完整图审共同判断方法迁移是否出现正信号。
