============================================================
四、教师和学生究竟学习哪一个函数
============================================================

对输入：
  X = C ∪ F

在denoiser坐标中执行：
  X_d = a * X

教师读取整份X_d，包括C和F；
运行一次确定性的decoder修正：
  proposal_T_d = X_d + delta_T_d

定义实际有效教师残差：
  r_T_d = proposal_T_d - X_d

学生同样：
  proposal_S_d = X_d + delta_S_d
  r_S_d = proposal_S_d - X_d

所有残差相加和差值在FP32进行。
训练只监督free槽位：

  L_KD =
    sum_i ||r_S_d[i, free] - stopgrad(r_T_d[i, free])||²
    / (9 * sum_i |F_i|)

这是整batch free标量平均，不是逐样本loss平均。
不另外按real/synthetic或K给loss加权。

C输出不用学生预测，导出统一采用：
  output_model[F] = proposal_model[F]
  output_model[C] = original_C_bytes

网络内部可以读取C，来自free损失的梯度可以通过C特征传播。
不要把所有C hidden detach。
但不把C预测误差混进主loss来稀释free蒸馏误差。

关键限制：
- 教师eval、requires_grad=False、无反向。
- 禁止调用会随机encode/sample或再次加噪的训练forward。
- 用上轮已核验的显式decode/残差路径。
- 不把post_quant_linear重复执行两次。
- 不把已经包含输入坐标的输出再加一次输入。
- 师生都不在推理时加入Gaussian。
- 不将GEO后的删面/合并结果当作逐槽坐标标签。

教师缓存保存FP32 input_d、proposal_T_d或等价精确残差。
若历史缓存无法还原这一精确合同，
按预算重新查询教师，不能假装近似逆缩放等于原张量。

不要用：
  S(X) 去拟合 T(S(X))
这会改变为教师固定点/重复去噪目标，
不是本轮要复制的一次T(X)。

============================================================
九、蒸馏误差：必须超过“不修”的恒等参照
============================================================

对每个输入只统计free有效标量：

  E_i = mean((r_S - r_T)^2)
  B_i = mean(r_T^2)

B_i就是残差恒等预测r=0的教师模仿误差。

同时报告：
- E_i的绝对值；
- B_i；
- R_i = E_i / B_i；
- 按free标量汇总的总误差/总教师残差能量；
- 逐例R_i的中位数、分位数；
- ||r_S|| / ||r_T||；
- cos(r_S, r_T)；
- 师生preGEO坐标差的RMS、p95、max，
  同时给denoiser单位和模型单位/L。

若B_i≤1e-14 denoiser单位平方，
该例相对比例标LOW_SIGNAL/NA，只报告绝对误差。
这个阈值只防除零，不是质量标准，不从绝对主表删除样本。
余弦遇到零向量也标NA。

R<1只说明比完全不修更接近教师，
不是“已经接近教师”或“保留了某百分比几何质量”。
不得把1-R直接叫去噪能力保留率。

训练缓存、内部校验、新旧DEV分别汇总。
真实RAW与合成输入分别汇总，
避免合成任务容易拟合掩盖真实部署分布差异。

额外复用上一轮18个冻结合成DEV：
- 6 clean；
- 12 noisy。

学生新增18次前向。
D0对应结果优先复用，缺精确目标时预算内补一次教师查询。

============================================================
十三、如何判断结果，不把“更小”直接写成成功
============================================================

先回答三个独立问题：

A. 容量压缩是否真正完成？
- 实际参数、权重和独立部署依赖是否明显降低？
- 学生是否仍暗中调用教师？
- 教师卸载后能否独立推理？

B. 教师函数是否被学到？
- 固定训练样本和内部校验上是否都比恒等预测更好？
- 真实DEV残差误差是否明显低于恒等参照？
- 是否只有合成数据拟合好，真实RAW仍拟合差？
- 训练误差很低、校验误差高，与两者都高分开解释。
- 不依据一轮有限预算宣布小网络理论容量不足。

C. 下游质量和效率是否值得使用？
- 师生同GEO下是否保持相近FF/CF/I和结构？
- 是否丢掉D0已有的少数接合？
- 是否以更多删除或细构件损伤换取低FF？
- 实际显存或耗时有没有有意义的下降？

本轮不以“必须超过教师”作为通过条件，
也不以“学生接缝仍未解决”单独否定压缩价值。

可使用以下结果分类，但必须附具体数值：

PROMISING_COMPRESSION：
  明显更小；真实RAW上确实近似教师；
  同POST质量接近，无明确新增严重结构损伤；
  至少权重/显存/延迟中的实际资源收益成立。

FUNCTION_FIT_BUT_POST_SENSITIVE：
  坐标残差拟合较好，但合并后拓扑/删面/相交明显偏离。

SYNTHETIC_ONLY_TRANSFER：
  合成输入模仿好，真实RAW没有保住教师能力。

SIZE_QUALITY_TRADEOFF：
  资源下降明确，但几何或结构代价也明确。

INSUFFICIENT_FIT_WITHIN_BUDGET：
  固定4000步尚未学会足够准确的教师映射。

EXECUTION_BLOCKED：
  资产、数据或数值/资源阻塞，未完成主实验。

以上是描述性开发分类，不是统计显著性或论文录用标准。
不要为得到某种分类事后改阈值或剔除坏例。
本轮只产生一个研究候选，不自动替换D0。
