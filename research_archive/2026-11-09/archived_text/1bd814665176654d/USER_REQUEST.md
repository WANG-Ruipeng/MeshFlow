**这轮最重要的发现，不是BLEND没有超过RBF，而是：我们此前把“模型内部的角点排列必须固定”，和“最终网格必须方向一致”混成了一个合同。对这批输入，这两个要求本来就不相容。**

这个发现需要修正之前对“方向接合失败”的一部分解释，但**不会推翻真实缝隙、座面错层、非法相交和边界匹配不足的结果**。

我对这份报告有三个判断：

**方向审计找到了一个明确的表示性问题，值得优先修正。BLEND完成了有界传播的设计目标，却没有得到更好的几何折中。RBF仍有局部接近与共边信号，但还不能凭方向问题被解释清楚，就升级成可靠接合方法。**

以下依据你贴出的报告。我复算了显示表格的差值、收益保留比例和逐父变化；**没有读取本轮完整CSV、网格或原图，也没有重跑处理或评分。**

## 一、方向矛盾这次有了明确来源，不再只是“可能法向没整理好”

报告给出的证据链很完整：

| 环节 | 本轮观察 |
|---|---|
| 原来源C所选面的45条双面共享边 | 绕序全部相反 |
| 按保存的角点规范化排列重排后 | 其中28条变成同向 |
| 六个条件 | 五个已有直接C–C方向矛盾 |
| 同一条件的两份噪声 | 使该问题出现在10/12输出 |
| D0、RBF、BLEND | 都遇到这个固定C矛盾，不是某个后处理独有 |

**这直接排除了两种错误解释：不能把这些C内部方向矛盾归因于RBF，也不能说这六个条件的原始来源面本来就方向不一致。**

28/45是“所检查共享边中方向关系改变的比例”，约62.2%，不是翻了62.2%的三角形，更不是62.2%的表面产生物理损伤。

### 为什么固定C以后，翻多少free面都解决不了？

用报告的二元翻转变量表示，面 \(i\) 是否翻转记为 \(f_i\in\{0,1\}\)。

两张面当前沿共享边同向时，一致定向要求：

\[
f_i\oplus f_j=1.
\]

但两张面都属于C，严格合同又要求：

\[
f_i=f_j=0.
\]

于是：

\[
0\oplus0=1,
\]

直接矛盾。

**这个矛盾不经过任何free面。** 所以，无论新增free如何生成、去噪器如何修正、后处理怎样翻free，都不能在保持这两张C原绕序的同时满足该一致性要求。

这不是优化器没找到解，也不是计算量不足，而是**当前约束没有解**。

不过，这个结论限定在报告审计的六条条件及对应图结构。不能顺势扩大成“全部训练数据都存在同样问题”或“整个模型一直在学习错误法向”。

## 二、这要求我们修正什么旧结论，又不修正什么？

### 需要修正：不能再把当前反向路径可达性直接当成几何接合能力

例如RBF的86ec n0：

\[
\text{无方向合法图可达面积}=85.333\%,
\]

\[
\text{当前反向绕序路径可达面积}=3.047\%.
\]

现在已经知道，固定C本身阻断了整体方向求解。**这两个数的巨大差距，不能解释为另外82%左右的表面与C隔着物理缝隙。**

我之前虽然强调“同向共边不等于没有连接”，但仍把反向绕序没有增加当成了比较重要的负面证据。**这部分现在必须进一步收窄：它首先说明当前导出的方向合同没有满足，不能单独归咎于候选没有改善几何。**

历史锚点去噪报告也把“新增边不是相反绕序”单列为限制；这类记录本身没有错，但对相同六个条件，其解释需要结合本次发现，不能继续当成纯粹的模型接合能力证据。Pasted text Pasted text

### 不需要修正：几何事实没有因为方向归因改变而消失

按本报告使用的无方向定义，下列结果仍然成立：

| 结果 | 是否受本次方向解释修正影响 |
|---|---|
| 实际共享了哪些顶点、哪些边 | 不受影响 |
| C边界顶点到F顶点的距离 | 不受影响 |
| CF／FF非法相交、I冲突覆盖 | 本轮几何等价核验下不受影响 |
| 三角形面积、最小角、删面 | 不受影响 |
| 四份座面没有有效C/F共边 | **仍然成立** |
| 蓝C留在另一张主座面下面 | **仍然是未解决的用途／布局问题** |
| 当前绕序能否沿全图一致传播 | **需要重新解释和另行验证** |

**因此，这不是“原来control其实已经好了，只是指标误判”。** 更准确的是：

> 我们发现了一个确实会妨碍方向评价和定向导出的表示问题；但它不是座面分离、边界未匹配或RBF相交代价的充分解释。

报告还保留了奇偶环矛盾和非流形边。因此，即使消除来源规范化造成的C–C矛盾，也不能预设全部POST立即可一致定向，更不能预设它们全部流形、水密。

## 三、我更建议“恢复用户原始绕序”，而不是笼统放宽成“允许随便翻C”

这里有一个重要的合同选择。

我们实际需要保护的，通常是：

> **用户给的那些顶点、三角面、连接关系，以及用户确实提供且要求保留的朝向。**

但模型内部为了规范化而采用的角点顺序，不一定就是用户的原始朝向。

对本轮已有完整来源映射的C，可以区分：

\[
C_{\mathrm{user}}
\overset{P}{\longrightarrow}
C_{\mathrm{model}},
\]

其中 \(P\) 是每张面的角点规范化排列。

输出时则有一个很自然的候选：

\[
C_{\mathrm{export}}
=
P^{-1}C_{\mathrm{model}}.
\]

**不是移动C，也不是把它重三角化，而是把模型内部排列还原成用户／来源输入的排列。**

### 这比“为了提高方向得分而翻C”更合理

如果原来源C方向一致，且映射保存正确，恢复原始绕序可以同时做到：

- 顶点坐标值不变；
- 原三角面及其顶点关联不变；
- 不增加、不删除C面；
- 恢复原输入朝向，而不是按生成结果临时决定C该朝哪边。

但需要明确：**导出的有序角点数组会不同于当前规范化数组，所以它不是旧“规范化C逐字节不变”导出合同下的同一个结果。** 必须另起版本，旧结果继续保留。

同时，任意换序也并非没有语义区别。循环置换保持三角形朝向，交换两个角点则会反向；若有逐角属性，也须跟随同一映射。不能只核对“无序三个点相同”，就宣称所有输入语义完全未变。

### 最小改动可以只发生在导出端

我不建议马上改训练数据的规范化方式，再重新训练整个R2。

更干净的第一步是：

```text
现有生成与去噪计算完全不变
             ↓
保存的POST几何完全不动
             ↓
C按原始输入排列恢复
             ↓
以恢复后的C朝向为固定条件，整理free方向
```

这样可以先独立回答：

> **此前低方向可达性中，有多少是内部表示没有正确还原造成的？**

如果改变模型输入排序，可能还涉及特征、配对和数值路径；本报告没有测试这些影响。**不能未经验证就假定“模型应当等变，所以前向一定完全一样”。**

这一轮优先修正导出与评价合同，不必先动生成器或D0。

## 四、BLEND的结论很清楚：幅度约束成功了，但“更温和就更安全”的期待没有成立

BLEND确实完成了我们给它安排的数学目标：

\[
u(x)=\sum_i\alpha_i(x)b_i,
\qquad
\alpha_i\geq0,\quad\sum_i\alpha_i\leq1,
\]

因此：

\[
\|u(x)\|
\leq
\max_i\|b_i\|.
\]

本轮最大实际位移为0.116977，小于0.184163的安全半径，所有限幅和舍入修正均未触发。

**所以，它不是仍然发生RBF式大幅外推，只是被隐藏的裁剪救了回来。这个设计性质实际兑现了。**

但几何结果并没有随之全面改善：

| 相对D0的变化 | RBF | BLEND |
|---|---:|---:|
| POST边界均距相对下降 | **8.25%** | 2.77% |
| 严格A-VMR增加 | **12.103 pp** | 5.688 pp |
| A-VMR@2%L增加 | **4.001 pp** | 0.595 pp |
| CF变化 | **−1.070 pp** | −0.680 pp |
| FF变化 | +0.530 pp | **+1.391 pp** |
| I变化 | +0.704 pp | **+0.301 pp** |
| 小角率变化 | +0.392 pp | **−0.132 pp** |
| 有效共边总数 | **9** | 3 |

按显示值复算，BLEND保留了约：

\[
33.6\%\text{的RBF平均距离净收益},
\]

\[
47.0\%\text{的RBF严格A-VMR净收益}.
\]

同时，它减少了约57.2%的RBF平均I增量。

这些比例是**均值变化之比**，不是成功案例比例，也不是几何质量保留率。它们说明：**BLEND确实压低了某些代价，但牺牲了相当一部分原收益，FF还更高。**

尤其BLEND相对RBF的距离12/12都更大，这不是一个只在少数坏例上减弱传播、其他位置保持原收益的选择性改进。

### 但不能把这一轮叫作“只测了位移幅度”

RBF的系数来自核矩阵求解；BLEND是非负、归一化融合。改变的不只是幅度，还包括不同锚点位移怎样相消、组合，以及最终的传播方向和空间分布。

因此，不能从结果推导：

> “原来大幅放大是好事，必须恢复它。”

能推导的只是：

> **这个有界融合版本，比原RBF更少出现部分大I尾部，但没有保住整体接近与连接收益。**

## 五、BLEND的FF代价比两个I尾部更普遍，不能只修尾部就认为问题结束

报告已经指出，866e n0和bdd29 n0的I代价明显降低。但新的风险集中到了86ec，两份噪声的I和FF都增加。

按你给出的逐例表合并两噪声，BLEND−D0的父均FF变化约为：

| 父 | FF变化 |
|---|---:|
| 33ec | +1.575 pp |
| 534b | −1.210 pp |
| 866e | +2.109 pp |
| 86ec | +4.939 pp |
| bdd2 | +0.926 pp |
| f596 | +0.006 pp |

**五个父增加，只有一个父下降。** 仅作敏感性分析，去掉最重的86ec，剩余五父的FF仍平均增加约0.681个百分点；去掉任意一个父，均值代价都没有反转。正式结果当然仍保留六父。

这说明：

> **BLEND的FF问题不只是原RBF两个大I尾部换了位置，而是更分散的几何取舍。**

为什么小位移仍可能增加相交？从几何上，决定两张邻近面的相对关系的是：

\[
(x_i+u_i)-(x_j+u_j)
=
(x_i-x_j)+(u_i-u_j).
\]

即使每个 \(\|u_i\|\) 都有界，也没有自动限制邻近角点之间的相对位移 \(u_i-u_j\)。而最终GEO又有合并阈值，较小改动仍可能改变哪些角点合并、哪些局部交叉被保留。

**这只是数学上的可能机制，不是本轮已完成的唯一归因。** PRE完整CF／FF／I没有预算，因此当前不能分摊“融合阶段造成多少、GEO阶段造成多少”。

有界是一个值得保留的设计性质，但它本身不是无交或结构安全保证。

## 六、这轮给研究路线的真正帮助，是把三个问题分开了

我们现在可以比以前更准确地说：

### 1．输入表示与方向合同

这一项已有明确来源证据：原C一致，规范化后出现矛盾，又被严格锁定。

**这是应当先纠正的系统问题，不需要一个新loss来解决。**

### 2．C/F局部几何协调

RBF在11/12输出上改善距离，并形成少量实际共边；BLEND说明，有界传播可以得到一部分收益，但没有形成更好的总体折中。

**这条方向还有局部信号，但不能再把“限制位移大小”当成足够的安全措施。**

### 3．USER部件是否真正接入合理物体

四份座面仍无有效共边，图审仍记录错层、另生主座面和背板并存。

**这不是恢复绕序会自动解决的问题，也不能靠方向指标重新解释成成功。**

所以，当前既不应说“RBF可以晋级了，原来只是方向指标有问题”，也不应说“全部探索都失败了”。**我们找到了一个必须修正的表示矛盾，同时仍有一部分真实控制缺口。**

## 七、下一步我赞同先校正方向合同，但要把它当成可用性修正，而不是新增学习收益

我会把下一项工作限定为一件事：

> **基于同一批已保存POST，建立“恢复原始C排列、仅整理free朝向”的独立导出与评价版本。**

核心是恢复有来源依据的C方向，不是按哪种翻法让RBF得分最高来选C朝向。D0、RBF、BLEND必须使用相同规则。

这项检查需要同时保留两类结果：

**方向结果：** 来源规范化导致的C–C矛盾是否消失；free能否在固定原C方向下统一；还有多少环约束矛盾或非流形问题。

**几何不变结果：** 坐标、无序面集合、连接、距离、无方向共边、CF／FF／I、小角和删面是否保持原值。原始缓存仍对应原绕序，不把继承结果冒称新跑了一遍评分。

如果方向可达性提高，应该写成：

> **正确恢复输入表示，使已有几何连接能够被一致定向。**

而不是：

> **模型新增生成了更多接缝。**

如果修正后仍有方向冲突，就继续将其分类，而不是自动删面、拆点或放开C方向来凑一个可定向输出。

---

**我的最终判断：这轮方向审计的重要性，高于BLEND本身的胜负。它揭示了一个我们此前确实没有理清的边界——不可变用户几何，不等于不可变的内部规范化排列。**

默认仍保留D0，RBF继续作为局部协调候选，BLEND不替代。**先把原输入几何、模型表示和最终定向导出分清楚，再评价哪些连接真的缺失、哪些连接只是被错误的方向合同挡住。**

这不是为了让指标变好而放松标准，而是避免要求生成器和后处理去完成一个由输入表示预先制造的无解任务。
