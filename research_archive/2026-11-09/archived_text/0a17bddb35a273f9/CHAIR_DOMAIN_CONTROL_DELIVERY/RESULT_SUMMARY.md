# 结果摘要

研究问题是 Chair 域内三角几何条件能否有效控制补全与宽度，以及 Geo、Joint 在匹配更新预算下分别带来什么收益和代价。三臂代码名 `T1 / Geo / Full` 分别对应 **Native / Native+Geo / Native+Geo+Joint**。本轮从各自 repair_v2 的 step1000 恢复，Full 既有几何预热没有重新开始。

| 项目 | 实际完成 |
|---|---:|
| 父对象与划分 | 48；训练/验证/留出 = 32/8/8 |
| 三臂新增 optimizer 更新 | 各 3000，合计 9000 |
| 终点累计逻辑步数 | 各 4000 |
| 起点 / 中间 / 终点生成 | 120 / 48 / 414 |
| 完整生成总数 | 582；重复 0 |
| 终点几何不适用格 | 18，保留为 NA |
| 固定 teacher / 有限预检前向 | 288 / 27 |
| 总模型前向 | 101415 / 上限 102420 |
| 解析候选 / 跨条件评分单元 | 432 / 648，均非新增模型生成 |

训练 C 实际可用 453 个，目标 512 个中的其余 59 个如实登记不可用；没有通过删除困难父对象、重网格或看输出后改样本来补齐。三臂沿用冻结流和噪声。没有新增 loss、改 JEdge5 系数或时间门控、扫描学习率/EMA/求解器、运行 Pair/焊接、增加预算或切换默认模型。

主要结论如下，均以正式 CSV 的父等权统计为准：

- **Geo 有局部覆盖收益，尚未证明整体更优。** 相对 Native，A 的训练20%/训练40%/验证20%/验证40%覆盖分别增加约 1.28/6.14/2.92/2.12 个百分点。RMS 仅训练40%均值改善约 0.608%L，6/7 个有效父改善；另外三格均值变差。40%条件同时改变 C、free 补集与有效父集合，不是纯信息量因果比较。
- **宽度控制在验证父上很弱。** Native/Geo/Joint 的终点验证宽度斜率均值约 0.121/0.081/0.061，理想值为 1。Geo 的第一噪声起终点配对宽度误差：训练父从 0.05774 降至 0.04886 L0，验证父从 0.13946 增至 0.15642 L0。不能把斜率变化单独解释为绝对控制质量改善。
- **没有整体优于直接后拉伸 Post-scale 的证据。** 解析参照用于检验不响应或整体仿射缩放能够解释多少表现；Post-scale 使用原条件下的输出，信息条件不同，不能据此宣称模型已具备复杂结构推理或任意局部编辑。
- **Joint 未保住覆盖。** 相对 Geo，A 四格覆盖均下降。验证40%接口边 RMS 改善约 0.158%L，同时 FF 受影响自由面增加约 1.224 个百分点。接口收益伴随其他质量代价。
- **留出回归存在相交退化。** 新4000相对源1000，三臂平均 RMS 和覆盖有所改善，但 FF 受影响自由面比例分别增加约 1.57/1.39/1.68 个百分点；不能写成“无回归”。严格水密为 NOT_RUN。

这些结论来自单训练 seed 的已观察域内开发性验证。A20 每个划分有效父均为 8/8；A40 训练为 7/8、验证为 6/8。B 每划分只有 4 个父和 2 个噪声，即 8 条终点响应曲线；CSV 在三个 alpha 行重复展示的斜率不是 24 个独立观测。真正起终点配对仅使用第一噪声。中间生成仅有 8 个验证父的 A20 第一噪声，其余中间项保持 NA。

执行 23/23 阶段实际完成。Full 起点评价曾发生一次文件原子替换 I/O 中断，已保存原始日志、状态、账本和恢复审计；恢复复用了全部 40 条既有生成，零重放。旧 BF16 置换 FAIL 保留，未重跑历史补数。A/C 图件的 48 张排版副本只调整标题留白，原图保留，未增加模型或评分调用。详细证据见 [DELIVERY_NOTES.md](native_t1/runs/chair_domain_control_v1/DELIVERY_NOTES.md)。
