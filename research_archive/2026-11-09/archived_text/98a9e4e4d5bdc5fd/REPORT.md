# SEAM 几何保护实测：接续收益保住了，但四步升级不能直接串起来训练

完成日期：2026-10-16。实际执行 CPU 占用校准、来源法向反例检查、16份固定 D0 提议的容量保护与完整评分，以及 RAW→PRE_GEO→POST 面对账本。零神经网络前向、零训练、零新噪声；没有切默认、删除权重、commit 或 push。

**结论：保留 SEAM_SLOT 的原接续正结果，也保留容量保护的局部拓扑收益；本版不能作为 FF/I 已修好的稳定底座启动 RL。** 占用校准失去全部 Null 判断，所提60°法向约束会误罚正常侧壁，容量保护虽消除了18条 C/F 非流形边，却新增11对 seam–bulk 非法相交，I 尾部基本没变。这不是 SEAM 路线被否定，而是三个修正需要分开看。

## 3. 占用权重核查与一次解析校准

实际BCE为负类权重8.25、正类权重66/124≈0.532258，按每更新132边全局平均。代码符合正式合同，未发现权重写反。旧阈值z≥0是偏重Null的成本敏感规则；在理想总体最优条件下对应原概率≥93.94%，不是未加权的50%。

固定解析去权重为 `z_corrected = z + log(15.5)`，原logit阈值为−2.740840。此公式不证明200步网络已概率校准；没有扫阈值挑最好结果。

## 4. 60°法向约束被来源几何反例否定

要求 seam 法向与邻接C面法向夹角<60°，会拒绝四C中 **50/62** 个合法来源接口，以及全表341/389个；原已有合法POST共边中，FULL4的113/131和SEAM的155/175也不满足。不能按这个公式开训。

设C定向边为t，面法向为n，向内共法线m=n×t；第三点相对边中点为a·t+r·m+h·n。采用反向共享底边后：

`dot(n_seam,n_C) = -r / sqrt(r²+h²)`。

夹角<60°实际要求 `r < -sqrt(3)|h|`，把第三点限制到向外且近共面的区域。正常垂直侧壁r=0、h≠0时是90°；它会被罚掉。“面法向”和“边界外共法线”不是同一方向。将来若设计第三点约束，应针对有限C表面的非法穿插/近共面内向覆盖，允许正常侧壁，而不是把所有大二面角禁止。[逐来源接口](normal/source_per_edge.csv) · [解析例与报告](normal/REPORT.md)

`3f/n2` 原槽16确实向C内部伸展：RAW高度−0.11715、与C法向176.12°；PRE_GEO高度−0.00922、179.69°；POST高度0、180°。它支持“RAW已有内向延展，D0后更接近平面，GEO变成精确共面”。没有保存的积分轨迹，不能断言错误发生于积分后期。[逐槽分阶段表](normal/generated_per_seam_stage.csv)

## 7. 决策与下一步边界

用户给定的进入RL前提是前三项底座稳定；本轮没有达到。**RL状态：NOT_RUN_GATE_NOT_MET。** 没有训练错误的60°loss，也没有把全占用当成修好分类器，再在这两个前提上进行奖励训练。R29/R30既有负结果仍成立；原窗口策略已真实运行过，新的纯二值奖励尚未被这轮证明有独有收益。

保留SEAM_SLOT_C200：原“共享边能实际连入较大bulk”的正结果不受推翻。容量保护保留为独立工程候选，但不自动升级默认；它改善拓扑容量、同时撕开部分内部连接并新增FF，不能作为无代价修复。

若继续改动，优先让下一项受控训练面对**bulk内部冲突与C附近重复覆盖**，保留当前共享身份；不要把正确侧壁罚掉，也不要只奖励是否出现一条边。原FF/边界loss历史已存在，任何新loss需说明在新共享表示下的实质差别和如何保住形状；本轮不据这份诊断直接选择或启动新的loss/RL方案。占用分类改进仍可单独研究，但不承诺召回提高必然降低FF。
