# 四对象旧/带余量目标的单对象可拟合性诊断

新目标使四个对象的同场曲面 RMS 都下降，但原 Fixed 质量门槛的合格对象仍为 1/4。预先写下的扩大联合训练条件未满足；本轮没有启动后续联合训练。

八个任务均从同一原 v1 模型参数开始，CPU 单线程、全新 AdamW、seed10、batch4、固定 20,000 次更新。每 UID 的旧/新目标抽样时间序列哈希完全相同；全部八个任务实际上也共用同一抽样序列。共 160,000 次更新，每对象每目标曝光 80,000 次。这是一个训练种子的四个已见对象配对诊断，不是双种子成绩。

最终只使用第 20,000 次更新权重；0/5k/20k 的 24 个固定观察全部保留，不据中间结果选择权重。网络与 proxy256 不变，部署使用原 CPU4/32 步路径，最终接受方向重新查询半径，无 Fixed 回退。

20 个端点全部成功生成，均为实际 512 面并通过端点精确几何检查。原教师与带余量教师都符合各自已记录的质量约束；学习后的旧/新模型均只有 7f1be3e7 通过原质量门槛，该对象也通过 +0.1° 门槛。其余三个模型失败原因仍是角度尾部；不将拓扑/精确有效性当成角度质量合格。

2379915c 的新模型 p05 已超过 Fixed，但最小角仍低 0.276827°。8c919e99 的最小角大幅增加，p05 却低 0.286813°；736820a8 的最小角增加，p05 仍低 0.071287°。这些混合变化不能概括为全方面质量改善，也不能从教师端点的 +0.1° 余量推出学习输出有同样余量。

## 拟合误差与零位移教师

端点误差使用同节点方向坐标的均方误差；相对值除以该任务自身教师相对 Fixed 的位移能量。新旧目标的位移幅度不同，所以相对值更低不自动意味着绝对拟合误差更小。

| UID | 旧目标最终方向 MSE / 目标能量 | 新目标最终方向 MSE / 目标能量 | 旧/新最终绝对方向 MSE |
|---|---:|---:|---:|
| 7f1be3e7 | 0.071586 | 0.058622 | 1.99164e-05 / 2.30605e-05 |
| 2379915c | 0.370823 | 0.276433 | 2.91045e-06 / 7.34452e-06 |
| 8c919e99 | 0.572790 | 0.462832 | 1.95435e-07 / 4.95304e-06 |
| 736820a8 | 未定义（零位移） | 0.166276 | 8.49997e-10 / 4.36442e-06 |

736820a8 的旧教师恰为 Fixed，不能报告伪造的相对误差。虽然旧模型最终绝对方向 MSE 仅约 8.50e-10，它的 p05 仍比 Fixed 低 0.007723°，说明很小的总体方向误差仍可能越过本研究的严格尾部质量门槛。新目标的位移已被部分学到并降低了同场表面误差，仍没有恢复该对象的 p05 资格。

## 预先声明的算力分配规则

规则文件在二十个终端几何评测之前于 04:04 写下，SHA256 为 `8d7509ed3e69b8b9fd59acf6203e927b5d357f4e901bc0f4a4423149b522dfc6`。阈值未按结果调整。

1. 四个新模型均精确有效且 512 面：通过。
2. “原 Fixed 共同质量门槛通过、双次 RMS 相对 Fixed 均改善至少 2%”的联合成功数净增至少 1，且不丢旧成功：未通过，1/4 → 1/4，未丢失旧成功。
3. 至少两个对象新模型相对旧模型双次 RMS 均改善至少 2%：通过，3/4。8c919e99 两次为约 2.013% 和 1.689%，按原规则不算该项成功。

三项须同时满足，因此本轮为 NO-GO。这只是是否继续投入这条固定目标方案的探索性算力决策，不是统计显著性检验或论文接收标准。新的联合训练尚未获此结果授权。

## 可复核范围

独立 READBACK_REVIEW 重新执行了 24 个原 CPU 自由部署、全部 32 个离散桥时间的离线速度探针，并逐值核对最终方向/alpha。它还重查 20 个端点的最终半径、实际质量、精确几何和双 dtype 网格哈希，核对保存的 MC 缓存，没有重新采样 MC。技术 PASS 表示记账与数值重放一致，不表示研究假设通过。

所有表面误差均针对同一冻结径向主场的完整 2050 节点/4096 面曲面，数组逐值等于 RadialSupport.mesh(logr)，不是原始音箱资产网格。优化器与评测共享几何参考；评测 MC 样本独立。历史已封存文档的 GT 用词不回写，统一勘误见输出根目录 REFERENCE_SEMANTICS_CORRECTION_20260925.md。

带余量教师由另一段优化轨迹产生，同时改变位移与质量余量；本轮不能把效果解释成纯粹 +0.1° 标量的因果效果。没有使用旧 GPU 模型来充当配对 CPU 控制。四对象均为已见开发对象，不产生泛化结论，也不是与 MeshFlow 生成基线的论文级胜负比较。

八任务驱动总用时约 2087.34 秒（34.79 分钟），有其他研究任务并行，不能作为隔离性能基准。完整模型/优化器/CPU RNG/抽样状态、0/5k/20k 权重、原始训练曲线、所有失败分母与源码身份均已保留。
