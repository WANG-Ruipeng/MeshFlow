# R2_C_RESTORE_COUPLING_V1：固定 C 的去噪协调恢复

状态：COMPLETE，2026-10-11。固定实验已完成并停止。没有训练、生成器采样、新噪声、学生模型调用、参数扫描或默认模型切换。

**结论：简单 C 反馈成功降低了网络的 C 预测误差，但没有带来足够的接合改善；RBF 协调恢复获得更明显的局部接近与共边增量，同时增加了相交等代价。两者均不晋级为默认后处理。** 本轮支持“恢复信息能够改变部分 C/F 关系”，不支持“只要 D0 自己预测准 C，就会自动接好 F”。

## 1. 实际做了什么

固定此前 6 个 USER 条件父 × 2 份原噪声，即同一 12 份 R2_USER_MIX RAW；其中 4 份座面、8 份靠背。没有挑样、换权重、重抽噪声或训练。每组都保留原 C，最终使用完全相同的 GEO_C。

|组|计算|本轮新增 D0 前向|
|---|---|---:|
|D0_BASE|复用单次官方 D0 proposal，恢复 C，复用原 POST|0|
|RBF|对已有 proposal 传播恢复 C 的位移，再原 GEO_C|0|
|FEEDBACK|固定 F_RAW，累计调整内部 C 工作副本，两次查询后用末次 F，再原 GEO_C|24|
|D3|复用原三次去噪及原 POST，仅作三次总调用数的辅助参照|0|

所有真实查询均成功，24 attempts / 24 completions，无 OOM、失败、重试或参数调整。另做 4 个 CPU RBF 合成正反控和 3 个解析反馈检查；这些检查没有调用实际 D0，不能冒称已经证明真实 D0 的合成接合恢复能力。24 新 GEO_C、24 新 POST 完整质量评分；D0/D3 的 24 份既有质量结果经身份校验后复用。

冻结协议：[registration.json](registration.json)。全部执行事件：[ledger.jsonl](ledger.jsonl)。原 RAW、官方权重、旧评分器和旧报告保持只读。

## 2. 参数与合同

原固定尺度 L=9.208138264587333，不使用当前生成网格的 bbox 重新归一化。

RBF 使用 compact Wendland C2 核，支撑半径 0.10L，lambda=1e-6。每个源顶点 ID 的所有角点副本总权重为 1，保留全部不同 proposal 位置，不平均掉冲突。解 `(K + lambda diag(1/w)) a = C - C_hat`，在 F_hat 位置查询位移。每个 free 角点实际 FP32 位移上限 0.02L=0.1841627653；必要的 FP32 舍入回退也记录。最终 C 从原数组逐字节写回。这是正则拟合，不保证控制点插值残差为零，也不保证无折叠、无相交或正确语义连接。

反馈固定 eta=0.5、两次更新、累计工作 C 位移球半径 0.02L。每次用原始 F_RAW，误差为恢复前 `C-D0_C(C+delta,F_RAW)`；更新 FP64 delta，再构造 FP32 工作输入。每次都保存实际 GPU scaled input_d、完整 proposal_d、model-coordinate proposal、误差、delta 与末端输出。最终使用 query2 的 F，不按效果选轮次。

原 C 和最终 C 精确保留，但网络内部 C 工作副本确实改变，且按角点独立补偿，可能拆开同一源顶点的内部副本；不能沿用旧流程“每次网络输入 C 都不变”的描述。

官方 D0 EMA：455,592,963 参数；SHA256 `6a31f4c7dcbea7a6ac58c26075b20c897fd19aad4c33b5295cc4c93ed7078c36`。严格加载原源码，BF16 网络、FP32 参数及残差/缩放，SDPA math，TF32 关闭，严格 deterministic，逐查询核验未消耗 RNG。完整去噪输出包含恒等项。

## 6. 为什么 C 反馈的误差降了，接合却变化不大

C 预测误差的逐输出均值，再跨 12 输出平均，从 0.043324 降至 0.022475，再降至 0.017103；12/12 都单调下降。均值之比对应约 60.52% 降幅；先逐例算相对降幅再平均为 58.91%，两种汇总不能混写。

但 query2 的 F 相对初始 D0 平均位移只有 0.001772 模型单位。没有工作位移球饱和，所以本轮弱收益不能简单归因为位移上限一直卡住。网络改变内部 C 响应的能力，明显没有转化为同量级的 free 整体修正；这支持“当前误差驱动不足以修复接合”的判断，不构成 J_FC 恒为零或所有反馈求解都无效的证明。

[逐更新残差与位移](feedback_per_update.csv)、[逐 C 角点](feedback_per_C_corner.csv)、[逐父双噪声机制表](mechanism/feedback_paired_parent_noise.csv)及每次实际输入/proposal 均留本地。因 BF16 和非线性影响，不能把当前响应直接解释为精确后验协方差。

RBF 的另一个限制也实际出现：86ec 两噪声的锚点所需位移最大仅约 0.161/0.172，但未限幅 free 场最大达到 3.788/4.963；两例分别有21和43个角点触发限幅。线性方程残差很小，说明不是求解失败，而是局部场存在很大的放大。小锚点拟合残差不保证 free 位移场可靠。其余 10 例没有触发限幅；没有为这两例更改核宽、正则或上限。

## 9. 决策与下一步假说

**维持单次官方 D0 + C恢复 + 原GEO_C作为参照。RBF保留为有局部信号、但有代价的研究候选；当前两步简单反馈不采用为默认。** 本次不是否定所有条件求解器，也不支持马上升级Jacobians、大训练或蒸馏。

若继续，优先处理RBF中“该让哪些free面跟随、如何避免局部场放大”这个问题。检验假说是：现有接近增量中有可保留的部分，但重复角点约束产生的放大和对不该联动表面的移动，引入了I代价；一个有明确几何对应、位移与方向限制的协调算子，才可能保住部分增量并减少这些代价。仍需实际检验，不能从本轮直接推出成立；不在本轮自动执行。

完整新源码位于 `r2/tools/c_restore_coupling_v1/`，原评分源码小文件位于 [scoring_code](scoring_code/)。主入口：`python -B r2/tools/c_restore_coupling_v1/run.py --stage {prepare,geometry,denoise,score,gallery,all}`。各科学阶段验证已有receipt后复用；已启动但缺少合法receipt的模型调用拒绝静默重跑。已经完成，不应追加查询或据新结果挑参数。
