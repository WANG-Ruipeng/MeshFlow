# 同一物理 C：内部翻边与两臂 200 步快测

实验：`R2_BENCH_C_EDGEFLIP_V1`。实际完成日期：2026-10-28。

**结论：本版内部重三角化增强不晋级，也不自动延长训练。** 它在 `459/n0` 上比普通续训更能保住换划分后的主体组织，但没有稳定减少碎面；原输入面板的最终 FF 更高、合法 C/F 共边覆盖下降，且熟悉父 `bcb/n1` 出现明显的主体/C 关系退化。单面孤岛数量下降不能抵消这些结果。

EXPOSURE 保持原来的证据地位，本轮也不晋级普通续训 PLAIN200。这里的 EXPOSURE 数字只来自本轮三个父、六个原请求，不能与历史 46 请求的均值直接比较。固定任务已完成；没有清理旧资产、改变默认模型、commit 或 push。

## 1. 这次实际检验了什么

上一轮中点细分同时改变了 K、N、部分 count bin 和外边界划分。此次只翻转一个合法内部对角线：**顶点坐标、K、N、count bin、C 的有限物理表面、有向外边界和原 free 噪声全部保持**。它隔离了内部三角划分变化，但仍会改变三角形中心、边形状、每面特征与角点组织；不能称为只改了某一个 attention 因子。

| 评价父 | 身份 | K / N | 内部翻边 |
|---|---|---:|---|
| 459 | 既有 DEV | 3 / 198 | 合法，内部边 [1,2] → [0,4] |
| f495 | 既有 DEV | 5 / 160 | BLOCKED；候选不满足几何合同，保留原输入回归 |
| bcb | 已训练的 HIGH 父 | 2 / 520 | 合法，内部边 [1,2] → [0,3] |

每条输入使用原 n0/n1。没有补父、抽新噪声、重三角化 free 或放宽几何门槛。合法翻边要求共面凸四边形、来源绕序一致、外边界不变、不产生重复/退化/新增局部非法相交，并限制小角恶化。两条实际评价翻边的平面差和面积相对误差均为 0。

这不是全新独立测试集，也不是跨新父泛化检验。评价条件是既有开发证据，其中 bcb 在训练池内；只有两种输入具备合法翻边，覆盖有限。

## 2. 冻结 EXPOSURE 的前置结果

原权重与原六份 RAW 复用；仅生成四份翻边 RAW。每份 Euler50、C 在全部 51 个状态精确保留，模型参数前后 hash 相同。

| 请求 | 原 RAW FF → 翻边 FF | 共同物理 C 的 I：原 → 翻边 |
|---|---:|---:|
| 459/n0 | 98.462% → 97.436% | 0 → 0 |
| 459/n1 | 96.923% → 94.359% | 14.6973% → 14.7461% |
| bcb/n0 | 83.784% → 84.749% | 0 → 0.0488% |
| bcb/n1 | 86.873% → 89.768% | 0 → 0 |

实际双视图/截面中，459 的主体组织基本保持；bcb 没有重现上轮中点细分 n1 的明显 L 形退化。但没有明确碎面改善，四对均无合法 RAW C/F 共边。此处 RAW 指标不能同最终整理网格的低 FF 数字拼接比较。

即使 K 相同，旧 I 仍依赖查询归属三角面及其截交线：459/n1 使用新 C 原评分得到 I=14.7949%，固定原 C 再核对则为 14.7461%。所以保留原177字段，同时新增独立的共同原 C 列；没有改写旧评分定义。原 2048 个物理查询点、权重、法向和边界距离不变，只重映射翻边后的所属三角面/重心坐标。

## 3. 两臂训练与可比性

用户明确批准 PLAIN200 与 FLIP200 各 200 步后，才启动本轮训练。

| 项目 | 两臂共同合同 |
|---|---|
| 起点 | 保留的 EXPOSURE global25500 live 生成器及匹配 AdamW/RNG |
| 模型 | 原 Native/T1 + role + Geo；无新网络、占用头更新或辅助 loss |
| 优化 | 原 free-only FM、OT 后 HYBRID0.25；batch8/micro1；lr1e-5；原 AdamW/clip |
| 数据 | 同30条 TRAIN 条件；OLD/FOCUS/HIGH 实例数各1200/200/200 |
| 数值 | BF16 前向、FP32 参数/积分、严格确定性、math SDPA、TF32关闭 |
| 预算 | 每臂200更新、1600前向、1600反向；固定global25700/native13700 |
| 唯一处理差异 | FLIP200按每条条件完整 CLEAN/X_WIDTH 配对交替使用合法内部翻边 |

30条训练条件中28条可翻，2条保留原输入。FLIP200共实际翻转728实例（CLEAN364、X_WIDTH364），另52个计划翻转实例因几何门槛回退原输入；未剔除父。C 与完整训练目标中的已知面同步替换，**free目标、噪声、OT和监督速度不变**，不是给原目标施加一份几何不一致的 C。

独立核对1600个配对实例的身份、N/K、组系数、随机数组身份与实际 t；60次真实 CPU OT 原/翻边检查通过。首次翻边在第5步，之前4步两臂 objective/FM/梯度范数完全相同。没有为了验证增加模型探针，也没有重新加载终点跑训练。

此次复用了 EXPOSURE 旧计划的前200行及其随机流作为**新续训分支**；不是把旧任务冒充无缝恢复，也不是全新随机流证据。首末50步来自不同固定任务批次，不能单凭该均值证明收敛。

| objective均值 | 首50步 | 末50步 | 全200步 |
|---|---:|---:|---:|
| PLAIN200 | 0.09704179 | 0.09757545 | 0.09429593 |
| FLIP200 | 0.09737532 | 0.09772078 | 0.09447939 |

训练 loss 没有增强臂独有优势。两臂均真实完成、零科学失败、零重算，完整终点和推理导出均保留。

## 4. 固定终点评价：主要结果

三模型各评价六个原输入和四个翻边输入，分开报告。先保存全部24份新 RAW，再进行24次单次官方 Bench D0，统一接原 GEO_C/来源定向、HINGE_OPP015、ALPHA、HOLE。原 EXPOSURE 六份 RAW/FINAL 按身份和 hash 复用。没有选 best checkpoint 或挑噪声。

下表为**六个原输入**、先父内两噪声平均再父等权；百分比均按逐输出原分母计算后取均值。I 使用固定原 C 查询。

| FINAL 指标 | EXPOSURE | PLAIN200 | FLIP200 |
|---|---:|---:|---:|
| 非法 FF 受影响 free 面比例 ↓ | 12.414% | 18.808% | **23.099%** |
| 非法 CF 受影响 free 面比例 ↓ | 8.268% | 4.307% | 4.598% |
| I 冲突覆盖 ↓ | 14.950% | 12.866% | 13.590% |
| free 小角 <5° 比例 ↓ | 59.076% | 66.699% | 63.600% |
| q>10 比例 ↓ | 42.706% | 54.927% | 55.299% |
| 有合法 C/F 共边的输出 | 2/6 | 2/6 | **1/6** |
| 平均合法 C/F 边数 | 0.500 | 0.500 | 0.167 |
| 原索引共边图单面孤岛均数 ↓ | 19.000 | 19.667 | 14.667 |
| 过滤非法共边后的单面孤岛均数 ↓ | 20.333 | 20.333 | 16.167 |
| 存活 free 面数均值 | 64.833 | 59.667 | 56.167 |
| 删除 free 面数均值 | 224.500 | 229.667 | 233.167 |
| free 总面积均值（模型单位²） | 20.707 | 19.558 | 20.090 |
| FINAL/RAW free 面积比例均值 | 62.563% | 57.548% | 56.838% |

**FLIP200 相对普通续训的最终 FF 增加4.291个百分点，CF增加0.291个百分点，I增加0.724个百分点。** 小角比例下降3.100个百分点，但 q>10、合法接口覆盖及存活面数未同步改善。孤岛计数的下降主要不能独立解释为修好碎面；见下一节 bcb/n1 的实际反例。

DEV 两父单独看，FINAL FF 为18.621% → 24.790% → 27.463%；没有跨DEV的质量升级。熟悉 bcb 父则为0 → 6.845% → 14.371%。原逐父/逐噪声均保留，未用 bcb 的孤岛下降掩盖其形状退化。

四个**翻边输入**独立结果如下，不与六个原请求混成一份较好均值：

| FINAL 指标 | EXPOSURE | PLAIN200 | FLIP200 |
|---|---:|---:|---:|
| FF | 18.246% | 8.856% | 22.329% |
| 共同 C 的 CF / I | 5.108% / 3.455% | 0 / 0 | 0 / 0 |
| 小角 <5° | 60.808% | 76.847% | 76.527% |
| 有合法 C/F 共边 | 1/4 | 2/4 | 1/4 |
| 单面孤岛（未滤非法边）均数 | 24.500 | 25.000 | 25.250 |

PLAIN200 的低 FF/零 CF/I 同时伴随很低的面积保留，不能把它视为后处理全面升级；FLIP200 在这组也没有稳定优势。

## 5. 实际图审：为什么没有把“孤岛下降”记为成功

20页、60格三模型同尺度双视图和同位置双截面已实际查看。评阅是非盲 AI_PROXY，保留用途、主体、支撑与碎片的不确定项；不是独立人类评价。没有根据评分自动生成标签，也没有把截面端点直接当作浮片。

本轮实际标签的“合理采用 ∩ 合理完整主体 ∩ 主要支撑存在”同输出交集：

| 面板/阶段 | EXPOSURE | PLAIN200 | FLIP200 |
|---|---:|---:|---:|
| 原输入 RAW | 3/6 | 2/6 | 1/6 |
| 原输入 FINAL | 1/6 | 0/6 | 0/6 |
| 翻边输入 RAW | 3/4 | 2/4 | 2/4 |
| 翻边输入 FINAL | 1/4 | 0/4 | 0/4 |

这是当前固定图审中的标签交集，不是自动几何真值，也不改写历史同资产的旧标签。尤其不确定的 C 接触或细腿残迹没有被强行算成成功。

- **459/n0，局部正信号。** PLAIN200 原输入仍有宽端架/靠背，换内部对角线后变为上层灰板和细支撑，FINAL只剩较稀疏的框线。FLIP200在两种划分下保留较完整的宽端架/靠背组织。因此可以说它改善了这一请求对划分的用途/形状稳定性，不能说已经证明广泛减少碎面。
- **459/n1，两个新模型共同退化。** 两种划分下，PLAIN200与FLIP200都出现灰板在蓝C上方、蓝C处于低层的关系；FINAL主体更稀疏。原输入该例 free 面积从19.934降至2.838/2.876模型单位²，而CF/I降到0。**冲突变低与丢面、失去合理采用同时发生。**
- **bcb/n1，反对晋级的关键例。** FLIP200原输入生成L形灰板和偏置支撑，蓝C没有自然并入主体；FINAL支撑大部分消失。原索引共边单面孤岛从PLAIN200的35降至5，但FF从9.524%升至20.408%，合法C/F边从2降至0。这是“孤岛少但整体更差”的实际反例，不是无条件把新款式判坏。
- **f495，旧问题未修好。** n0三个模型都在蓝C上方另有灰水平层；n1都保留密集板条及端架，但蓝C用途仍不明确。后处理改变板条和端部开口，未看到FLIP200独有的碎裂修复。细截线不足以认证拓扑悬片，所以相关项记为不确定。
- **bcb其他请求，RAW轮廓相近。** 没有可靠看到增强独有的碎片改善。FINAL普遍将回弯侧体/支撑删薄成板片或细条残留；这项阶段损伤仍存在。

同物理C响应也没有一致减小。固定free槽位的平均角点位移（只作响应诊断，不是质量分数）在459/n0为PLAIN200的7.799%L、FLIP200的1.404%L；但bcb/n1从PLAIN200的0.623%L增加到FLIP200的24.998%L。后者与实际主体变化一致，不能只报告前者。

RAW三角汤按定义有独立索引，RAW索引孤岛数量不能当视觉碎片数量。FINAL合法边过滤图的孤岛也可能来自非法关系被过滤，而不是物理断裂。完整图统计因此与视觉观察分开保存。

## 6. 账本、资源与边界

- 本轮总400更新、3200训练前向、3200反向；无额外头训练或探针。
- 24新RAW共1200次Euler前向；24次单次官方D0；无新增评价噪声或查询。训练按冻结旧种子构造原Gaussian/HYBRID数组，CPU门检也按同种子物化，不把它们称为零随机数组计算。
- 72次完整新评分（4冻结RAW、20训练RAW、48 BASE/FINAL），额外24次共同原C的CF/I诊断，无额外FF扫描；原后处理自身BASE面对缓存另按24次记账。
- 训练30条件可行性、60次CPU OT、实际配对账本和终点hash均通过。工程准备中HIGH条目缺少旧group字段的适配修正发生在训练前，已留记录；未改变数据或科学预算。
- RTX5080总显存16303MiB、24 CPU核。两条训练先后启动并部分重叠，各墙时374.56/371.78秒；设备实测峰12436MiB，最小空闲3544MiB。WDDM下进程VRAM不可用；Torch allocated/reserved不冒充进程占用。重叠时间按进程或科学调用窗口有不同口径，详见资源/独立审计，不能作为独占吞吐基准。
- 采样分两个独立进程增量启动，D0一进程；CPU评分/渲染分别最多2 worker、线程受限。全部保护原资产和原评分定义保持；未终止用户进程。

这是一个有限开发快筛：两个评测C可合法翻边、一个保留原输入；旧噪声和小面板无法支撑泛化认证。本轮负结果只针对这份固定200步内部翻边增强，不否定所有表面条件表示或充分训练。但它已经不支持把该增强作为当前碎面修复方案，**不应仅凭局部正例自动加训。**

## 7. 交付与停止决定

保留EXPOSURE现状、两条真实终点和全部正负证据，不替换默认。当前可以确定的事实是：C划分仍能影响生成，200步增强没有稳定压低这种敏感性，也没有改善最终碎裂/质量；原有RAW→D0/GEO结构损伤并未被解决。后续若再提出机制，需要同时保住主体、支撑和采用，不能只用孤岛或低CF/I判成功；本轮不自动启动下一项实验。
