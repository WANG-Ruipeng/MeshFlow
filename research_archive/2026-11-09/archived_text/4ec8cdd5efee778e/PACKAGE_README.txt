This compact analysis package contains all per-output/per-parent numeric tables, all actual visual observations, actual scoring and pilot source, hashes, protocol, calls and engineering records. Illustration pages are an explicitly selected subset; every RAW/BASE/FINAL mesh, 51-state trajectory, full gallery and original receipt remains in the local experiment directory. Large weights and complete meshes are excluded. The original source dependencies are included as byte-identical evidence, not a standalone replacement environment.
